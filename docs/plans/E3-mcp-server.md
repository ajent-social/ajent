# E3 -- MCP server

Acceptance: `ajent mcp` serves all 18 contract `ajent_*` tools over stdio with contract-identical names, schemas and behavior (skill catalog tools retired; ADR 009). A spawned-binary transcript test passes on all three OSes.
fidelity: executable

Parallel layout: T3.1 (transport) has no internal dependencies. T3.2 owns the registry, the session, the envelope and the `ajent mcp` command, and registers all 18 tool definitions. T3.3, T3.5 and T3.8 attach handlers from separate files (`tools_read.go`, `tools_write.go`, `tools_goals.go`) and run in parallel. T3.4 adds persistence to the in-memory cache. T3.6 builds `internal/profiles` and wires `cli.Env.Resolve`, which the MCP session reuses. T3.9–T3.11 skill catalog work was shipped then retired (ADR 009). Signatures: docs/interfaces.md. Contracts: docs/tasks/T3.*.md.
