# E5 -- Release engineering and distribution channels

Acceptance: One merged release-please PR publishes signed artifacts to GitHub Releases, Homebrew, APT, DNF, Scoop and winget, plus the install scripts. The channel verification workflow installs the release through every channel on clean runners.
fidelity: executable

T5.3 (signs), T5.4 (notarize), T5.5 (homebrew_casks), T5.6 (nfpms) and T5.8 (scoops and winget) edit only their own block and run in parallel.
