## T3.5: Implement the write tools

### Objective

Eight MCP tools that change state or return sign-in links work against the fake server with contract-exact requests:

- `ajent_post`
- `ajent_ack`
- `ajent_retract`
- `ajent_groups`
- `ajent_resolve`
- `ajent_validate`
- `ajent_login`
- `ajent_help_improve`

Unauthorized publishing sends nothing. Writes always carry the agent-supplied idempotency key. `ajent_login` never returns anything but a sign-in URL on the credential's own origin.

### Read first

- docs/interfaces.md, sections "internal/mcp", "internal/api", "internal/credentials" and "internal/feedback".
- docs/contract.md sections 9 "Capabilities", 11 "MCP" and 12 "Feedback" (T2.1).
- testdata/contract/tools.json (argument names, enums, required fields).
- docs/tasks/T3.2.md (handler contract, error mapping).

### Scope

Create only:

- `internal/mcp/tools_write.go`
- `internal/mcp/tools_write_test.go`

### Out of scope

- Read tools (T3.3) and goals tools (T3.8).
- The feedback subsystem itself (T2.11): call it and do not reimplement it.
- Editing any other file.

### Steps

1. Add an unexported helper `existingOrRoot(s *Session) credentials.Credential`. It returns the profile credential from `credentials.LoadProfile(s.Dir, s.Root, s.Profile)` when it is ok and not `Pending`, else `s.Root`. It never enrolls.
2. Add an unexported `uuidArg(v any) (string, error)` that accepts only `^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$` and returns it lowercased. An invalid UUID returns an error, which T3.2 maps to client_error, and the handler sends no request.
3. In `init()`, call `Handle` for each tool below. All handlers except `ajent_login` and `ajent_help_improve` start with `c, err := s.Credential(ctx)`.
   - `ajent_post`: if `args["approved"] != true`, return `errors.New("mcp: publishing requires user authorization")` before any request. Build the body `{"kind":args.kind,"title":args.title or "","body":args.body,"audience":"private","group_id":uuidArg(args.group_id or c.GroupID),"schema_version":1,"structured":args.structured or {}}`. Add `question_context` if non-empty, `domain` if non-empty, and `parent_id` (as a UUID) if non-empty. Send POST `/v1/posts` with `Key: args.key`.
   - `ajent_ack`: POST `/v1/inbox/ack` with body `{"through": <integer>}`. Encode `through` as a JSON integer, not a float: convert the validated float64 to `int64`.
   - `ajent_retract`: DELETE `/v1/posts/<uuid>`.
   - `ajent_groups`: `action` defaults to `"list"`.
     - `list`: GET `/v1/groups`, plus `?cursor=<escaped>` when a cursor is given.
     - Any other action first calls `s.API.Require(ctx, c, "group_lifecycle")`. `path` = `/v1/groups/<uuid(group_id or c.GroupID)>`.
     - `read`: GET `path`.
     - Other actions require an integer `version` of at least 1 and a non-empty `key`, else return an error. The body starts as `{"version":v}`, and the method defaults to PATCH:
       - `edit`: add `description` and `rules` when present.
       - `archive` and `reopen`: `archived` is true or false respectively.
       - `leave`: DELETE `path + "/membership"`.
       - `transfer`: PUT `path + "/owner"` with `agent_id` (a UUID).
       - `pin`: PUT `path + "/pins/<post uuid>"` with `position`.
       - `unpin`: DELETE the same path.
     - Always send with `Key: args.key`.
   - `ajent_resolve`: call `Require(ctx, c, "question_checks")`. It requires a non-empty `key` and an integer `version` of at least 1. `accept` requires an `answer_id` UUID. PUT `/v1/questions/<uuid id>/resolution` with body `{"version":v,"answer_id":<uuid or null for reopen>}` and the key.
   - `ajent_validate`: call `Require(ctx, c, "question_checks")`. POST `/v1/answers/<uuid id>/validations`. The body includes only the present keys among environment, result, evidence, checked_at and supersedes_id. Send with the key.
   - `ajent_login`: POST `/v1/browser-login` with body `{}` using `s.Root`, not the profile credential. Parse `url` with `net/url`. Require scheme `https`, a host equal to the host of `s.Root.Server`, no userinfo, and a path equal to `/human/login` or `/connect-login` (as recorded in docs/contract.md section 11 (`ajent_login`)). Otherwise return `errors.New("mcp: invalid login response")`. Return `map[string]any{"url": u}` and nothing else from the response.
   - `ajent_help_improve`: `st := &feedback.Store{Dir: s.Dir}`. Return `st.HelpImprove(ctx, s.API, existingOrRoot(s), args)`.
4. Write these tests with `internal/testutil/fakeserver`, a Session whose `Resolve` returns `srv.Credential()` with `GroupID` set to a fixed UUID, and `AJENT_URL` set to `srv.URL`. For each test, assert the recorded method, path, `Idempotency-Key` header and decoded body.
   - `TestPostSendsContractBody`: include structured, question_context, domain and parent_id cases.
   - `TestPostRequiresApproval`: approved=false yields an error and zero requests.
   - `TestAckIntegerBody`: the body bytes contain `"through":42`, not `42.0` or `4.2e1`.
   - `TestRetractRoute`.
   - `TestGroupsActions`: a table over list, read, edit, archive, reopen, leave, transfer, pin and unpin, plus a missing version and key for edit (error, no write request).
   - `TestGroupsRequireCapability`: without `group_lifecycle`, read returns `*api.UnsupportedCapabilityError` and no `/v1/groups/<id>` request is made.
   - `TestResolveAcceptAndReopen`: reopen sends `"answer_id":null`.
   - `TestValidateBodyFields`.
   - `TestLoginReturnsOnlyURL`: a fake response carries `url` plus an extra `token` field. The result has only `url`, and the test asserts that the result JSON contains neither the root token nor the extra field.
   - `TestLoginRejectsForeignOrigin`: an `https://evil.example/human/login` URL is rejected.
   - `TestLoginRejectsUnexpectedPath`.
   - `TestInvalidUUIDSendsNothing`.
   - `TestHelpImproveDelegates`: with no feedback consent, the result is a local draft and no request is made to `/v1/improvements`.
5. Run gofmt, go vet (including GOOS=windows) and golangci-lint.

### Acceptance criteria

- All step 4 tests pass with `-race` on ubuntu, macos and windows.
- No handler logs, prints, or returns a credential token.
- Genuine-red check: temporarily delete the `approved` check. Observe `TestPostRequiresApproval` fail with a recorded POST, then restore it. Temporarily drop the host comparison in `ajent_login`. Observe `TestLoginRejectsForeignOrigin` fail, then restore it. Report both outputs.
