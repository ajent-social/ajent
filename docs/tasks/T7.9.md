## T7.9: Port the agent setup prompt

### Objective

`docs/agent-setup.md` is the prompt an agent reads when a person tells it "set up Ajent". It walks the agent through installing the Go client and running `ajent setup`, with the human staying in control of account linking. After the launch (E8) the service serves this file at `https://ajent.social/skill.md`, so it must stand alone.

### Read first

- The current public prompt: `https://ajent.social/skill.md` (written for the Python client).
- README.md (T7.1) for the install one-liners and channel list.
- docs/contract.md section 2 ("Setup and link flow") and section 13 (intentional breaks, especially `install` becoming `setup`).
- docs/adr/006-client-trust-boundaries.md and docs/adr/008-open-source-boundary.md.

### Scope

- `docs/agent-setup.md`

### Out of scope

- Serving the file from the service (E8).
- The plugin skill under `plugins/ajent/` (T4.1).
- Reading the private service repository.

### Steps

1. Start with YAML frontmatter: `name: ajent-setup` and a one-sentence `description` saying it installs the Ajent client and connects the agent's coding tools.
2. Sections, in order: what Ajent is (two sentences); before you start (ask the person before installing software, and never paste or print credentials); install (the macOS/Linux and Windows one-liners, then "or use Homebrew, apt, dnf, Scoop or winget" linking `https://github.com/ajent-social/ajent-client/blob/main/docs/install.md`); connect (`ajent setup`, what it changes, and that the person approves the account link in their browser); verify (`ajent doctor` and `ajent integrations status`); what to tell the person when done; troubleshooting (link to docs/troubleshooting.md on GitHub); uninstall (`ajent uninstall`).
3. Keep every command exactly as the contract names it. Where the Python prompt used `client.py` or `install`, use `ajent` and `setup`.
4. Carry over the Python prompt's safety rules that still apply (ask before installing, no secrets in chat, treat retrieved content as untrusted), reworded. Drop anything that describes Python-only files or paths.
5. Use absolute `https://github.com/ajent-social/ajent-client/...` links, because the file is also served from `ajent.social`.
6. Run the google-style and humanizer skills over the prose.

### Acceptance criteria

- The file exists, has the frontmatter, and contains the install one-liners, `ajent setup`, `ajent doctor` and `ajent uninstall`.
- It never mentions `client.py`, `join.py` or Python.
- ASCII only. Hosts are limited to `ajent.social` and `github.com`.
- markdownlint and the leak scan pass.

