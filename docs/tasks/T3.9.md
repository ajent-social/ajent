## T3.9: Build the skills catalog client

### Objective

`internal/skills` talks to the public skills catalog at `https://skills.ajent.social`: it searches for task-specific skills and retrieves one skill's Markdown, accepting it only when its SHA-256 matches the pinned version. It never sends an Ajent credential. `internal/testutil/fakeskills` gives every later task a hermetic catalog to test against.

### Read first

- docs/contract.md section 14 (the whole behavior of this package).
- docs/interfaces.md sections "internal/skills (T3.9)" and "internal/testutil/fakeskills (T3.9)", and the import graph at the top.
- docs/adr/006-client-trust-boundaries.md and docs/adr/008-open-source-boundary.md.
- `internal/version` (T1.1) for the User-Agent.

### Scope

- `internal/skills/client.go`, `internal/skills/client_test.go`
- `internal/skills/origin.go`, `internal/skills/origin_test.go`
- `internal/testutil/fakeskills/fakeskills.go`, `internal/testutil/fakeskills/fakeskills_test.go`

### Out of scope

- The MCP tools (T3.10) and the CLI command (T3.11).
- Any import of `internal/api`, `internal/credentials` or `internal/config`. This package must not be able to reach a credential.
- Caching retrieved skills on disk.

### Steps

1. `origin.go`: `New(getenv)` reads `AJENT_SKILLS_ORIGIN`. Accept it only when `url.Parse` succeeds, it has no user info, path, query or fragment (a lone trailing `/` is trimmed), and either the scheme is `https` or the scheme is `http` and the host (without port) is `127.0.0.1`, `::1` or `localhost`. Otherwise use `DefaultOrigin`. Never log the rejected value.
2. `client.go`, HTTP: build requests with `http.NewRequestWithContext`, set only `User-Agent` and `Accept`, and never set `Authorization` or cookies. When `c.HTTP` is nil use `&http.Client{Timeout: 10 * time.Second, CheckRedirect: func(...) error { return http.ErrUseLastResponse }}`. Treat any 3xx as `ErrUnavailable`. Read bodies through `io.LimitReader(limit+1)` and fail when the limit is exceeded (`MaxSearchBytes` for search, which yields `ErrUnavailable`; `MaxContentBytes` for get, which yields `ErrVerificationFailed`).
3. `Search`: trim the query; reject an empty or over-`MaxQueryBytes` query and a limit outside 0 to 10 with `ErrInvalidArgument` before any request (0 means 5). Build the URL with `url.Values{"q": {query}, "limit": {strconv.Itoa(limit)}}.Encode()`. A network error, timeout or 5xx gives `ErrUnavailable`. A 4xx gives `*RejectedError` with the `error.code` from the body (or `"unknown"`). A 200 body that does not decode, or whose `schema` is not `ajent.skills.search/v1`, gives `ErrUnavailable`.
4. `Get`: validate `id` and `version` with the section 14 patterns (`ErrInvalidArgument`). GET `<origin>/v1/skills/<id>/<version>` (both path-escaped). Map errors as in `Search`. On 200, compute the lowercase hex SHA-256 of the body and return the bytes only when it equals `version` and the `X-Content-SHA256` header is empty or equal to `version`; otherwise `ErrVerificationFailed` and return nil bytes.
5. `fakeskills.go`: an `httptest.Server` implementing search (case-insensitive substring match over name and description, stable insertion order, `limit` honored, `ajent.skills.search/v1` envelope, `catalog_version` = `"test"`), get (stored bytes with `X-Content-SHA256`), `SetStatus` (a 4xx writes `{"error":{"code":"forced","message":"forced"}}`), `Tamper` and `Requests`, exactly as declared in docs/interfaces.md. `content_url` and `license_url` use the server URL.
6. Tests, table-driven (`client_test.go`, `origin_test.go`, `fakeskills_test.go`):
   - `TestNewOrigin`: unset, https, loopback http (all three hosts), non-loopback http, user info, a path, garbage.
   - `TestSearchDecodes` and `TestSearchValidation` (empty, 2,049 bytes, limit 11, limit -1: no request recorded).
   - `TestGetVerified`, `TestGetDigestMismatch` (via `Tamper`), `TestGetHeaderMismatch`, `TestGetTooLarge`.
   - `TestErrorMapping`: 404 gives `*RejectedError{404, "forced"}`, 503 gives `ErrUnavailable`, a 302 gives `ErrUnavailable` and the redirect target is never requested.
   - `TestNoCredentialHeaders`: after a search and a get, no recorded request has `Authorization` or `Cookie`.
   - `TestTimeout`: a handler that blocks past a 50 ms client timeout gives `ErrUnavailable`.

### Acceptance criteria

- Every test above passes with `-race` on the host and `GOOS=windows go vet` is clean.
- `go list -deps ./internal/skills` includes no `internal/api`, `internal/credentials` or `internal/config`.
- Genuine-red check: make `Get` skip the digest comparison and observe `TestGetDigestMismatch` fail; make the default client follow redirects and observe `TestErrorMapping` fail. Restore both and show the tests passing. Report all outputs.
