## T2.2: Build the config package: directories, private writes and locks

### Objective

`internal/config` provides the private filesystem primitives that every other package uses: the config directory, atomic private writes, exclusive creation, symlink refusal, and a cross-process advisory lock that works on Linux, macOS and Windows. The tests pass on all three operating systems.

### Read first

- docs/interfaces.md, section `internal/config` (exact signatures)
- docs/adr/006-client-trust-boundaries.md (0600 and 0700 modes, symlink refusal)
- docs/design.md (invariants)

### Scope

Create exactly these files:

- `internal/config/config.go` (`Dir`, `EnsurePrivateDir`, `ReadPrivate`, `ReadJSON`, `WriteJSON`, errors)
- `internal/config/write.go` (`WritePrivate`, `CreateExclusive`)
- `internal/config/lock.go` (the `Lock` type, `Acquire`, polling loop)
- `internal/config/lock_unix.go` (`//go:build !windows`, using `syscall.Flock`)
- `internal/config/lock_windows.go` (`//go:build windows`, using `windows.LockFileEx` and `windows.UnlockFileEx`)
- `internal/config/config_test.go`
- `internal/config/lock_test.go`
- `go.mod` and `go.sum`, only to add `golang.org/x/sys` at its latest release (`go get golang.org/x/sys@latest`)

### Out of scope

- Credential or profile logic (T2.3, T2.12).
- Any other package.
- Changes to `cmd/`.

### Steps

1. In `config.go`, declare `ErrSymlink = errors.New("config: refusing symlink")` and `ErrLockTimeout = errors.New("config: lock timeout")`.
2. Implement `Dir() (string, error)`. If `os.Getenv("AJENT_CONFIG_DIR")` is non-empty, use it. Expand a leading `~` followed by the separator using `os.UserHomeDir`, and make the path absolute with `filepath.Abs`. Otherwise use `filepath.Join(home, ".aj")`. Then call `EnsurePrivateDir` and return the path.
3. Implement `EnsurePrivateDir(path string) error`:
   - If `os.Lstat(path)` reports a symlink, return an error wrapping `ErrSymlink`.
   - `os.MkdirAll(path, 0o700)`.
   - On non-Windows, `os.Chmod(path, 0o700)`.
   - Lstat again and refuse a symlink (this closes the race).
4. Implement `ReadPrivate(path string) ([]byte, error)`. Lstat the path. If it is a symlink, return `ErrSymlink` wrapped with the path. Otherwise `os.ReadFile`. `fs.ErrNotExist` passes through unwrapped-compatible, so `errors.Is` works.
5. Implement `WritePrivate(path string, data []byte) error`:
   1. Refuse a symlink at `path` (Lstat).
   2. Create the temp file with `os.CreateTemp(filepath.Dir(path), ".ajent-*")`.
   3. On non-Windows, `Chmod(0o600)` the temp file.
   4. Write the data, `Sync`, then `Close`.
   5. `os.Rename(tmp, path)`. Go's `os.Rename` replaces the target on Windows.
   6. On non-Windows, open the directory and `Sync` it, ignoring the error.
   7. Remove the temp file on any failure path, using a deferred cleanup guarded by a `renamed` flag.
6. Implement `CreateExclusive(path string, data []byte) error`. Open with `os.OpenFile(path, os.O_WRONLY|os.O_CREATE|os.O_EXCL, 0o600)`, write, `Sync`, and close. If the open fails with an error that satisfies `errors.Is(err, fs.ErrExist)`, return it wrapped with `%w` so the check still holds. On a write failure after creation, remove the file.
7. Implement `ReadJSON(path, v)` as `ReadPrivate` followed by `json.Unmarshal`. Implement `WriteJSON(path, v)` as `json.MarshalIndent(v, "", "  ")`, then append `"\n"`, then `WritePrivate`.
8. In `lock.go`, define `type Lock struct{ f *os.File }`. `Acquire(path, timeout)` does the following:
   - Refuse a symlink at `path`.
   - Open with `os.OpenFile(path, os.O_RDWR|os.O_CREATE, 0o600)`.
   - Loop: call the platform `tryLock(f) (bool, error)`. On success, return the lock. On "would block", sleep 10ms until `timeout` elapses, then close the file and return `ErrLockTimeout`.
   - A zero timeout means exactly one attempt.
   - `Release()` calls the platform `unlock(f)`, then `f.Close()`. It is safe to call twice (the second call returns nil).
9. `lock_unix.go`: `tryLock` uses `syscall.Flock(int(f.Fd()), syscall.LOCK_EX|syscall.LOCK_NB)`. `syscall.EWOULDBLOCK` returns `(false, nil)`. `unlock` uses `LOCK_UN`.
10. `lock_windows.go`: `tryLock` calls `windows.LockFileEx(windows.Handle(f.Fd()), windows.LOCKFILE_EXCLUSIVE_LOCK|windows.LOCKFILE_FAIL_IMMEDIATELY, 0, 1, 0, &windows.Overlapped{})`. `windows.ERROR_LOCK_VIOLATION` returns `(false, nil)`. `unlock` calls `windows.UnlockFileEx` with the same range.
11. Tests in `config_test.go` (table-driven, `t.TempDir()`, `t.Setenv`):
    - `TestDirHonorsEnv`: `AJENT_CONFIG_DIR` set to `<tmp>/x` returns that path and creates it. On unix it asserts mode 0700.
    - `TestDirRefusesSymlink`: skip on Windows. Point the env var at a symlink to a directory and expect `errors.Is(err, ErrSymlink)`.
    - `TestWritePrivateAtomicReplace`: write "a", then "b". The content is "b", no `.ajent-*` files remain, and on unix the mode is 0600.
    - `TestWritePrivateRefusesSymlink`: skip on Windows.
    - `TestCreateExclusive`: the first call succeeds. The second returns an error with `errors.Is(err, fs.ErrExist)` and the content is unchanged.
    - `TestReadPrivateRefusesSymlink`: skip on Windows.
    - `TestJSONRoundTrip`: covers `WriteJSON` output and the trailing newline.
12. Tests in `lock_test.go`:
    - `TestLockExclusionAcrossProcesses` uses the helper-process pattern: `os.Args[0]` with `-test.run=TestLockHelper` and the env var `AJENT_LOCK_HELPER=<path>`. The helper acquires the lock, prints `locked`, then sleeps 2s. The parent waits for `locked`, then `Acquire(path, 200*time.Millisecond)` must return `ErrLockTimeout`. After the helper exits, `Acquire(path, time.Second)` succeeds.
    - `TestLockHelper` returns immediately unless `AJENT_LOCK_HELPER` is set.
    - `TestLockReleaseTwice`.
13. Run `gofmt -w internal/config`, then `go vet ./internal/config/`, then `GOOS=windows go vet ./internal/config/` and `GOOS=darwin go vet ./internal/config/`.

### Acceptance criteria

- `go test ./internal/config/... -race -count=1` passes locally. CI passes on ubuntu, macos and windows.
- `GOOS=windows go build ./internal/config/` succeeds.
- Genuine-red check 1: temporarily remove the non-blocking flag from `tryLock` (unix) so a held lock blocks. Run `go test ./internal/config -run TestLockExclusionAcrossProcesses -timeout 30s` and observe it fail (timeout or wrong result). Restore it and report both outputs.
- Genuine-red check 2: temporarily remove the symlink check in `ReadPrivate`, then observe `TestReadPrivateRefusesSymlink` fail. Restore and report.
- No dependency other than the standard library and `golang.org/x/sys`.
