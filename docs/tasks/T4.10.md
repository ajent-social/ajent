## T4.10: Implement the ajent login command

### Objective

`ajent login` asks the service for a single-use browser sign-in URL with the root credential and prints it. `ajent login --open` also opens it in the default browser. The browser is launched with an argument vector, never through a shell, and only for an `https` URL on the credential's origin.

### Read first

- docs/interfaces.md `internal/cli`, `internal/api`, `internal/credentials`
- docs/contract.md: `POST /v1/browser-login` request and response (`url`)
- docs/adr/006-client-trust-boundaries.md

### Scope

- `cmd/ajent/cmd_login.go` (create)
- `cmd/ajent/cmd_login_test.go` (create)

### Out of scope

- The MCP `ajent_login` tool (T3.5).
- Human passkeys or recovery codes. Never read or print them.

### Steps

1. Register `login` (summary "Print a short-lived link to sign in to Ajent in your browser") with the flag `--open bool`.
2. `root, err := credentials.LoadRoot(env.ConfigDir)`. If the file is missing, return `credentials.ErrNoCredential`.
3. `env.API.Do(ctx, root, api.Request{Method: "POST", Route: "/v1/browser-login", Body: map[string]any{}}, &out)`, where `out` is `struct{ URL string`json:"url"`}`.
4. Validate with `url.Parse(out.URL)`. The scheme must be `https`, or `http` only when the credential origin is loopback http. The scheme and host must equal the credential's server origin, taking the scheme and host from `root.Server`. Otherwise return `errors.New("login: the service returned an unexpected link")`.
5. Print `out.URL` and a newline to `env.Stdout`. Print nothing else to stdout.
6. With `--open`, call `openBrowser(ctx, u string) error` through a package variable `var browserCommand = defaultBrowserCommand` that returns `(name string, args []string)`:
   - darwin: `open`, `[u]`
   - windows: `rundll32`, `["url.dll,FileProtocolHandler", u]`
   - otherwise: `xdg-open`, `[u]`
   Run it with `exec.CommandContext(ctx, name, args...).Start()` and do not wait. If it fails, print `Could not open a browser; open the link above.` to `env.Stderr` and still return nil.
7. Tests use the fakeserver with `AJENT_URL` set, a temp config with a root credential, and `browserCommand` replaced by a recorder:
   - `TestLoginPrintsURL`: stdout is exactly `<url>\n`. The request is `POST /v1/browser-login`, body `{}`, with a Bearer header.
   - `TestLoginOpen`: the recorder gets the per-GOOS name and args, with the URL as a single argv element.
   - `TestLoginRejectsForeignURL`: the server returns `https://evil.example/x`, giving exit 1 and nothing opened.
   - `TestLoginNoCredential`: exit 1, and stderr mentions `ajent setup`.
   - `TestLoginURLWithShellMetacharacters`: the URL `<origin>/l?a=1&b=$(x)` is passed unchanged as one argv element.

### Acceptance criteria

- All tests pass with `-race` on all three OSes.
- Genuine-red: remove the origin check, then observe `TestLoginRejectsForeignURL` fail. Restore and report both outputs.
- stdout never contains the token (assert this in `TestLoginPrintsURL`).

### Verification

- `go test ./cmd/ajent -run TestLogin -race -count=1 -v`
- `go vet ./cmd/ajent`
- `GOOS=windows go vet ./cmd/ajent`
