## T4.3: Implement enrollment and human linking in ajent setup

### Objective

`ajent setup` turns a fresh machine into a connected installation:

1. It creates a pending root credential exclusively.
2. It links the installation to a human account through browser approval.
3. It completes signup.
4. It configures scope and integrations through hooks.
5. It prints next steps.

`ajent link` runs only the linking step. Reruns reuse the existing identity and never sign up twice. An interrupted run can be resumed.

### Steps

1. `internal/setup/hooks.go`:

   ```go
   // ConfigureScope writes user or project scope settings. T2.13 assigns it from cmd/ajent/wire_scope.go.
   // When nil, setup prints a hint to run `ajent configure` and continues.
   var ConfigureScope func(ctx context.Context, env *cli.Env, root credentials.Credential, scope, domain string, private bool) error
   // Integrate configures detected coding tools. T4.6 assigns it. When nil, setup skips integrations.
   var Integrate func(ctx context.Context, env *cli.Env) error
   // PreSetup runs before enrollment, in order. T4.9 appends the migration offer.
   var PreSetup []func(ctx context.Context, env *cli.Env, opts Options) error

   var (
       pollInterval = 2 * time.Second
       linkTimeout  = 10 * time.Minute
       sleep        = func(ctx context.Context, d time.Duration) error { /* select on ctx.Done and time.After */ }
   )
   ```

2. Define `Options` exactly as in docs/interfaces.md.
3. `Run(ctx, env, opts)` in `setup.go` does these steps in order:
   1. Run each `PreSetup` function. Return its error if non-nil.
   2. `origin, err := api.Origin()`.
   3. Call `dir, err := env.Dir()` and return any error, so the config directory exists before the exclusive create. Build `c := credentials.Credential{Server: origin, Token: tok, Handle: handle, Pending: true}`. Set `tok` from `credentials.NewToken()`. Set `handle` to `opts.Handle`, or `"agent-" + hex(4 random bytes)` when empty. Then `credentials.CreateRoot(env.ConfigDir, c)`. If `errors.Is(err, fs.ErrExist)`, set `c, err = credentials.LoadRoot(env.ConfigDir)` instead. Never overwrite an existing credential.
   4. If `!api.Trusted(c.Server)`, return `errors.New("setup: the saved credential belongs to another server; use a separate AJENT_CONFIG_DIR")`.
   5. If `!opts.AgentOnly && !c.HumanLinked`: `linked, err := Link(ctx, env, opts, c)`. On error, return it. If `!linked`, return nil (the `--no-wait` path). Otherwise reload `c` with `LoadRoot`.
   6. If `c.Pending`: `POST /v1/signup` (Decision: never after a completed link, because Link clears `Pending`; in practice only the `--agent-only` path or a legacy pending credential signs up) with body `{"token": c.Token, "handle": c.Handle, "name": c.Handle}` and no Idempotency-Key. Decode the response into `map[string]json.RawMessage`. Merge it into `c` by marshaling `c`, overlaying the response keys, and unmarshaling back, so unknown keys land in `Extra`. Set `c.Pending = false` and `SaveRoot`. If not pending, `GET /v1/me` to confirm access.
   7. `GET /v1/me` into `struct{ Handle string`json:"handle"`}`.
   8. Decide whether to configure scope. Configure when `opts.Scope != "" || opts.Domain != "" || opts.Private`, or when neither `<ConfigDir>/config.json` nor `<projectRoot>/.aj/config.json` exists (`projectRoot = credentials.ProjectRoot(env.Cwd, env.Home)`). When configuring: if `ConfigureScope != nil`, call it with `(scopeOrUser, opts.Domain, opts.Private)`, where `scopeOrUser` is `opts.Scope` or `"user"` when empty. Otherwise print `Choose a sharing scope later with: ajent configure` to `env.Stdout`.
   9. If `Integrate != nil`, call it and return its error.
   10. Print these lines to `env.Stdout`, in order:
       - `Connected as <handle>. Existing credentials are reused on rerun.`
       - `Credential saved privately to <credentials.RootPath(env.ConfigDir)>`
       - `Try: ajent me`
       - `Ask your agent: Search Ajent for findings relevant to this task.`
       - `Ask your agent: Log me into Ajent. Or run: ajent login`
       - `No project files or posts were uploaded. Posts expire after 30 days by default.`
   If docs/contract.md records different wording for the equivalent Python lines, keep this wording. These lines are the Go product's copy.
4. `Link(ctx, env, opts, root)` in `link.go`:
   1. `GET /v1/installations/link` with the root credential into `state` (`map[string]any`). If it returns an `*api.Error` with `Status` 404 or 410, treat the state as nil. Return any other error.
   2. If `!root.HumanLinkPending || state == nil || state["status"] != "approved"`:
      - `name := opts.Handle`. If it is empty, use `root.Handle`. If that is also empty, use `"installation-" + hex(sha256(root.Token))[:8]`.
      - `POST /v1/installations/link` with body `{"handle": name, "project_scope": credentials.ProjectScope(projectRoot)}` into `link` (`struct{ URL string`json:"url"`; Code string`json:"code"`}`).
      - Set `root.HumanLinkPending = true` and `SaveRoot`.
      - Print `Sign in as yourself and approve this installation: <url>` and then `Compare code: <code>`.
      - If `opts.NoWait`: print `After approval, rerun ajent setup to finish linking.` and return `false, nil`.
      - Print `Waiting for browser approval (up to ten minutes)...`.
      - Loop until `linkTimeout` elapses (measure with `env.Now`): call `sleep(ctx, pollInterval)`, returning ctx errors. Then `GET /v1/installations/link` again. On `status == "approved"`, break. Any other status keeps polling. Any request error during polling (including 404 and 410, which are tolerated only in the first GET) is returned unchanged and keeps `HumanLinkPending`. Decision: Go keeps the reference's two outcomes, approved or timeout; there are no `denied` or `expired` statuses (docs/contract.md section 2). After the deadline, return `errors.New("setup: approval timed out; run ajent setup again")` and keep `HumanLinkPending` so the next run resumes.
   3. On approval, read `agent_id` (into `AgentID`) and `credential_id` (into `CredentialID`) from the state. Set `HumanLinked = true`, `Pending = false` and `HumanLinkPending = false`, then `SaveRoot`.
   4. Set `approved := state["scope"]`, defaulting to `"user"`. If it is neither `"user"` nor `credentials.ProjectScope(projectRoot)`, return `errors.New("setup: this approval belongs to a different project; run ajent link there")`.
   5. If `ConfigureScope != nil`, call it with `scope = "user"` when approved is `"user"` (otherwise `"project"`), `domain = state["domain"]` (a string, "" if missing) and `private = domain == ""`.
   6. Print `Installation linked. Your human login is separate from all agent credentials.` and return `true, nil`.
5. `cmd/ajent/cmd_setup.go` (package main): parse flags with a `flag.FlagSet`: `--handle string`, `--no-wait bool`, `--agent-only bool`, `--scope string` (only "", "user" or "project", otherwise usage error), `--domain string` and `--private bool`. Register three commands:
   - `setup`: summary "Connect this machine and configure your coding tools".
   - `install`: `Hidden: true`, same Run.
   - `link`: summary "Link this installation to your human account". It loads the root credential (return `credentials.ErrNoCredential` if absent) and calls `setup.Link`.
6. Tests use `internal/testutil/fakeserver`, with `AJENT_URL` set to the fake URL through `t.Setenv`, `t.TempDir()` for the config dir, cwd and home, and a fake `env.Now`. Set `pollInterval = time.Millisecond` and `linkTimeout = 50*time.Millisecond`, restoring both with `t.Cleanup`. In `setup_test.go`:
   - `TestSetupApprovePath`: the first link GET returns 404. The POST returns url and code. The second GET returns `approved` with agent_id and credential_id. After Run, credential.json has `human_linked: true`, no `pending`, and the approved agent_id. Stdout contains the URL, the code and all six final lines. No `/v1/signup` request is made (linking cleared pending).
   - `TestSetupAgentOnlySignup`: with `AgentOnly: true`, exactly one `POST /v1/signup` whose JSON body has keys `token`, `handle` and `name`, then `GET /v1/me`. credential.json has no `pending`.
   - `TestSetupRerunReusesIdentity`: run the agent-only path twice. The token is unchanged. There is exactly one signup request across both runs.
   - `TestSetupNoWait`: `NoWait: true` prints the URL and the rerun hint and returns nil. credential.json has `human_link_pending: true`. A second Run with the server now approving completes without a second POST link.
   - `TestSetupPollErrorFails`: the first GET returns 404, the POST succeeds, and the next polling GET returns 500. Run returns an `*api.Error` with status 500 after exactly one polling request (no retry), and `human_link_pending` stays true.
   - `TestSetupUnknownStatusKeepsPolling`: polling returns `{"status":"denied"}` twice, then `approved`. Run links successfully; no status other than `approved` ends the loop.
   - `TestSetupTimeout`: polling always returns `pending`. Run returns the timeout error. `human_link_pending` stays true.
   - `TestSetupContextCancel`: cancel ctx during polling. Run returns `context.Canceled`, and credential.json still exists with the same token.
   - `TestSetupHooks`: set `ConfigureScope` and `Integrate` to recording fakes. Both are called once with the expected arguments. Set `PreSetup` to a function returning an error. Run returns that error before any HTTP request.
   - `TestSetupRefusesForeignServer`: pre-write a credential with `server: https://example.invalid`. Run returns the other-server error.
7. `link_test.go`: `TestLinkWrongProjectScope`: approval with `scope: "project:deadbeef"` returns the different-project error.

### Acceptance criteria

- All tests pass with `-race`.
- Genuine-red: temporarily replace `CreateRoot` with `SaveRoot` in step 3.3 and observe `TestSetupRerunReusesIdentity` fail (a new token, or a second signup). Restore and report both outputs.
- Genuine-red: temporarily remove the `SaveRoot` that persists `HumanLinkPending = true` and observe `TestSetupNoWait` fail. Restore.
- No output line contains the token. Add the assertion `!strings.Contains(stdout, token)` to `TestSetupApprovePath`.
