## T6.1: Detect the install method

### Objective

`update.Detect(executable, configDir)` classifies how the running binary was installed, so that `ajent update` knows whether to replace itself or tell the user which package manager command to run. `update.UpgradeCommand(method)` returns that command. The classification is correct on fixture paths for macOS, Linux and Windows.

### Read first

- docs/adr/005-upgrade-strategy.md
- docs/interfaces.md, section "internal/update" (`Method`, the constants, `Detect`, `UpgradeCommand`)
- docs/tasks/T5.9.md step 2.9 (the `install.json` format written by the install scripts)

### Scope

Create only:

- `internal/update/detect.go`
- `internal/update/detect_test.go`

### Out of scope

- Other files in `internal/update`. Any CLI command.

### Steps

1. In `detect.go`, declare the `Method` type and its constants exactly as in docs/interfaces.md. Add these package-level seams, all unexported so tests can override them:
   - `var goos = runtime.GOOS`
   - `var dpkgInfoDir = "/var/lib/dpkg/info"`
   - `var runCmd = func(name string, args ...string) ([]byte, error) { return exec.Command(name, args...).Output() }`
   - `var getenv = os.Getenv`
   - `var evalSymlinks = filepath.EvalSymlinks`
2. `func Detect(executable, configDir string) Method`. Resolve `exe, err := evalSymlinks(executable)`, falling back to `executable` on error, and apply `filepath.Clean`. For Windows comparisons, work on `strings.ToLower(filepath.ToSlash(exe))`. Apply these rules in order and return the first match:
   1. **Script.** Read `filepath.Join(configDir, "install.json")` (tolerate absence) and decode `{"method": string, "path": string}`. If `method == "script"` and `evalSymlinks(path)` (fallback `path`) cleans to the same path as `exe` (case-insensitive on windows), return `MethodScript`.
   2. **Homebrew.** The slash-form path contains `/cellar/ajent/`, `/caskroom/ajent/`, `/Cellar/ajent/` or `/Caskroom/ajent/`. Use case-insensitive matching for these segments on darwin and linux too, because Homebrew paths are capitalized.
   3. **dpkg**, when `goos == "linux"`. If `exe == "/usr/bin/ajent"` and `filepath.Join(dpkgInfoDir, "ajent.list")` exists and has a line exactly `/usr/bin/ajent`, return `MethodDpkg`.
   4. **rpm**, when `goos == "linux"`. If `exe == "/usr/bin/ajent"` and `runCmd("rpm", "-qf", "--queryformat", "%{NAME}", "/usr/bin/ajent")` returns exactly `ajent` with a nil error, return `MethodRPM`.
   5. **Scoop**, when `goos == "windows"`. The lowercase slash path contains `/scoop/apps/ajent/`, or `/scoop/shims/` combined with the file name `ajent.exe`.
   6. **winget**, when `goos == "windows"`. The lowercase slash path contains `/microsoft/winget/packages/ajentsocial.ajent` or `/microsoft/winget/links/`.
   7. **go install.** Let `gobin := getenv("GOBIN")`. If that is empty, use `filepath.Join(getenv("GOPATH"), "bin")` when `GOPATH` is set, else `filepath.Join(home, "go", "bin")` with `home` from `os.UserHomeDir()`. If `filepath.Dir(exe)` equals `gobin`, return `MethodGoInstall`.
   8. Otherwise return `MethodUnknown`.
3. `func UpgradeCommand(m Method) string` returns exactly:
   - homebrew: `brew upgrade ajent`
   - dpkg: `sudo apt update && sudo apt install --only-upgrade ajent`
   - rpm: `sudo dnf upgrade ajent`
   - scoop: `scoop update ajent`
   - winget: `winget upgrade --id AjentSocial.Ajent --exact`
   - go-install: `go install github.com/ajent-social/ajent-client/cmd/ajent@latest`
   - script and unknown: `""`
4. Add `func (m Method) Managed() bool`, which returns true for homebrew, dpkg, rpm, scoop, winget and go-install. Also add `func (m Method) Label() string` for human messages: `Homebrew`, `APT`, `DNF`, `Scoop`, `winget`, `go install`, `the install script`, `an unknown method`.
5. `detect_test.go`: the table test `TestDetect` overrides the seams and uses `t.TempDir()` for `configDir` and `dpkgInfoDir`. Cases, with the expected method:
   - `script-matching-path` (install.json path equals exe): script
   - `script-json-other-path`: unknown
   - `script-json-symlink` (install.json path is a symlink to exe; create real symlinks and skip on windows when symlinks are not permitted): script
   - `brew-cellar-arm` `/opt/homebrew/Cellar/ajent/0.7.0/bin/ajent`: homebrew
   - `brew-caskroom` `/opt/homebrew/Caskroom/ajent/0.7.0/ajent`: homebrew
   - `brew-intel-symlink` (exe `/usr/local/bin/ajent`, with evalSymlinks mapping it to `/usr/local/Caskroom/ajent/0.7.0/ajent`): homebrew
   - `dpkg-owned` (goos linux, list file containing `/usr/bin/ajent`): dpkg
   - `dpkg-list-missing-rpm-owned` (runCmd returns `ajent`): rpm
   - `usr-bin-unowned` (runCmd returns an error): unknown
   - `scoop-app` `C:\Users\u\scoop\apps\ajent\current\ajent.exe` (goos windows): scoop
   - `winget-package` `C:\Users\u\AppData\Local\Microsoft\WinGet\Packages\AjentSocial.Ajent_Microsoft.Winget.Source_8wekyb3d8bbwe\ajent.exe`: winget
   - `winget-link` `C:\Users\u\AppData\Local\Microsoft\WinGet\Links\ajent.exe`: winget
   - `go-install-gobin` (GOBIN set): go-install
   - `go-install-gopath`: go-install
   - `unknown-path` `/tmp/x/ajent`: unknown
   Use `filepath.FromSlash` for unix paths, and raw backslash strings for windows cases. Detection lowercases and converts slashes itself, so the windows-path cases also run on unix hosts: set the `goos` seam to `"windows"`.
   Also add `TestUpgradeCommand` (every method) and `TestManaged`.

### Acceptance criteria

- `go test ./internal/update -run 'TestDetect|TestUpgradeCommand|TestManaged' -race -count=1` passes on ubuntu, macos and windows CI.
- `GOOS=windows go vet ./internal/update/` and `golangci-lint run ./internal/update/...` are clean.
- Genuine-red: swap the order of rules 1 and 2 so Homebrew matches first, and add the case `script-in-brew-like-path` (install.json path `/opt/homebrew/Cellar/ajent/x/ajent` with method script) expecting script. Observe it fail with homebrew, restore the order, and report both outputs. Keep the new case.

- `GOOS=windows go vet ./internal/update/`
