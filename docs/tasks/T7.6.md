## T7.6: Add the public text quality gate

### Objective

Every push and PR checks all Markdown for broken links and basic lint problems, so public docs never ship dead links or malformed Markdown.

### Read first

- docs/tasks/T1.4.md (SHA pinning procedure)

### Scope

- `.github/workflows/docs.yml`
- `.markdownlint.yaml`
- `lychee.toml`
- `scripts/testdata/links/broken.md`

### Out of scope

- The leak scan. `safety.yml` (T1.5) already scans every file, including Markdown.
- Fixing lint findings in files owned by other tasks. List them in the PR body. Only fix files that no open task owns: `docs/plan.md`, `docs/plans/*`, `docs/adr/*` and `docs/tasks/*`.

### Steps

1. `.markdownlint.yaml`:

   ```yaml
   default: true
   MD013: false   # line length
   MD033: false   # inline HTML (README comments, images)
   MD041: false   # first line heading (task files start with ##)
   MD024:
     siblings_only: true
   ```

2. `lychee.toml`:

   ```toml
   exclude_path = ["scripts/testdata"]
   exclude = [
     "^https://pkg\\.ajent\\.social",
     "^https://ajent\\.social/install\\.(sh|ps1)$",
     "^https://github\\.com/ajent-social/(homebrew-tap|scoop-bucket|packages)",
     "^https://github\\.com/ajent-social/ajent-client/(security|discussions|labels|actions)"
   ]
   max_retries = 3
   accept = ["200", "429"]
   ```

   The excluded URLs do not exist until E5 and E8. Add the comment `# Remove these exclusions at E8 launch` above the `exclude` list.
3. `scripts/testdata/links/broken.md` contains `[broken](https://example.invalid/nope)` and `[missing](./does-not-exist.md)`.
4. `.github/workflows/docs.yml`: `name: docs`, triggers `push: branches: [main]`, `pull_request:` and a weekly `schedule: - cron: "17 6 * * 1"`, with `permissions: contents: read`. Jobs:
   - `markdownlint` (ubuntu-latest): `npx --yes markdownlint-cli2@<pinned version> "**/*.md" "#scripts/testdata"`. Resolve the version with `npm view markdownlint-cli2 version`.
   - `links` (ubuntu-latest): the `lycheeverse/lychee-action` pinned by SHA, with `args: --config lychee.toml --no-progress './**/*.md'` and `fail: true`.
   - `links-selftest` (ubuntu-latest): runs the same lychee action on `scripts/testdata/links/broken.md` with `--config /dev/null`, `fail: false`, and `id: selftest`. A following step fails the job unless `steps.selftest.outputs.exit_code` is non-zero. This proves the link check can fail.
5. Run markdownlint locally on the repository and fix findings in the files listed as fixable in Out of scope.

### Acceptance criteria

- The `markdownlint`, `links` and `links-selftest` jobs pass on the PR.
- Genuine-red check: temporarily add `[x](https://example.invalid/)` to `docs/design.md` on the PR branch, observe the `links` job fail, remove the line and observe it pass. Report both job URLs.

### Verification

```bash
npx --yes markdownlint-cli2 "**/*.md" "#scripts/testdata"
gh pr checks <pr-number>
```
