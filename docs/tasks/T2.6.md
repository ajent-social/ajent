## T2.6: Build the CLI dispatcher

### Objective

`ajent` has a real command framework. Commands register themselves from separate files, so parallel tasks never collide. `ajent help` lists them. Exit codes and stderr formats are fixed: 0 for success, 1 for a runtime error with `ajent: ...`, and 2 for a usage error. `cmd/ajent/main.go` builds the environment and dispatches.

Create or modify exactly these files:

- Profile enrollment wiring (T3.6 adds `cmd/ajent/wire_profiles.go`).

### Steps

1. Add these exported identifiers to `internal/cli`. They are already declared in docs/interfaces.md:
   - `Command.Aliases []string`
   - `Command.Usage string` (one line, for example `ajent search [--group UUID] QUERY...`)
   - `Env.OpenTTY func() (io.ReadWriteCloser, error)`
   - `func (e *Env) Credential(ctx context.Context, profile string) (credentials.Credential, error)`: returns `credentials.ErrNoCredential` when `Resolve` is nil, and otherwise returns `e.Resolve(ctx, profile)`.
   - `func DefaultEnv() (*Env, error)`
   - `func PrintRawJSON(w io.Writer, raw []byte) error`
   - `func AddField(raw []byte, key string, value any) ([]byte, error)`
2. `Register(c Command)` panics if the name or any alias is already registered. This is a programming error caught by tests. Store the commands in a package map, and look up aliases through a second map.
3. `Commands()` returns the non-hidden commands sorted by `Name`.
4. `Main(ctx, env, args) int`:
   - With no args, or with `-h`, `--help` or `help`, print the usage listing to `env.Stdout` and return 0. The listing is `Usage: ajent <command> [flags]`, a blank line, then each command as `<name padded to 14>  <Summary>`, then `Run 'ajent help <command>' for details.`
   - Look up `args[0]`, including aliases. When it is unknown, print `ajent: unknown command "<x>"` and the usage listing to `env.Stderr`, and return 2.
   - Call `Run(ctx, env, args[1:])`. A nil error returns 0.
   - When `errors.Is(err, ErrUsage)` or `errors.Is(err, flag.ErrHelp)`, return 2. `ErrHelp` has already been printed by the FlagSet. For `ErrUsage`, print `ajent: <err text without the "usage" sentinel>` and `Usage: <Usage>` to stderr.
   - Otherwise return 1 and print one line to stderr. If `errors.As(err, &apiErr)` with `apiErr *api.Error`, print `apiErr.Error()`, which already reads `ajent: <code>. <action>`. Otherwise, if `err.Error()` already starts with `ajent:`, print it unchanged. Otherwise print `ajent:` plus `err.Error()`.
5. Commands build their own `flag.NewFlagSet(name, flag.ContinueOnError)` with `SetOutput(env.Stderr)`. Document this convention in a package comment in `cli.go`, along with the shared flag names that later tasks must reuse exactly:
   - `--profile` (string, default `terminal`)
   - `--project-profile` (bool)
   - `--json` (string, default `{}`, structured arguments, not an output switch)
   - `--key`
   - `--group`
6. `output.go`:
   - `PrintJSON` uses `json.MarshalIndent(v, "", "  ")` plus a newline.
   - `PrintRawJSON` uses `json.Indent` with a two-space indent on `raw`, preserving key order, plus a newline.
   - `AddField` requires `raw` to be a JSON object once trimmed. It inserts `,"key":<marshal(value)>` before the final `}`, or `"key":...` when the object is empty. It returns an error when `raw` is not an object.
7. `env.go`, `DefaultEnv()` fills in:
   - `Stdin`, `Stdout` and `Stderr` from `os`
   - `Getenv` as `os.Getenv`
   - `Cwd` from `os.Getwd`
   - `Home` from `os.UserHomeDir`
   - `ConfigDir` as `$AJENT_CONFIG_DIR` (after `filepath.Clean`) or `<Home>/.aj`. `DefaultEnv` never creates the directory, so `ajent version` and `ajent help` have no side effects. Read-only code may use `env.ConfigDir` directly; any code that writes under it calls `env.Dir()` first
   - `API` as `&api.Client{}`
   - `IsTerminal` from the tty file
   - `Now` as `time.Now`
   - `OpenTTY`, which opens `/dev/tty` with `os.OpenFile(path, os.O_RDWR, 0)` on unix, or `CONIN$` for reading plus `CONOUT$` for writing, combined into one ReadWriteCloser, on Windows

   Add the helper `func (e *Env) Dir() (string, error)`: when `ConfigDir` is empty, set it from `config.Dir()`; then call `config.EnsurePrivateDir(ConfigDir)` (creates it with 0700, refuses a symlink) and return it. It is already declared in docs/interfaces.md. `internal/cli` imports `internal/api`, `internal/credentials` and `internal/config`, and no other internal package.
8. `tty_unix.go` and `tty_windows.go`: `isTerminal(fd uintptr) bool` uses `golang.org/x/sys/unix.IoctlGetTermios(int(fd), unix.TIOCGETA or TCGETS)` (build-tagged per OS: darwin uses `TIOCGETA`, linux uses `TCGETS`), and `windows.GetConsoleMode` on Windows. Split the unix file into `tty_darwin.go` and `tty_linux.go` if needed, and list the actual files in the PR.
9. `cmd/ajent/main.go`:
   - Declare the package-level `var wire []func(*cli.Env)`, with a comment above it: later tasks add wiring only by appending from their own `cmd/ajent/wire_*.go` `init()` functions, and never edit main.go.
   - `main()` builds `env, err := cli.DefaultEnv()`. On error, print `ajent: <err>` to stderr and exit 1.
   - For each `w` in `wire`, call `w(env)`.
   - `os.Exit(cli.Main(context.Background(), env, os.Args[1:]))`.
10. `cmd_version.go` registers `version`, with the flag `--json` as a bool (the one exception, documented in the command Usage). It prints `ajent <Version> (<Commit>, <Date>)`, or `version.Get()` as JSON.
11. `cmd_help.go` registers `help`. `ajent help <cmd>` prints `Usage: <Usage>`, the Summary, and the command's flag defaults. To get the flag defaults, each command must expose them: use the optional `Command.Flags func() *flag.FlagSet` field (declared in docs/interfaces.md) returning a fresh FlagSet with the definitions. When it is nil, print only Usage and Summary. An unknown command returns exit 2.
11a. `cmd/ajent/helpers.go` provides the command helpers that T2.7 to T2.11 reuse, so those tasks run in parallel:

- `func profileFlags(fs *flag.FlagSet) *string` defines `--profile` (default `terminal`) and returns it. It also defines `--project-profile` as a bool that is accepted and ignored, because the CLI always applies the project hash (contract section 3).
- `func toolCredential(ctx context.Context, env *cli.Env, base string) (credentials.Credential, error)`: `root := credentials.ProjectRoot(env.Cwd, env.Home)`, `name := credentials.ProjectProfile(base, root)`. When `!credentials.ValidProfile(name)`, return `credentials.ErrInvalidProfile`. Otherwise return `env.Credential(ctx, name)`.
- `func rootCredential(env *cli.Env) (credentials.Credential, error)`: `dir, err := env.Dir()`, then `credentials.LoadRoot(dir)`.
- `func getAndPrint(ctx context.Context, env *cli.Env, cred credentials.Credential, route string) error`: GET into a `json.RawMessage`, then `cli.PrintRawJSON`.
- `func sendAndPrint(ctx context.Context, env *cli.Env, cred credentials.Credential, r api.Request) error`: `Do` into a `json.RawMessage`, then `cli.PrintRawJSON`.
- `func jsonArgs(s string) (map[string]any, error)` decodes an object with `UseNumber`. Anything that is not an object returns `errors.New("--json must be a JSON object")`.
- `helpers_test.go` has `TestToolCredentialHashesProfile` and `TestJSONArgs`.

 1. Do not edit go.mod or go.sum: `golang.org/x/sys` is already required after T2.2 (see docs/tasks/OWNERSHIP.md). Dependencies: this task imports `internal/config` (T2.2), `internal/api` (T2.4) and `internal/credentials` (T2.12 for the type, T2.3 for `ProjectRoot`, `ProjectProfile` and `LoadRoot`). All three must be merged before you start. Do not create placeholder packages. If any is missing, stop and report BLOCKED.
 2. Tests:
    - `internal/cli/cli_test.go`, run with a fresh registry per test through an unexported `reset()` helper used only in tests:
      - `TestUnknownCommandExit2`
      - `TestUsageErrorExit2`
      - `TestRuntimeErrorExit1Format`: an error `errors.New("boom")` prints `ajent: boom`. An error whose text already starts with `ajent:` is not double-prefixed.
      - `TestAliasDispatch`
      - `TestDuplicateRegisterPanics`
      - `TestHelpListsCommandsSorted`
      - `TestCredentialNilResolve` returns `credentials.ErrNoCredential`.
    - `internal/cli/output_test.go`:
      - `TestPrintRawJSONKeepsOrder` with input `{"b":1,"a":{"d":2,"c":3}}`
      - `TestAddField` covers an object, an empty object and a non-object error.
    - `cmd/ajent/main_test.go`: build the binary once in `TestMain` with `go build -o <tmp>/ajent .`, then exec it:
      - `TestBinaryVersion` (exit 0, stdout starts with `ajent`)
      - `TestBinaryUnknown` (exit 2, stdout empty, stderr contains `unknown command`)
      - `TestBinaryHelp` (stdout lists `version` and `help`)
    - `cmd/ajent/testenv_test.go`: every command task reuses this helper and must not modify it. It contains:
      - `func newTestEnv(t *testing.T, srv *fakeserver.Server) (env *cli.Env, stdout, stderr *bytes.Buffer, profiles func() []string)`. It returns an Env with buffers, `Cwd` and `Home` set to fresh temp dirs, `ConfigDir` set to `t.TempDir()`, `API` set to `&api.Client{Sleep: func(time.Duration) {}}`, `Now` set to a fixed time `2026-01-01T00:00:00Z`, `IsTerminal` always false, `OpenTTY` returning an error, and `Resolve` returning `srv.Credential()` for any profile. `Resolve` also appends each requested profile name to a slice, and the returned `profiles()` closure returns a copy of that slice.
      - `func run(t *testing.T, env *cli.Env, args ...string) int` calls `cli.Main(context.Background(), env, args)`.
      - `func writeRoot(t *testing.T, env *cli.Env, c credentials.Credential)` writes `c` as JSON to `<ConfigDir>/credential.json` with mode 0600. It uses `os.WriteFile`, because `credentials.SaveRoot` belongs to T2.3.
