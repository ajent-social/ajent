## T5.13: Rehearse every channel against locally served snapshot artifacts

### Objective

Before the repository goes public, one manually dispatched workflow, `rehearsal.yml`, proves the whole distribution chain end to end without publishing anything. It builds a snapshot, signs it with an ephemeral key, serves it locally on each runner, and installs through install.sh, install.ps1, a locally built signed APT/DNF repository, the rendered Homebrew cask and the rendered Scoop manifest. It validates the winget manifests and runs the upgrade end-to-end test. Every job must be green.

### Read first

- docs/tasks/T5.2.md, T5.3.md (keygen: `.seed`, `.pub`, `.pem`), T5.5.md, T5.6.md, T5.7.md (`build-repo.sh`, `test-repo.sh`), T5.8.md (`test-scoop.ps1`), T5.9.md (`test-install.sh`, `test-install.ps1`), T6.8.md
- docs/adr/003-distribution-channels.md

### Scope

Create:

- `.github/workflows/rehearsal.yml`
- `scripts/rehearse-cask.sh`
Append a dated entry to `docs/devlog.md` with the run URL and findings (create the file if it does not exist, using the heading `# Devlog`, newest entries first).

### Out of scope

- Publishing to any real channel, tap, bucket or site. Fixes to the channel tasks (file issues and report them).

### Steps

1. `rehearsal.yml`: `on: workflow_dispatch`, `permissions: contents: read`. A job `build` on ubuntu:
   1. Run `go run ./internal/tools/signchecksums -keygen "$RUNNER_TEMP/k"`.
   2. Run the GoReleaser snapshot with `--skip=notarize,publish` and env `RELEASE_ED25519_KEY=$(cat $RUNNER_TEMP/k.seed)`, so the signs step runs with the ephemeral key.
   3. Build test binaries that trust the key: for each target used later (`linux/amd64`, `darwin/arm64`, `windows/amd64`), run `go build -ldflags "-X github.com/ajent-social/ajent/internal/update.extraKeyB64=$(cat $RUNNER_TEMP/k.pub) -X github.com/ajent-social/ajent/internal/version.Version=<snapshot version>"`. Repack them into the archive names GoReleaser uses, and regenerate and re-sign `checksums.txt`. This keeps the `verify-release` checks working with the ephemeral key.
   4. Upload `dist/` plus `k.pub` and `k.pem` as an artifact named `rehearsal-dist`.
2. Jobs that download `rehearsal-dist`:
   - `script-unix` (ubuntu, macos): `sh scripts/test-install.sh dist <version>`.
   - `script-windows`: `pwsh -File scripts/test-install.ps1`.
   - `packages` (ubuntu): clone `ajent-social/packages` (public; no token needed). Build the site from `dist/*.deb` and `dist/*.rpm` with a throwaway GPG key, reusing the key-generation lines from its `scripts/test-repo.sh`. Serve it with `python3 -m http.server`, then install in `debian:stable`, `ubuntu:24.04` and `fedora:latest` containers with signature checking on, and assert the version.
   - `brew` (macos): `sh scripts/rehearse-cask.sh`. It copies the rendered cask, rewrites its URLs to `file://<abs dist path>/<archive>`, runs `brew install --cask ./ajent.rb`, asserts the version and uninstalls.
   - `scoop` (windows): `pwsh -File scripts/test-scoop.ps1 -Manifest <rendered> -DistDir dist`.
   - `winget` (windows): `winget validate --manifest <rendered dir>`.
   - `upgrade` (matrix of ubuntu, macos, windows): `go test ./test/e2e -run TestUpgrade -count=1` (from T6.8).
3. Job `summary` (`if: always()`): table of results. It fails if any job failed.
4. SHA-pin actions, run `actionlint`, and run `shellcheck scripts/rehearse-cask.sh`.
5. Dispatch it: `gh workflow run rehearsal.yml --ref main`. Wait for completion. If a job fails because of a channel task's defect, file a GitHub issue titled `rehearsal: <channel> <symptom>` with the log excerpt and report it. Do not change the channel task's files in this task.
6. Record the run URL, per-job results and issues filed in `docs/devlog.md`.

### Acceptance criteria

- `rehearsal.yml` completes with every job green. Report the run URL.
- `actionlint` and `shellcheck` pass.
- `docs/devlog.md` has a dated entry with the run URL.
- Genuine-red: dispatch once with an input `tamper: true` that appends a byte to the linux archive after signing. The `script-unix` ubuntu job and the `packages` checksum step fail. Report that run's URL next to the green one. Keep the input, defaulting to `false`.

### Verification

- `go run github.com/rhysd/actionlint/cmd/actionlint@latest .github/workflows/rehearsal.yml`
- `shellcheck scripts/rehearse-cask.sh`
- `gh run list --workflow rehearsal.yml --limit 2`
