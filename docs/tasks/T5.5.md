## T5.5: Publish the Homebrew tap

### Objective

Every release updates `Casks/ajent.rb` in `ajent-social/homebrew-tap`, so `brew install ajent-social/tap/ajent` installs the notarized binary on macOS (arm64 and amd64) and `brew upgrade` picks up new releases.

### Read first

- docs/adr/003-distribution-channels.md
- GoReleaser documentation: customization > homebrew_casks (introduced in v2.10, replacing `brews`)
- `.goreleaser.yaml` (the `homebrew_casks (T5.5)` marker block)
- docs/plan.md Appendix A (package description)

### Scope

Modify only `.goreleaser.yaml`, between `# ---- BEGIN homebrew_casks (T5.5) ----` and `# ---- END homebrew_casks (T5.5) ----`.
Create `scripts/check-cask.sh`.

### Out of scope

- Creating the tap repository or token (T5.0). Homebrew core submission (E9). Linux Homebrew. Linux users use apt, dnf or the install script.
- The release workflow env wiring (T5.11 passes `HOMEBREW_TAP_TOKEN`).

### Steps

1. Fill the marker block:

   ```yaml
   # ---- BEGIN homebrew_casks (T5.5) ----
   homebrew_casks:
     - name: ajent
       ids: [default]
       binaries: [ajent]
       repository:
         owner: ajent-social
         name: homebrew-tap
         branch: main
         token: "{{ .Env.HOMEBREW_TAP_TOKEN }}"
       directory: Casks
       homepage: https://ajent.social
       description: "Connect your coding agents to a shared, private workspace of checked findings through MCP."
       license: Apache-2.0
       commit_author:
         name: ajent-release-bot
         email: ajent-release-bot@users.noreply.github.com
       commit_msg_template: "ajent {{ .Tag }}"
       caveats: "Run `ajent setup` to connect your coding agents."
       skip_upload: auto
   # ---- END homebrew_casks (T5.5) ----
   ```

   `skip_upload: auto` skips prereleases. Check field names against the pinned GoReleaser version's documentation (for example `ids`, `binaries`, `commit_author`) and report any renames. Do not add a quarantine-removal hook. ADR 004 allows that only as the unsigned fallback, and the maintainer confirmed notarization.
2. Run a snapshot with publishing skipped (`goreleaser release --snapshot --clean --skip=sign,notarize,publish`). GoReleaser writes the rendered cask to `dist/homebrew/Casks/ajent.rb`. If the path differs in the pinned version, find it with `find dist -name ajent.rb`.
3. Create `scripts/check-cask.sh` (SPDX header, `set -eu`). It takes the cask path, asserts it contains `url "https://github.com/ajent-social/ajent-client/releases/download/` twice (arm and intel) and two `sha256 "` lines each 64 hex characters long, and asserts every sha256 in the cask appears in `dist/checksums.txt`. Exit 1 with a clear message on failure.
4. On a macOS machine or runner, run `brew style --cask dist/homebrew/Casks/ajent.rb`. If `brew style` requires the cask to be in a tap, create a local tap with `brew tap-new --no-git ajent-local/test`, copy the cask into its `Casks/` directory, and run `brew style ajent-local/test/ajent`. Remove the local tap afterwards with `brew untap ajent-local/test`.
5. Local install test on macOS (optional in CI, required once locally): edit a copy of the cask so its `url` points at `file://$PWD/dist/<darwin archive>`, then run `brew install --cask ./ajent.rb`, `ajent version`, and `brew uninstall --cask ajent`.

### Acceptance criteria

- `goreleaser check` exits 0.
- The snapshot renders a cask. `scripts/check-cask.sh dist/homebrew/Casks/ajent.rb` exits 0, and `brew style` reports no offenses.
- The local install test in step 5 prints the snapshot version.
- Genuine-red: change one sha256 digit in the rendered cask, run `scripts/check-cask.sh`, and observe exit 1. Restore it and report both outputs.

### Verification

- `go run github.com/goreleaser/goreleaser/v2@<GR> check`
- `go run github.com/goreleaser/goreleaser/v2@<GR> release --snapshot --clean --skip=sign,notarize,publish`
- `sh scripts/check-cask.sh "$(find dist -name ajent.rb | head -1)"`
- `shellcheck scripts/check-cask.sh`
