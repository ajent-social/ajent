## T4.6: Build backups, rollback, sync and integration commands

### Objective

Before any file outside `~/.aj` changes, ajent snapshots it into `~/.aj/backups/<id>/`. `ajent rollback <id>` restores the exact prior bytes and deletes files that did not exist before. It also reads backups written by the Python client. `Sync` runs every detected writer behind one snapshot and records the results. The commands `ajent integrations [status|sync|remove]` and `ajent rollback <id>` expose this. `ajent setup` calls `Sync` through `setup.Integrate`.

Decision (orchestrator, from the T2.1 contract freeze): `ajent rollback` accepts both the Python all-digit backup IDs (`backups/<time_ns>/`, manifest as a JSON array) and the Go ID format. Go never creates the `<file>.ajent-backup-<time_ns>` sibling copies that the Python client left next to harness files; the backup directory is the only copy (docs/contract.md section 4).

### Steps

1. Backup layout. `<configDir>/backups/<ID>/` has mode 0700. `ID = time.Now().UTC().Format("20060102T150405Z") + "-" + hex(3 random bytes)`. Saved copies are files named `0`, `1` and so on. `manifest.json` (written with `config.WriteJSON`):

   ```json
   {"version": 1, "created": "<RFC3339 UTC>", "entries": [
     {"target": "<absolute path>", "exists": true, "saved": "0", "mode": 420},
     {"target": "<absolute path>", "exists": false}
   ]}
   ```

   `mode` is the decimal `perm` bits.
2. `Snapshot(configDir string, paths []string) (Backup, error)`: deduplicate and sort `paths`. For each path, call `os.Lstat`. A symlink returns `config.ErrSymlink` wrapped with the path, and no backup directory is left behind (remove the partial dir). A missing file gives an entry with `exists: false`. A present file is copied with `config.WritePrivate` into the next index. After writing, prune `backups/` to the newest 20 new-format IDs. IDs that do not match the new format (for example Python numeric IDs) are never pruned.
3. `Rollback(configDir, id string) error`:
   - Validate `id` against `^(\d{8}T\d{6}Z-[0-9a-f]{6}|\d{1,20})$`. Otherwise return `errors.New("integrations: unknown backup id")`.
   - Refuse if the backup dir is a symlink.
   - Read `manifest.json`. If it is a JSON object with `version: 1`, use `entries`. If it is a JSON array, treat it as the Python legacy format: each item has `target`, `exists`, optional `saved` and `mode`, the same meaning.
   - For each entry: refuse a symlinked target. For `exists: true`, create the parent with 0700, `config.WritePrivate(target, saved bytes)`, then `os.Chmod(target, mode)` when `mode != 0`. For `exists: false`, remove the target if present.
4. `Sync(ctx, p Params) ([]Result, Backup, error)`:
   - `ws := Writers()`. `detected` is the writers with `Detect(p)` true.
   - `paths` is the union of `w.Paths(p)` for detected writers, plus `<ConfigDir>/mcp-example.json` and `<ConfigDir>/integration-status.json`.
   - `b, err := Snapshot(p.ConfigDir, paths)`. Return the error on failure. Nothing has been written yet.
   - For each detected writer, call `Apply`. A Go error becomes `Result{Name, Status: "incomplete", Detail: err.Error()}`, and the loop continues.
   - Write `<ConfigDir>/mcp-example.json` as `{"mcpServers": {"ajent": Entry(p, "custom-agent")}}` with `config.WriteJSON`.
   - Write `<ConfigDir>/integration-status.json` as `{"updated": "<RFC3339>", "backup": "<ID>", "results": [...]}`.
   - Return results in `Writers()` order.
5. `cmd/ajent/cmd_integrations.go` (package main):
   - Add `paramsFromEnv(env *cli.Env) (integrations.Params, error)`, which returns `integrations.ParamsFromEnv(env.Home, env.ConfigDir, env.Getenv)`.
   - Register `integrations`, with summary "Show, sync or remove coding-tool integrations". Subcommand from `args[0]`, default `status`:
     - `status`: PrintJSON `{"detected": [names of detected writers], "last": <parsed integration-status.json or null>}`.
     - `sync`: run `Sync`. For each result, print `<name>: <status>` plus `: <detail>` when set. Then print `Integration backup: <ID>. Roll back with: ajent rollback <ID>` and `Reload MCP connections or start new agent sessions to pick up the integration.`
     - `remove`: Snapshot all detected writers' Paths, call `Remove` on each, print the results and the backup line.
     - Any other subcommand is a usage error.
   - Register `rollback`, with summary "Restore a configuration backup". It needs exactly one arg (otherwise usage). Call `integrations.Rollback(env.ConfigDir, id)`, then print `Restored installation backup <id>. Restart affected MCP processes.`
6. `cmd/ajent/wire_integrations.go`: in `init()`, set `setup.Integrate = func(ctx context.Context, env *cli.Env) error { return runIntegrationsSync(ctx, env) }`, reusing the `sync` printing path.
7. Tests (`internal/integrations`) use a fake `Writer` type defined in the test file. Clear and restore the registry around each test.
   - `TestSnapshotRollbackRestoresBytesAndModes`: two existing files (modes 0644 and 0600) and one absent. After Snapshot, mutate both files and create the absent one. Rollback restores the bytes and modes and deletes the created file.
   - `TestSnapshotRefusesSymlink`: no backup directory remains.
   - `TestRollbackLegacyPythonManifest`: hand-write `backups/1726000000000000000/manifest.json` as an array plus saved file `0`. Rollback restores it.
   - `TestRollbackRejectsBadID`: `../x`, an empty string and `abc`.
   - `TestSnapshotPrunesTo20`.
   - `TestSyncSnapshotsBeforeApply`: the fake writer's Apply asserts that the backup dir already contains its path.
   - `TestSyncWritesStatusAndExample`: check the JSON shapes.
   - `TestSyncWriterErrorBecomesIncomplete`.
   - `TestSyncSkipsUndetected`: Apply is not called and the path is not in the manifest.
   - In `cmd/ajent/cmd_integrations_test.go`: `TestIntegrationsCommandStatusSyncRollback`, driven through `cli.Main` with fake writers and `integrations.BinaryOverride` set. `sync` prints the backup ID. `rollback <that id>` restores the files. A bad subcommand exits 2.

### Acceptance criteria

- All tests pass with `-race` on ubuntu, macos and windows.
- Genuine-red: skip deleting `exists: false` targets in Rollback, then observe `TestSnapshotRollbackRestoresBytesAndModes` fail. Restore and report both outputs.
- Genuine-red: call Apply before Snapshot in Sync, then observe `TestSyncSnapshotsBeforeApply` fail. Restore.
