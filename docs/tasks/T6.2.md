## T6.2: Discover releases, compare versions and persist update state

### Objective

`update.Source` finds the latest stable (or prerelease) version and a specific version, from the GitHub Releases API with an ETag cache. It falls back to `https://pkg.ajent.social/latest.json` on rate limiting and returns within 3 seconds when offline. `update.Newer` compares semantic versions. `update.LoadState` and `update.SaveState` persist `state.json`. The reusable test helper `internal/testutil/fakerelease` serves GitHub-shaped release metadata and signed release assets for T6.3, T6.6, T6.8 and T5.13.

### Steps

1. `semver.go`:
   - `func Newer(a, b string) bool` reports whether `a` is strictly newer than `b`. Strip one leading `v` from each. Split off build metadata at `+` and ignore it.
   - Parse `MAJOR.MINOR.PATCH[-PRERELEASE]`. Each core part is a non-negative decimal without leading zeros (except `0` itself). If either side fails to parse, return false.
   - Compare major, minor and patch numerically. If they are equal: a version without a prerelease is newer than one with a prerelease. When both have one, compare dot-separated identifiers left to right. Numeric identifiers compare numerically and rank lower than alphanumeric ones. Alphanumeric identifiers compare in ASCII order. If all shared identifiers are equal, the longer list is newer.
   - Also export `func Valid(v string) bool`.
   - `semver_test.go`: `TestNewer` table with at least these (a, b, want) rows: `(0.7.1, 0.7.0, true)`, `(0.7.0, 0.7.0, false)`, `(v0.8.0, 0.7.9, true)`, `(0.10.0, 0.9.0, true)`, `(1.0.0, 1.0.0-rc.1, true)`, `(1.0.0-rc.1, 1.0.0, false)`, `(1.0.0-rc.2, 1.0.0-rc.10, false)`, `(1.0.0-rc.10, 1.0.0-rc.2, true)`, `(1.0.0-beta, 1.0.0-alpha, true)`, `(1.0.0-alpha.1, 1.0.0-alpha, true)`, `(1.0.0-1, 1.0.0-alpha, false)`, `(1.0.0+build.5, 1.0.0, false)`, `(dev, 0.7.0, false)`, `(0.7.0, dev, false)`, `(01.0.0, 0.9.0, false)`, `(0.7.1-SNAPSHOT-abc1234, 0.7.0, true)`. Also add `TestValid`.
2. `state.go`: the `State` struct exactly as in docs/interfaces.md.
   - `LoadState(configDir)` reads `filepath.Join(configDir, "state.json")` with `config.ReadJSON`. It returns the zero `State` and nil error when the file is absent, and the zero `State` and nil error (after renaming the file to `state.json.corrupt`) when the JSON is malformed.
   - `SaveState` uses `config.WriteJSON`, which gives mode 0600 and an atomic write.
   - Add `func (s State) AutoEnabled(m Method) bool`. It returns `*s.Auto` when `s.Auto` is non-nil and `m == MethodScript`, returns true when `s.Auto` is nil and `m == MethodScript`, and returns false for every other method.
   - `state_test.go`: `TestStateRoundTrip`, `TestStateMissing`, `TestStateCorrupt`, `TestAutoEnabled` (nil, true and false, for script and for homebrew).
3. `source.go`:
   - Constants: `DefaultGitHubAPI = "https://api.github.com/repos/ajent-social/ajent"` and `DefaultFallbackURL = "https://pkg.ajent.social/latest.json"`.
   - `func DefaultSource(configDir string) *Source` sets `HTTP` to `&http.Client{Timeout: 3 * time.Second}` and `CacheDir` to `configDir`. `GitHubAPI` is `AJENT_UPDATE_API` when set, else the default. `FallbackURL` is `AJENT_UPDATE_FALLBACK_URL` when set, else the default. These env overrides exist for tests and mirrors. Trust comes from signatures (T5.3), so the overrides do not weaken verification. Document that in a comment.
   - `func CheckAllowed(getenv func(string) string) bool` returns false when `AJENT_NO_UPDATE_CHECK` is non-empty or `CI` is non-empty, and true otherwise.
   - Every request sets `User-Agent: version.UserAgent()` and `Accept: application/vnd.github+json`. No other identifying headers or query parameters.
   - `Latest(ctx, pre)`:
     1. When `pre` is false, GET `{GitHubAPI}/releases/latest`. When true, GET `{GitHubAPI}/releases?per_page=20` and choose the release with the greatest version by `Newer`, ignoring drafts.
     2. ETag cache: file `filepath.Join(CacheDir, "release-cache.json")` holding `{"url": {"etag": "...", "body": <raw json>}}`. Send `If-None-Match` when an entry exists. On `304`, use the cached body. On `200`, store the new ETag and body.
     3. On HTTP `403` or `429`, or any `5xx`, when `pre` is false: GET `FallbackURL` and decode it directly into `Release` (it uses the same field names; `tag` is ignored).
     4. On a network error or context deadline, return an error wrapping `ErrUnavailable` (declare that sentinel). Callers treat it as "no update information".
   - `Get(ctx, version)`: GET `{GitHubAPI}/releases/tags/v{version}` with the same cache and error rules, but no fallback.
   - Mapping from GitHub JSON: `tag_name` becomes `Version` (strip the `v`), `prerelease` becomes `Prerelease`, and each entry of `assets[]` maps `name` to `browser_download_url` in `Assets`. Reject releases whose version is not `Valid`.
4. `internal/testutil/fakerelease/fakerelease.go` (package `fakerelease`, test support, stdlib only):

   ```go
   type Server struct{ URL string /* unexported */ }
   func New(t testing.TB) *Server                     // httptest server, closed via t.Cleanup
   func (s *Server) API() string                      // s.URL + "/repos/ajent-social/ajent"
   func (s *Server) FallbackURL() string              // s.URL + "/latest.json"
   // AddRelease registers a release; assets are served at s.URL/download/v<version>/<name>
   // and listed with browser_download_url pointing there.
   func (s *Server) AddRelease(version string, prerelease bool, assets map[string][]byte)
   func (s *Server) SetStatus(path string, code int)  // force a status for a path (e.g. 403 on /releases/latest)
   func (s *Server) Requests() []string               // "METHOD path" in order
   // BuildAssets returns archive, checksums.txt and checksums.txt.sig for one platform.
   // binary is the executable content; the archive layout matches GoReleaser (tar.gz with "ajent",
   // zip with "ajent.exe" for windows); name format "ajent_<version>_<goos>_<goarch>.<ext>".
   func BuildAssets(t testing.TB, version, goos, goarch string, binary []byte, key ed25519.PrivateKey) map[string][]byte
   ```

   Routes: `GET /repos/ajent-social/ajent/releases/latest` returns the newest non-prerelease. `GET .../releases?per_page=N` returns all releases, newest first. `GET .../releases/tags/v<version>` returns one release. `GET /latest.json` returns the newest stable in the `latest.json` shape. `GET /download/v<version>/<name>` returns the asset bytes. Every JSON response sets an `ETag` (a quoted hash of the body) and honors `If-None-Match` with `304`. Unknown paths return 404. The signature is standard base64 of `ed25519.Sign(key, checksums)` plus `\n`. The checksums lines are `<sha256 hex>  <name>`. The name format is duplicated here on purpose; T6.3 asserts it matches `update.ArchiveName`.
   `fakerelease_test.go`: `TestBuildAssetsVerifies` (checks the signature with `ed25519.Verify` and that the archive contains the binary) and `TestRoutes`.
5. `source_test.go`, using fakerelease: `TestLatestStable`, `TestLatestSkipsPrerelease`, `TestLatestPre`, `TestLatestETagCache` (the second call sends `If-None-Match`, gets `304` and returns the same release), `TestLatestFallbackOn403`, `TestLatestFallbackOn5xx`, `TestLatestOfflineWithin3s` (point at a closed listener, measure elapsed time under 3.5s, and assert `errors.Is(err, ErrUnavailable)`), `TestGetVersion`, `TestGetMissing404`, `TestUserAgentOnly` (the recorded request headers contain no `Authorization`), `TestCheckAllowed`, `TestDefaultSourceEnvOverride`.

### Acceptance criteria

- `go test ./internal/update/... ./internal/testutil/fakerelease/... -race -count=1` passes on ubuntu, macos and windows CI.
- `golangci-lint run ./internal/update/... ./internal/testutil/...` and `gofmt -l` are clean.
- Genuine-red: make `Newer` ignore prerelease identifiers (compare only major, minor and patch). Run `go test ./internal/update -run TestNewer -count=1` and observe the rc and alpha rows fail. Restore it and report both outputs.
