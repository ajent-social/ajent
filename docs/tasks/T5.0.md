## T5.0: Provision the release accounts and secrets

### Objective

Everything the automated release pipeline needs from a human exists. That means the channel repositories, a winget-pkgs fork, scoped tokens, the Ed25519 release key, the package GPG key, a protected `release` environment and the `pkg.ajent.social` DNS record. After this task, no release step waits on a person. This is a runbook for the maintainer (David). Each step ends with a verification command whose expected output is stated.

### Read first

- docs/adr/003-distribution-channels.md
- docs/adr/004-release-signing.md
- docs/plans/E5-release-distribution.md (rows T5.5, T5.7, T5.8, T5.11)

### Scope

Only settings and secrets on GitHub, a DNS record, and files kept offline in the maintainer's password manager. No files in this repository change, with one exception: the public keys produced here are handed to T5.3 (Ed25519) and T5.7 (GPG) through the task notes, and those tasks commit them.

### Out of scope

- Apple signing secrets (T5.14).
- Writing any workflow or GoReleaser configuration.
- `AJENT_LIVE_CREDENTIAL` (T4.12) and `LEAK_DENYLIST` (T1.5).

### Steps

1. Prerequisites. Install `gh` and log in as an `ajent-social` org owner (`gh auth status` shows the account). Install OpenSSL 3 with `brew install openssl@3`, then run `export OSSL="$(brew --prefix openssl@3)/bin/openssl"`. Also install GnuPG (`brew install gnupg`). Verify: `$OSSL version` prints `OpenSSL 3.` and `gpg --version` prints `gpg (GnuPG) 2.`.
2. Create the channel repositories:
   - `gh repo create ajent-social/homebrew-tap --public --description "Homebrew tap for ajent" --add-readme`
   - `gh repo create ajent-social/scoop-bucket --public --description "Scoop bucket for ajent" --add-readme`
   - `gh repo create ajent-social/packages --public --description "Signed APT and DNF repositories and install scripts for ajent, served at pkg.ajent.social" --add-readme`
   Verify: `gh repo view ajent-social/homebrew-tap --json visibility -q .visibility` prints `PUBLIC`. Repeat for the other two.
3. Fork winget-pkgs into the org: `gh repo fork microsoft/winget-pkgs --org ajent-social --clone=false`. Verify: `gh repo view ajent-social/winget-pkgs --json parent -q .parent.nameWithOwner` prints `microsoft/winget-pkgs`.
4. Create the tokens. Fine-grained personal access tokens cannot open pull requests on repositories outside their resource owner, so winget needs a classic token.
   - `HOMEBREW_TAP_TOKEN`: fine-grained, resource owner `ajent-social`, repository `homebrew-tap` only, permission Contents read and write. Expiry 1 year.
   - `SCOOP_BUCKET_TOKEN`: the same, for `scoop-bucket` only.
   - `PACKAGES_TOKEN`: fine-grained, repository `packages` only, permission Contents read and write (this is required for `repository_dispatch`). Also Actions read.
   - `WINGET_TOKEN`: classic token with scope `public_repo`, from a maintainer account that has push access to `ajent-social/winget-pkgs`. Expiry 1 year.
   Record each expiry date in the maintainer calendar 2 weeks before it expires.
5. Generate the Ed25519 release key, offline, in a temporary directory:
   - `$OSSL genpkey -algorithm ed25519 -out release-ed25519.pem`
   - Private seed for CI: `$OSSL pkey -in release-ed25519.pem -outform DER | tail -c 32 | base64` (standard base64, 44 characters). This is `RELEASE_ED25519_KEY`.
   - Public key, raw base64: `$OSSL pkey -in release-ed25519.pem -pubout -outform DER | tail -c 32 | base64`. Give this value to T5.3.
   - Public key, PEM: `$OSSL pkey -in release-ed25519.pem -pubout -out ajent-release.pub.pem`. Give this file to T5.3.
   - Fingerprint: `$OSSL pkey -in release-ed25519.pem -pubout -outform DER | $OSSL dgst -sha256`. Give this value to T5.3 for SECURITY.md.
   Store `release-ed25519.pem` in the password manager, then delete it from disk with `rm -P release-ed25519.pem`.
   Verify: `echo test > m; $OSSL pkeyutl -sign -inkey release-ed25519.pem -rawin -in m -out s; $OSSL pkeyutl -verify -pubin -inkey ajent-release.pub.pem -rawin -in m -sigfile s` prints `Signature Verified Successfully`. Run this before deleting the PEM.
6. Generate the package GPG key. Create `gpg-batch.txt` with exactly these lines, replacing `<PASSPHRASE>` with a newly generated 32-character random passphrase:

   ```text
   Key-Type: RSA
   Key-Length: 4096
   Key-Usage: sign
   Name-Real: ajent packages
   Name-Email: packages@ajent.social
   Expire-Date: 3y
   Passphrase: <PASSPHRASE>
   %commit
   ```

   Run `gpg --batch --generate-key gpg-batch.txt`, then `rm -P gpg-batch.txt`.
   - Key ID: `gpg --list-secret-keys --keyid-format long packages@ajent.social` (the 16-hex-character ID after `rsa4096/`).
   - Secret for CI: `gpg --armor --export-secret-keys <KEYID>`. This is `PACKAGES_GPG_KEY`, and the passphrase is `PACKAGES_GPG_PASSPHRASE`.
   - Public key: `gpg --armor --export <KEYID> > gpg.key`. Give this file to T5.7.
   - Revocation certificate: `gpg --output revoke.asc --gen-revoke <KEYID>`. Store it and the exported secret key in the password manager.
   Verify: `gpg --verify` of a test detached signature succeeds: `echo x > f; gpg --local-user <KEYID> --detach-sign --armor f; gpg --verify f.asc f` prints `Good signature`.
7. Confirm that the package maintainer address `maintainers@ajent.social` and the key email `packages@ajent.social` receive mail (use a forwarding alias). If you pick different addresses, record them in the T5.6 and T5.7 task notes before those tasks run.
8. Create the protected `release` environment on `ajent-social/ajent`:
   - `REVIEWER_ID=$(gh api users/<your-login> -q .id)`
   - `gh api -X PUT repos/ajent-social/ajent/environments/release -F "reviewers[][type]=User" -F "reviewers[][id]=$REVIEWER_ID" -F "deployment_branch_policy[protected_branches]=true" -F "deployment_branch_policy[custom_branch_policies]=false"`
   Verify: `gh api repos/ajent-social/ajent/environments/release -q '.protection_rules[].type'` includes `required_reviewers`.
9. Store the secrets. Pipe values in from the password manager and never type them into shell history:
   - In the `release` environment of `ajent-social/ajent`: `gh secret set HOMEBREW_TAP_TOKEN --env release --repo ajent-social/ajent`. Do the same for `SCOOP_BUCKET_TOKEN`, `WINGET_TOKEN`, `PACKAGES_TOKEN` and `RELEASE_ED25519_KEY`.
   - In the `ajent-social/packages` repository, as plain repository secrets: `gh secret set PACKAGES_GPG_KEY --repo ajent-social/packages` and `gh secret set PACKAGES_GPG_PASSPHRASE --repo ajent-social/packages`.
   Verify: `gh secret list --env release --repo ajent-social/ajent` lists exactly the five names, and `gh secret list --repo ajent-social/packages` lists the two GPG names.
10. DNS. At the DNS provider for `ajent.social`, create `CNAME pkg -> ajent-social.github.io`. If the provider proxies traffic, set this record to DNS-only so GitHub Pages can issue its certificate. Verify: `dig +short CNAME pkg.ajent.social` prints `ajent-social.github.io.`. GitHub Pages itself is enabled by T5.7 after its first publish.
11. Verify the org domain for Pages (this prevents takeover of the custom domain): org Settings > Pages > Add a verified domain `ajent.social`, then add the TXT record GitHub shows. Verify: the domain shows "Verified" on that settings page.
12. Hand-off. Post the Ed25519 raw public key, the PEM, the fingerprint and the GPG public key (`gpg.key`) in the notes for T5.3 and T5.7. Public keys are not secret.

### Acceptance criteria

- `gh repo view` succeeds for `ajent-social/homebrew-tap`, `ajent-social/scoop-bucket`, `ajent-social/packages` and `ajent-social/winget-pkgs` (the fork).
- `gh secret list --env release --repo ajent-social/ajent` shows `HOMEBREW_TAP_TOKEN`, `SCOOP_BUCKET_TOKEN`, `WINGET_TOKEN`, `PACKAGES_TOKEN` and `RELEASE_ED25519_KEY`.
- `gh secret list --repo ajent-social/packages` shows `PACKAGES_GPG_KEY` and `PACKAGES_GPG_PASSPHRASE`.
- The `release` environment requires a reviewer.
- `dig +short CNAME pkg.ajent.social` resolves to `ajent-social.github.io.`.
- The Ed25519 and GPG public keys are handed to T5.3 and T5.7. Private material exists only in the password manager and in GitHub secrets.

- `gh secret list --env release --repo ajent-social/ajent`
- `gh secret list --repo ajent-social/packages`

- `dig +short CNAME pkg.ajent.social`
