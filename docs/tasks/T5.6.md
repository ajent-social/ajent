## T5.6: Build the Linux packages

### Objective

Each release produces `.deb` and `.rpm` packages for amd64 and arm64 that install `/usr/bin/ajent` with license and docs. The packages install cleanly in `debian:stable`, `ubuntu:24.04` and `fedora:latest`, where `ajent version` prints the release version. The packages never run `ajent setup` from maintainer scripts.

### Read first

- docs/adr/003-distribution-channels.md
- GoReleaser documentation: customization > nfpm
- `.goreleaser.yaml` (the `nfpms (T5.6)` marker block)
- docs/plan.md Appendix A (package description)

### Scope

Modify only `.goreleaser.yaml`, between `# ---- BEGIN nfpms (T5.6) ----` and `# ---- END nfpms (T5.6) ----`.
Create:

- `packaging/postinstall.sh`
- `scripts/test-linux-packages.sh`

### Out of scope

- The APT and DNF repositories and package signing (T5.7). The man page and shell completions (E9).

### Steps

1. Create `packaging/postinstall.sh` (POSIX sh, SPDX header, `set -e`). It only prints `ajent installed. Run "ajent setup" as your normal user to connect your coding agents.` It writes nothing and exits 0. Make it executable.
2. Fill the marker block:

   ```yaml
   # ---- BEGIN nfpms (T5.6) ----
   nfpms:
     - id: packages
       ids: [ajent]
       package_name: ajent
       file_name_template: "{{ .ConventionalFileName }}"
       vendor: Ajent
       homepage: https://ajent.social
       maintainer: "Ajent maintainers <maintainers@ajent.social>"
       description: "Connect your coding agents to a shared, private workspace of checked findings through MCP."
       license: Apache-2.0
       section: utils
       priority: optional
       formats: [deb, rpm]
       bindir: /usr/bin
       contents:
         - src: LICENSE
           dst: /usr/share/doc/ajent/LICENSE
           file_info:
             mode: 0644
         - src: NOTICE
           dst: /usr/share/doc/ajent/NOTICE
           file_info:
             mode: 0644
         - src: README.md
           dst: /usr/share/doc/ajent/README.md
           file_info:
             mode: 0644
       scripts:
         postinstall: packaging/postinstall.sh
       rpm:
         group: Development/Tools
   # ---- END nfpms (T5.6) ----
   ```

   If the T5.0 notes record a different maintainer address, use it.
3. Create `scripts/test-linux-packages.sh` (SPDX header, `set -eu`, needs docker or podman: use `${CONTAINER:-podman}` and fall back to `docker` when podman is absent). For the host architecture (map `uname -m` to `amd64` or `arm64`):
   - `debian:stable` and `ubuntu:24.04`: mount `dist/` read-only at `/d`, then run `apt-get install -y /d/ajent_*_${arch}.deb && ajent version --json`.
   - `fedora:latest`: run `dnf install -y /d/ajent-*.${rpmarch}.rpm && ajent version --json`, where `rpmarch` is `x86_64` or `aarch64`.
   - Each run asserts that the JSON `version` equals the expected version (first argument), that `/usr/bin/ajent` exists, and that `/usr/share/doc/ajent/LICENSE` exists.
   - Each run also asserts no `.aj` directory was created under `/root` (so no setup ran).
4. Run the snapshot (`goreleaser release --snapshot --clean --skip=sign,notarize,publish`), then `sh scripts/test-linux-packages.sh "$(jq -r .version dist/metadata.json)"`.
5. Inspect metadata: `dpkg-deb -I dist/ajent_*_amd64.deb` (in a debian container) shows Package `ajent`, the Maintainer, Homepage and Section `utils`. `rpm -qip dist/ajent-*.x86_64.rpm` (in a fedora container) shows License `Apache-2.0` and the URL.

### Acceptance criteria

- `goreleaser check` exits 0, and the snapshot writes four packages: deb and rpm for amd64 and arm64.
- `scripts/test-linux-packages.sh` exits 0 on an amd64 Linux host (and on arm64 when available), with the version asserted in all three distributions.
- `shellcheck scripts/test-linux-packages.sh packaging/postinstall.sh` is clean.
- Genuine-red: change `bindir` to `/usr/local/bin`, rerun the snapshot and the test script, and observe the `/usr/bin/ajent` assertion fail. Restore it and report both outputs.

### Verification

- `go run github.com/goreleaser/goreleaser/v2@<GR> check`
- `go run github.com/goreleaser/goreleaser/v2@<GR> release --snapshot --clean --skip=sign,notarize,publish`
- `sh scripts/test-linux-packages.sh "$(jq -r .version dist/metadata.json)"`
- `shellcheck scripts/test-linux-packages.sh packaging/postinstall.sh`
