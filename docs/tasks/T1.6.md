## T1.6: Write agent-contributor guidance

### Objective

Any coding agent that opens this repository learns the project's rules from `AGENTS.md` in under a minute. `CLAUDE.md` imports it, so Claude Code sessions load the same rules.

### Read first

- docs/design.md (invariants)
- docs/interfaces.md (the conventions list at the top)
- docs/tasks/README.md
- docs/adr/002-go-stdlib-single-binary.md, docs/adr/006-client-trust-boundaries.md, docs/adr/007-harness-integration-model.md

### Scope

- `AGENTS.md`
- `CLAUDE.md`

### Out of scope

- Any reference to private repositories, internal tooling, personal machines, build leases, home paths or internal project names. This file is public.
- Restating the full ADRs. Link to them.

### Steps

1. `AGENTS.md` headings, in order, each with 2 to 8 bullet points:
   - `# Agent guide for ajent`: one sentence describing what the repository is (docs/design.md, first paragraph).
   - `## Before you change code`: read docs/design.md, docs/interfaces.md and, for plan tasks, `docs/tasks/<id>.md`. Signatures in docs/interfaces.md are binding. Behavior in docs/contract.md is binding.
   - `## Rules`:
     - Use the standard library only, plus `golang.org/x/sys`. No new modules without an ADR.
     - Use `flag` for CLI parsing. No frameworks.
     - Unit tests make no real network calls. Use `internal/testutil/fakeserver`.
     - `ajent mcp` writes only JSON-RPC to stdout. Diagnostics go to stderr.
     - Tokens never appear in output, logs, errors or test failure messages.
     - Back up before writing any file outside the config directory (docs/adr/007-harness-integration-model.md).
     - Every network write carries an idempotency key that is reused on retry.
     - Never read server, grants or scope from files inside a project (docs/adr/006-client-trust-boundaries.md).
     - Every Go and shell file starts with the SPDX header `Apache-2.0`.
   - `## Workflow`: run `make fmt lint test` before opening a PR. Use small commits, one logical change each. Use Conventional Commit titles. Sign off with `git commit -s`. Do not mix files from different top-level directories in one commit.
   - `## Tests`: table-driven, named `Test<Func><Case>`. Cross-OS behavior must pass on Windows. Use `t.TempDir()` for any filesystem path. For behavior changes, show the test failing before the fix.
   - `## Public repository`: everything here is public. Do not add hostnames other than `ajent.social`, `pkg.ajent.social` and `github.com`, and add no personal paths, internal names, credentials or pricing statements. CI runs a leak scan.
2. `CLAUDE.md` contains exactly one line: `@AGENTS.md`
3. Keep `AGENTS.md` under 80 lines, ASCII only, in Google developer docs style.

### Acceptance criteria

- `wc -l AGENTS.md` is 80 or fewer lines. `cat CLAUDE.md` prints `@AGENTS.md`.
- `LC_ALL=C grep -n '[^ -~]' AGENTS.md CLAUDE.md` prints nothing.
- `grep -nE '/Users/|/home/|localhost:[0-9]+' AGENTS.md` prints nothing.
- Every rule in the `## Rules` section links to, or can be traced to, docs/design.md, docs/interfaces.md or an ADR.

### Verification

```bash
wc -l AGENTS.md; cat CLAUDE.md
LC_ALL=C grep -n '[^ -~]' AGENTS.md CLAUDE.md || echo ascii-ok
grep -nE '/Users/|/home/' AGENTS.md || echo paths-ok
```
