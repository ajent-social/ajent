## T2.13: Wire scope configuration into ajent setup

### Objective

`ajent setup` and `ajent link` configure sharing scope through the same code path as `ajent configure`. After this task, `setup.ConfigureScope` is assigned at startup, so a first-run setup either saves the chosen scope or prints the deferred hint instead of `Choose a sharing scope later with: ajent configure`.

### Read first

- docs/interfaces.md sections `internal/scope` and `internal/setup` (the `ConfigureScope` hook)
- docs/tasks/T2.10.md (`scope.Configure`, `Options`, `ErrDeferred`)
- docs/tasks/T4.3.md step 1 (hook declaration) and steps 3.8 and 4.5 (the two call sites)
- cmd/ajent/testenv_test.go (T2.6)

### Scope

Create exactly these files:

- `cmd/ajent/wire_scope.go`
- `cmd/ajent/wire_scope_test.go`

### Out of scope

- `internal/scope` (T2.10) and `internal/setup` (T4.3). Do not edit either package.
- `cmd/ajent/main.go`. This task uses an `init()` assignment, not the `wire` slice, because the hook is a package variable in `internal/setup`.

### Steps

1. In `cmd/ajent/wire_scope.go` (first line `// SPDX-License-Identifier: Apache-2.0`, `package main`), add:

   ```go
   func init() { setup.ConfigureScope = configureScopeForSetup }

   func configureScopeForSetup(ctx context.Context, env *cli.Env, root credentials.Credential, sc, domain string, private bool) error {
       msg, err := scope.Configure(ctx, env, root, scope.Options{
           Scope:       sc,
           Domain:      domain,
           DomainSet:   domain != "",
           Private:     private,
           DuringSetup: true,
       })
       if errors.Is(err, scope.ErrDeferred) {
           fmt.Fprintln(env.Stdout, err.Error())
           return nil
       }
       if err != nil {
           return err
       }
       fmt.Fprintln(env.Stdout, msg)
       return nil
   }
   ```

2. In `cmd/ajent/wire_scope_test.go`, write these tests. Use `newTestEnv` with a fakeserver. Make `env.OpenTTY` return an error (non-interactive).
   - `TestSetupHookAssigned`: `setup.ConfigureScope` is non-nil after package init.
   - `TestConfigureScopeForSetupPrivate`: call `configureScopeForSetup(ctx, env, srv.Credential(), "project", "", true)`. `<Cwd project root>/.aj/config.json` has `private_only: true`. Stdout contains `Private mode saved for this project.` There are zero requests to `/v1/domain-grants`.
   - `TestConfigureScopeForSetupDeferred`: call with `("user", "", false)` non-interactively. The error is nil. Stdout contains `configure a domain later`. No `config.json` is written.
   - `TestConfigureScopeForSetupError`: the fake `/v1/domain-grants` returns 403 for `("user", "example.com", false)` with `example.com` listed as verified. The returned error text contains `needs human approval`.
3. Run `gofmt -w cmd/ajent/wire_scope.go cmd/ajent/wire_scope_test.go`.

### Acceptance criteria

- `go test ./cmd/ajent -run 'TestSetupHookAssigned|TestConfigureScopeForSetup' -race -count=1` passes on all three OSes.
- Genuine-red check: temporarily return `err` instead of nil in the `ErrDeferred` branch. `TestConfigureScopeForSetupDeferred` must fail. Restore and report both outputs.
- Genuine-red check: temporarily delete the `init()` line. `TestSetupHookAssigned` must fail. Restore and report both outputs.
