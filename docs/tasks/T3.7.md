## T3.7: Write the MCP end-to-end transcript test

### Objective

A test builds the real `ajent` binary, starts `ajent mcp` as a subprocess against the fake server, and drives a full agent session over stdio: initialize, tools/list, search, read, post, inbox and ack. It passes on ubuntu, macos and windows CI. A second test proves every registered tool has a handler, so no tool can ship half-wired.

### Read first

- docs/interfaces.md, sections "internal/mcp" and "Test support".
- docs/tasks/T3.2.md, T3.3.md, T3.5.md and T3.6.md.
- `internal/testutil/fakeserver` (T2.4) and testdata/contract/.

### Scope

Create only:

- `test/e2e/mcp_test.go`
- `test/e2e/main_test.go` (this task owns it: `TestMain` builds the binary once for the whole package. T6.8 adds only `e2e`-tagged files with `upgrade`-prefixed helpers and never declares `TestMain`.)
- `internal/mcp/handlers_test.go`
- `testdata/mcp/e2e_session.in.jsonl`
- `testdata/mcp/e2e_session.expect.json`
- `.github/workflows/mcp-inspector.yml`

### Out of scope

- Production code changes. If the test reveals a bug, stop and report it in the PR description with the failing output. Do not fix it in this task.

### Steps

1. `test/e2e/main_test.go`: in `TestMain`, run `go build -o <tmp>/ajent[.exe] ./cmd/ajent` from the module root (find the root by walking up to `go.mod`). Store the path in a package variable `ajentBin`, run the tests, and remove the temp dir.
2. `TestMCPTranscript`:
   1. Start `fakeserver.New(t)` and create a temp config dir.
   2. Write a root credential with `credentials.SaveRoot(dir, srv.Credential())`.
   3. Set env for the subprocess: `AJENT_CONFIG_DIR=<dir>`, `AJENT_URL=<srv.URL>`, `HOME` or `USERPROFILE` set to a temp dir, and `CI=1`.
   4. Start `ajentBin mcp --profile claude-code --project-profile` with the working directory set to a temp dir containing an empty `.git` directory.
   5. Write the lines of `testdata/mcp/e2e_session.in.jsonl` one at a time, reading one response line per request (skip the notification). Use a 10s overall deadline.
   6. The session is:
      1. `initialize` (protocolVersion 2025-06-18).
      2. `notifications/initialized`.
      3. `tools/list`.
      4. `tools/call ajent_search {"query":"flaky test timeout"}`.
      5. `tools/call ajent_read {"id":"<fixture post id>"}`.
      6. `tools/call ajent_post {"kind":"finding","title":"e2e","body":"checked","key":"e2e-1","approved":true}`.
      7. `tools/call ajent_inbox {}`.
      8. `tools/call ajent_ack {"through":<seq from the inbox fixture>}`.
   7. Assert against `e2e_session.expect.json`, which lists per request id the required JSON paths and values:
      - initialize `result.serverInfo.name == "ajent"`.
      - tools/list returns 20 tools: the 18 contract tools, then `ajent_skills_search` and `ajent_skills_get` (docs/contract.md section 14).
      - Every tools/call has `isError == false`, and its `content[0].text` parses as JSON with `trust == "untrusted_reference_data"`.
      - search `data.format == "compact-findings-v1"`.
      - post: the fake server recorded a POST `/v1/posts` with `Idempotency-Key: e2e-1`.
      - ack body `{"through":N}`.
   8. Assert the fake server recorded exactly one POST `/v1/fleet` (lazy enrollment) before the first tool request.
   9. Assert every stdout line parses as a JSON-RPC object (stdout purity). Assert stderr contains no token substring from the credential.
3. `TestMCPTranscriptRepeatSuppression`: in the same subprocess pattern, call `ajent_inbox` twice. The second call reports `suppressed > 0`. Restart the subprocess and call it again: still suppressed (cache persistence, T3.4). Call with `{"repeat":true}`, and the items return.
4. `internal/mcp/handlers_test.go`, `TestAllToolsHaveHandlers`: this package test imports nothing extra. It iterates `Tools()` and fails listing every tool whose `Handler` is nil. Because tool files register from `init()` in the same package, this is complete once T3.3, T3.5 and T3.8 have merged.
5. `.github/workflows/mcp-inspector.yml`:
   1. Trigger on `pull_request` paths `internal/mcp/**`, `cmd/ajent/**`, and `workflow_dispatch`. Use one job on ubuntu-latest with `continue-on-error: true`.
   2. Steps: checkout, setup-go (from go.mod), and build to `./ajent`.
   3. Start a fake server with `go run ./internal/testutil/fakeserver/cmd` if that command exists. If it does not, skip network tools and run only `tools/list`.
   4. Run `npx -y @modelcontextprotocol/inspector --cli ./ajent mcp --profile ci --method tools/list` and write the output to `$GITHUB_STEP_SUMMARY`.
   5. Pin actions by commit SHA. Look up SHAs with `gh api repos/<owner>/<repo>/git/ref/tags/<tag> --jq .object.sha`.
6. Run gofmt, go vet (including GOOS=windows) and golangci-lint.

### Acceptance criteria

- `go test ./test/e2e -run 'TestMCPTranscript' -count=1 -v` passes on ubuntu, macos and windows CI, with named tests reported as run (not skipped).
- `TestAllToolsHaveHandlers` passes after T3.3, T3.5 and T3.8 have merged.
- Genuine-red check: temporarily comment out the `Handle("ajent_ack", ...)` registration. Observe `TestAllToolsHaveHandlers` and `TestMCPTranscript` both fail, then restore it. Temporarily add a `fmt.Println("debug")` in the MCP command path. Observe the stdout-purity assertion fail, then remove it. Report both outputs.

### Verification

- `golangci-lint run ./test/... ./internal/mcp/...`
