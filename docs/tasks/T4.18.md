## T4.18: Write the shared agent skill integration

### Objective

`ajent integrations sync` installs the embedded Ajent network skill at `~/.agents/skills/ajent-network/SKILL.md`. Codex and other compatible tools discover user skills in that directory. The file is refreshed on every sync when it is ajent-managed. A file the user wrote themselves is never overwritten. Unsafe destinations (symlinks, directories writable by others) are refused.

### Read first

- docs/tasks/T4.17.md, docs/interfaces.md `internal/integrations` and "Root package (T4.1)"
- docs/tasks/T4.1.md (the skill file and its managed marker line)
- docs/adr/006-client-trust-boundaries.md

### Scope

- `internal/integrations/agentskills.go` (create)
- `internal/integrations/agentskills_test.go` (create)
- `internal/integrations/agentskills_unix.go` and `agentskills_windows.go` (create; the ownership and permission check per OS, with build tags)

### Out of scope

- Claude Code's own skill loading. The plugin carries the skill for Claude (T4.1 and T4.4).
- Any other skill name or directory.

### Steps

1. `type agentSkillsWriter struct{}` registered in `init()`. `Target()` returns `Target{Name: "agentskills", Profile: ""}`.
2. `skillPath(p) = filepath.Join(p.Home, ".agents", "skills", "ajent-network", "SKILL.md")`. `Detect(p)` always returns true. `Paths(p)` is `[]string{skillPath(p)}`.
3. `const managedMarker = "<!-- Managed by ajent. ajent integrations sync overwrites local edits. -->"`. Load the content with `fs.ReadFile(ajent.Plugins, "plugins/ajent/skills/network/SKILL.md")` from the root package `github.com/ajent-social/ajent`.
4. `managed(existing []byte) bool` is true when either condition holds:
   - `bytes.Contains(existing, []byte(managedMarker))`
   - The file starts with `"---\nname: network\n"` and contains `client.py` (the Python-era copy, which T4.9 migration relies on).
5. `safeDestination(p) error` rejects these cases:
   1. `skillPath` is a symlink (`os.Lstat`).
   2. Any of `ajent-network`, `skills` or `.agents` under Home is a symlink.
   3. On unix (`agentskills_unix.go`), any existing one of those directories or the file is not owned by `os.Getuid()` or has mode bits `0o022` set. Use `syscall.Stat_t` from `FileInfo.Sys()`.
   4. On windows (`agentskills_windows.go`), only checks 1 and 2 apply.
   Return `errors.New("integrations: shared skill destination is not private to you; left unchanged")` or `config.ErrSymlink`.
6. `Apply(ctx, p)`:
   - If `safeDestination` fails, return `incomplete` with the error text as Detail and a nil Go error.
   - Read the existing file. If it is absent: create the parent directories with 0700, write with `config.WritePrivate`, and return `configured`.
   - If it is present and equal to the content, return `unchanged`.
   - If it is present, managed and different, overwrite it and return `configured`.
   - If it is present and not managed, return `unchanged` with detail `existing skill preserved`.
7. `Remove(ctx, p)`: delete the file only when it is managed (`removed`). Remove `ajent-network/` too if it is then empty. Otherwise return `unchanged`.
8. Tests:
   - `TestSkillInstallFresh`: the file content equals the embedded bytes. Mode is 0600 on unix.
   - `TestSkillSecondRunUnchanged`.
   - `TestSkillRefreshManaged`: a pre-existing file with the marker and old text gets overwritten.
   - `TestSkillReplacesPythonEra`: `---\nname: network\n...python3 ~/.aj/client.py login...` gets overwritten.
   - `TestSkillPreservesForeign`: a user-written file stays unchanged and gets the `existing skill preserved` detail.
   - `TestSkillRefusesSymlink`: skip on windows if symlinks are unavailable.
   - `TestSkillRefusesGroupWritable`: unix only. `chmod 0o775` on `.agents/skills` gives `incomplete`.
   - `TestSkillRemoveManagedOnly`.

### Acceptance criteria

- All tests pass with `-race` on ubuntu, macos and windows.
- Genuine-red: make `managed` always return true, then observe `TestSkillPreservesForeign` fail. Restore and report both outputs.
- Genuine-red: remove the `0o022` check, then observe `TestSkillRefusesGroupWritable` fail on unix. Restore.
