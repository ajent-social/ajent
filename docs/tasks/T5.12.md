## T5.12: Write the channel verification workflow

### Objective

`verify-release.yml` proves that a published version installs through every channel on clean runners. The channels are install.sh (ubuntu, macos), install.ps1 (windows), Homebrew (macos), APT (debian, ubuntu), DNF (fedora), Scoop and winget (windows), and the GitHub archive with signature and attestation checks. Each job asserts `ajent version --json` equals the tag. One job also runs `ajent doctor` against <https://ajent.social> with the maintainer's live test credential. This workflow is the "deployed to production and verified" gate for every release.

### Read first

- docs/adr/003-distribution-channels.md (a release is done only when this is green)
- docs/tasks/T5.7.md step 8 (APT and DNF user commands), T5.9.md (install script env vars), T5.5.md, T5.8.md
- docs/tasks/T4.12.md (where `AJENT_LIVE_CREDENTIAL` lives and its format)

### Scope

Create only `.github/workflows/verify-release.yml`.

### Out of scope

- Fixing channel problems it finds (open issues instead). The rehearsal against local artifacts (T5.13).

### Steps

1. Triggers:
   - `workflow_dispatch` with input `tag` (required, `vX.Y.Z`).
   - `schedule: - cron: '17 6 * * 1'` (weekly). On schedule, resolve the tag with `gh release view --repo ajent-social/ajent-client --json tagName -q .tagName`.
   Set `permissions: contents: read` and `concurrency: {group: verify-${{ inputs.tag || 'scheduled' }}, cancel-in-progress: false}`.
2. Job `resolve` (ubuntu): outputs `tag` and `version` (the tag without `v`). Validate the tag against `^v[0-9]+\.[0-9]+\.[0-9]+$`. Prereleases are not verified by this workflow.
3. Job `wait-pages` (ubuntu, needs resolve): poll `https://pkg.ajent.social/latest.json` every 30s for up to 20 minutes until `jq -r .version` equals the version, then fail with a clear message on timeout. Channel jobs that use pkg.ajent.social need this job.
4. A shared assertion used in every channel job, inlined as a step: run `ajent version --json` and check with `jq -e --arg v "$VERSION" '.version == $v'` (on Windows, use PowerShell `ConvertFrom-Json` and compare).
5. Channel jobs. Each one sets `AJENT_NO_SETUP=1`, and all need `resolve`:
   - `script-unix` (matrix `ubuntu-latest`, `macos-latest`; needs wait-pages): `curl -fsSL https://pkg.ajent.social/install.sh | env AJENT_VERSION="$VERSION" AJENT_NO_SETUP=1 AJENT_REQUIRE_SIGNATURE=${{ runner.os == 'Linux' && '1' || '0' }} sh`, then `"$HOME/.local/bin/ajent" version --json`.
   - `script-windows` (`windows-latest`; needs wait-pages): `$env:AJENT_VERSION=$env:VERSION; $env:AJENT_NO_SETUP='1'; irm https://pkg.ajent.social/install.ps1 | iex`, then `& "$env:LOCALAPPDATA\Programs\ajent\ajent.exe" version --json`.
   - `brew` (`macos-latest`): `brew install ajent-social/tap/ajent`, assert the version, then run `spctl --assess --type execute "$(readlink -f "$(brew --prefix)/bin/ajent")"`.
   - `apt` (matrix container `debian:stable`, `ubuntu:24.04`; needs wait-pages): `apt-get update && apt-get install -y curl gpg ca-certificates`, then the APT command from docs/tasks/T5.7.md step 8 without `sudo`.
   - `dnf` (container `fedora:latest`; needs wait-pages): the DNF command from T5.7 step 8 without `sudo`, with `-y`.
   - `scoop` (`windows-latest`): install Scoop non-interactively, then `scoop bucket add ajent https://github.com/ajent-social/scoop-bucket; scoop install ajent`.
   - `winget` (`windows-latest`, `continue-on-error: true`): make sure winget is present (same method as T5.8), then `winget install --id AjentSocial.Ajent --version $env:VERSION --exact --accept-source-agreements --accept-package-agreements --disable-interactivity`. Write `winget: accepted` or `winget: pending (not yet in the community repository)` to `$GITHUB_STEP_SUMMARY`, depending on whether `winget show --id AjentSocial.Ajent --version $env:VERSION` succeeds.
   - `archive` (ubuntu):
     1. `gh release download "$TAG" --repo ajent-social/ajent-client --pattern "ajent_${VERSION}_linux_amd64.tar.gz" --pattern checksums.txt --pattern checksums.txt.sig`.
     2. Verify the signature with OpenSSL 3 using `https://pkg.ajent.social/ajent-release.pub.pem` and also the committed `packaging/ajent-release.pub.pem` at the tag. Both must match, which catches a site/repo divergence.
     3. Run `sha256sum --ignore-missing -c checksums.txt`.
     4. Run `gh attestation verify "ajent_${VERSION}_linux_amd64.tar.gz" --repo ajent-social/ajent-client`.
     5. Extract, then run the version assertion and `./ajent verify-release --checksums checksums.txt --sig checksums.txt.sig --file ajent_${VERSION}_linux_amd64.tar.gz`.
6. Job `live-doctor` (ubuntu; needs script-unix; `environment:` the same environment name that T4.12 uses for `AJENT_LIVE_CREDENTIAL`):
   1. Install via install.sh as above.
   2. Write the credential secret to `$RUNNER_TEMP/aj/credential.json` with mode 0600, and set `AJENT_CONFIG_DIR=$RUNNER_TEMP/aj`.
   3. Run `ajent doctor`. Assert exit 0 and that `jq -e '.local_client_version == env.VERSION'` holds on its JSON output.
   4. Delete the directory in an `if: always()` step.
   If the secret is empty, fail with `AJENT_LIVE_CREDENTIAL not configured`. Do not skip silently.
7. Job `summary` (`if: always()`, needs all): write a Markdown table of channel name to result (`success`, `failure` or `skipped`, from `needs.<job>.result`) into `$GITHUB_STEP_SUMMARY`. Exit 1 if any job other than `winget` did not succeed.
8. SHA-pin every action. Run `actionlint`.
9. Before any public release exists, validate the workflow by dispatching it against a tag in a scratch context. It will fail at download; that is expected. Record that the YAML parses and the jobs start. The real green run happens at the first release in E8.

### Acceptance criteria

- `actionlint` passes.
- A manual dispatch (step 9) creates a run in which every job starts. Report the run URL.
- At the first public release (E8): all channel jobs except `winget` are green, and `summary` shows the table. This item is checked at E8.
- Genuine-red: dispatch with a tag whose version does not exist in the tap (for example an older nonexistent `v0.0.1`). The `brew` and `apt` jobs fail on the version assertion or install step, and `summary` exits 1. Report the run URL.

### Verification

- `go run github.com/rhysd/actionlint/cmd/actionlint@latest .github/workflows/verify-release.yml`
- `gh workflow run verify-release.yml -f tag=<tag> && gh run list --workflow verify-release.yml --limit 1`
