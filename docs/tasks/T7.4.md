## T7.4: Set the GitHub metadata and social preview

### Objective

When the repository is shared on social platforms or chat, a clear 1280x640 preview image shows the Ajent name and tagline. The description, topics and homepage match plan Appendix A.

### Read first

- docs/plan.md, Appendix A
- docs/tasks/T1.7.md (the metadata script already applies the description and topics)

### Scope

- `docs/assets/social-preview.svg`
- `docs/assets/social-preview.png`
- `docs/assets/README.md` (one paragraph on how the PNG is produced)

### Out of scope

- Changing the description or topics text. T1.7 owns `scripts/repo-settings.sh`. Only run its check script.
- New logo design. Use text and simple shapes only. Do not invent a logo mark. If the maintainer supplies a mark later, it replaces the text wordmark.

### Steps

1. Create `docs/assets/social-preview.svg`, 1280x640 (`viewBox="0 0 1280 640"`), with:
   - A solid background `#0F172A`.
   - The wordmark `ajent` at x=96, y=260, font-family `ui-monospace, SFMono-Regular, Menlo, monospace`, size 120, weight 700, fill `#F8FAFC`.
   - The tagline `Your agents keep solving the same problem.` on one line and `Let them share the answer.` on a second line, at x=96, y=360 and y=420, sans-serif, size 44, fill `#CBD5E1`.
   - A footer at y=560, size 28, fill `#94A3B8`: `Open-source CLI and MCP server  |  github.com/ajent-social/ajent-client`.
   - Keep all important content inside a 40px safe margin. ASCII text only.
2. Render the PNG with the first available tool: `rsvg-convert -w 1280 -h 640 docs/assets/social-preview.svg -o docs/assets/social-preview.png`. If that is missing, use `npx --yes @resvg/resvg-js-cli`, then fall back to `magick`. Check the size with `file docs/assets/social-preview.png`, which must report `1280 x 640`, and confirm the file is under 1 MB.
3. Write `docs/assets/README.md` recording the render command.
4. GitHub's REST API cannot upload the social preview. Add this manual step to the PR body for the maintainer: "Settings > General > Social preview > Edit > Upload `docs/assets/social-preview.png`."
5. Run `sh scripts/repo-settings_check.sh` (from T1.7) and report its output.

### Acceptance criteria

- The SVG and PNG exist. The PNG is exactly 1280x640 and under 1 MB.
- `scripts/repo-settings_check.sh` exits 0.
- The PR body contains the manual upload step.

### Verification

```bash
file docs/assets/social-preview.png
ls -l docs/assets/social-preview.png
sh scripts/repo-settings_check.sh
```
