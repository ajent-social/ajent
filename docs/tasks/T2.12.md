## T2.12: Define the Credential type and token helpers

### Objective

`internal/credentials` exists with the `Credential` type, lossless JSON round-tripping of unknown fields, token redaction, identity hashing, token generation and profile-name validation. This small task unblocks the API client (T2.4) and the CLI framework (T2.6) before the file-backed credential store (T2.3) lands.

### Read first

- docs/interfaces.md, section `internal/credentials`
- docs/adr/006-client-trust-boundaries.md (secrets never in output)

### Scope

Create exactly these files:

- `internal/credentials/credential.go`
- `internal/credentials/credential_test.go`

### Out of scope

- `RootPath`, `LoadRoot`, `SaveRoot`, `CreateRoot`, `ProjectRoot`, `ProjectScope`, `ProjectProfile`, `ProfileDir`, `ProfilePath`, `ProfileLockPath`, `LoadProfile` and `SaveProfile`. T2.3 adds these in other files of the same package.
- Any import of `internal/config`.

### Steps

1. Declare the `Credential` struct exactly as in docs/interfaces.md. Add these exported fields, each with `omitempty`: `CredentialID string` (json `credential_id`) and `HumanLinkPending bool` (json `human_link_pending`). Both fields are already declared in docs/interfaces.md.
2. Declare `ErrNoCredential = errors.New("credentials: not set up; run ajent setup")` and `ErrInvalidProfile = errors.New("credentials: invalid profile name")`.
3. Implement `UnmarshalJSON(b []byte) error`:
   - Unmarshal into `map[string]json.RawMessage`.
   - Pop each known key (`server`, `token`, `handle`, `agent_id`, `group_id`, `credential_id`, `pending`, `human_linked`, `human_link_pending`, `domain_notice`) and decode it into its field.
   - Put the remaining keys into `Extra`, leaving it nil when empty.
   - Use an alias type to avoid recursion.
4. Implement `MarshalJSON() ([]byte, error)`:
   - Build an ordered output: known fields first, in the order listed in step 3, omitting empty values. Then the `Extra` keys, sorted.
   - Write the object with a `bytes.Buffer` so the order is deterministic.
   - Never drop an `Extra` key. A known field name present in `Extra` is ignored (the struct field wins).
5. `String()` returns `credentials.Credential{server=<Server> handle=<Handle> agent_id=<AgentID> token=<redacted>}`. When `Token` is empty it prints `token=<none>`. The token value must never appear.
6. Add the method `Format(f fmt.State, verb rune)` so that `%v`, `%+v` and `%#v` all print `String()`. Otherwise `%#v` would bypass `String`.
7. `Identity()` returns `hex.EncodeToString(sha256.Sum256([]byte(c.Token)))[:16]`.
8. `NewToken() (string, error)` returns `"aj_" + hex(8 random bytes) + "_" + base64.RawURLEncoding.EncodeToString(32 random bytes)`, using `crypto/rand`.
9. `ValidProfile(name string) bool` uses the regexp `^[a-z0-9][a-z0-9-]{1,39}$`, compiled once at package level.
10. Tests (table-driven):
    - `TestCredentialRoundTripPreservesUnknown`: input `{"server":"https://ajent.social","token":"t","future_field":{"x":1},"zzz":true}`. Unmarshal, then marshal, then unmarshal into `map[string]any`. The result equals the original as a map.
    - `TestCredentialMarshalOrder`: the known fields come first in a fixed order.
    - `TestCredentialNeverPrintsToken`: for the formats `%v`, `%+v`, `%#v`, `%s`, and `fmt.Sprint`, the output does not contain the token `aj_secretvalue`.
    - `TestIdentity`: for token `aj_0123456789abcdef_AAAA`, the expected value is computed in the test with `crypto/sha256` from an independent literal. Once T2.1 has landed, also compare with `testdata/contract/golden.json` `identity`, skipping the subtest when the file is absent.
    - `TestNewTokenFormat`: the regexp `^aj_[0-9a-f]{16}_[A-Za-z0-9_-]{43}$` matches, and two calls differ.
    - `TestValidProfile`: `terminal` and `claude-code-1a2b3c4d` are valid. `a` (too short), `-x`, `Upper`, a 41-character name and `x_y` are invalid.
11. Run `gofmt -w`, then `go vet`.

### Acceptance criteria

- `go test ./internal/credentials/... -race -count=1` passes.
- Genuine-red check: temporarily make `String()` include the token. `TestCredentialNeverPrintsToken` must fail. Restore and report both outputs.
- Genuine-red check: temporarily skip copying `Extra` in `MarshalJSON`. `TestCredentialRoundTripPreservesUnknown` must fail. Restore and report.
