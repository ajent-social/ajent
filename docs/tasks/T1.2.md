## T1.2: Add the Apache-2.0 license, NOTICE and header check

### Objective

The repository carries the verbatim Apache License 2.0 in `LICENSE`, a `NOTICE` file, and a script that fails when a Go or shell source file lacks the SPDX header.

### Read first

- docs/adr/001-open-source-client-apache-2.md

### Scope

- `LICENSE`
- `NOTICE`
- `scripts/check-license-headers.sh`
- `scripts/testdata/license/good.go`
- `scripts/testdata/license/bad.go`
- `scripts/testdata/license/good.sh`
- `scripts/check-license-headers_test.sh`

### Out of scope

- Adding headers to files created by other tasks. Each task adds its own header.
- CI wiring. T1.4 calls the script from `ci.yml`.

### Steps

1. Download the canonical license text: `curl -fsSL https://www.apache.org/licenses/LICENSE-2.0.txt -o LICENSE`. Confirm that the first non-blank line is `Apache License` and that the file contains `END OF TERMS AND CONDITIONS`. Do not edit the text. Keep the appendix as published.
2. Create `NOTICE` with exactly:

   ```text
   ajent
   Copyright 2026 The Ajent Authors

   This product includes software developed by The Ajent Authors
   (https://github.com/ajent-social/ajent-client).

   The "Ajent" name and logo are not licensed under the Apache License.
   ```

3. Create `scripts/check-license-headers.sh` (POSIX `sh`, `set -eu`):
   - First line `#!/bin/sh`, second line `# SPDX-License-Identifier: Apache-2.0`.
   - Usage: `scripts/check-license-headers.sh [dir]`. The default dir is `.`.
   - Find files with `find "$dir" -type f \( -name '*.go' -o -name '*.sh' -o -name '*.ps1' \)`, excluding paths that contain `/testdata/`, `/vendor/`, `/.git/` or `/dist/`.
   - For `.go` files: one of the first 3 lines must equal `// SPDX-License-Identifier: Apache-2.0`. Lines 1 to 3 are allowed because of `//go:build` constraints.
   - For `.sh` and `.ps1` files: one of the first 3 lines must equal `# SPDX-License-Identifier: Apache-2.0`.
   - Print `missing SPDX header: <path>` for each failure. Exit 1 if any failure, else exit 0 with no output.
   - Environment `LICENSE_CHECK_INCLUDE_TESTDATA=1` disables the testdata exclusion, which the self-test needs.
4. Create fixtures: `good.go` (header on line 1, then `package license`), `bad.go` (only `package license`), and `good.sh` (shebang then header).
5. Create `scripts/check-license-headers_test.sh`:
   - Copy `good.go` and `good.sh` into a `mktemp -d` dir, run the checker on it, and expect exit 0.
   - Add `bad.go`, run again, and expect exit 1 with output containing `bad.go`.
   - Print `PASS` or `FAIL: <reason>` and exit accordingly.
6. `chmod +x` both scripts. Also run `shellcheck` on both scripts if it is installed. If not, record that it was skipped.

### Acceptance criteria

- `scripts/check-license-headers.sh` exits 0 on the repository tree once all Go and shell files carry headers. Files from T1.1 already do. If a file created by another task lacks one, list it in the PR body and do not edit it.
- `sh scripts/check-license-headers_test.sh` prints `PASS`.
- `LICENSE` matches the SPDX Apache-2.0 text. `grep -c "TERMS AND CONDITIONS FOR USE, REPRODUCTION, AND DISTRIBUTION" LICENSE` prints 1.
- Genuine-red check: delete the header line from `scripts/testdata/license/good.go`, run the self-test, and observe `FAIL`. Restore the line and observe `PASS`. Report both outputs.

### Verification

```bash
sh scripts/check-license-headers_test.sh
scripts/check-license-headers.sh .
shellcheck scripts/check-license-headers.sh scripts/check-license-headers_test.sh || true
```
