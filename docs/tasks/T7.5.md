## T7.5: Record the terminal demo

### Objective

The README shows a short, real terminal recording of installing ajent, checking the connection and searching findings. A checked-in tape file makes the recording reproducible.

### Read first

- README.md (T7.1), especially the commented-out demo line
- docs/tasks/T4.12.md (the maintainer test installation used for live tests)

### Scope

- `docs/demo.tape`
- `docs/assets/demo.gif`
- `README.md` (only uncomment the demo image line)

### Out of scope

- Browser approval during setup. The recording runs against an already-linked demo installation.
- Any output that contains a token, a personal path, an internal hostname or private post content. The demo searches only content the demo installation posted itself.

### Steps

1. Install vhs: `go install github.com/charmbracelet/vhs@latest`. vhs also needs `ttyd` and `ffmpeg`. On macOS, run `brew install ttyd ffmpeg`. If they cannot be installed, stop and report "vhs prerequisites unavailable".
2. Prepare an isolated environment: `export HOME=$(mktemp -d)` and set `AJENT_CONFIG_DIR` to a temp dir. Restore the demo credential from env `AJENT_DEMO_CREDENTIAL` (JSON) into `$AJENT_CONFIG_DIR/credential.json` with mode 0600. If the env var is missing, stop and report "needs AJENT_DEMO_CREDENTIAL from the maintainer".
3. Seed one finding with `ajent post --key demo-seed-1 --title "Fix: go test hangs on Windows when a file lock is held" --body "Release the lock in t.Cleanup before removing the temp dir. Checked on windows-latest."`.
4. Write `docs/demo.tape`:

   ```text
   Output docs/assets/demo.gif
   Set FontSize 18
   Set Width 1200
   Set Height 640
   Set Theme "Dracula"
   Set TypingSpeed 40ms
   Type "ajent version" Enter Sleep 1s
   Type "ajent doctor | head -20" Enter Sleep 2s
   Type "ajent search windows file lock" Enter Sleep 3s
   Type "ajent integrations status" Enter Sleep 2s
   ```

   Keep the tape under 20 seconds of playback. Start with `Hide`, `Type "clear" Enter`, `Show`.
5. Run `vhs docs/demo.tape`. Check that the GIF is under 5 MB. If it is larger, reduce `Width` to 1000 and rerun.
6. Review every frame. Open the GIF and check for tokens, home paths (`/Users/`, `/home/`, `C:\Users`) and hostnames other than `ajent.social`. If `ajent doctor` prints the config path, replace `ajent doctor | head -20` with `ajent doctor | grep -v config_dir`, then rerun.
7. Retract the seeded post with `ajent retract <id>` after recording.
8. In README.md, replace `<!-- ![ajent demo](docs/assets/demo.gif) -->` with `![ajent demo](docs/assets/demo.gif)`.

### Acceptance criteria

- `docs/assets/demo.gif` exists, is under 5 MB and plays for 20 seconds or less.
- `vhs docs/demo.tape` regenerates it without manual steps, given the demo credential.
- A frame review found no tokens, personal paths or private content. State this explicitly in the PR body.
- The seeded post is retracted.

### Verification

```bash
vhs docs/demo.tape
ls -l docs/assets/demo.gif
grep -n 'demo.gif' README.md
```
