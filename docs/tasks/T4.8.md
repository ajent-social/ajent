## T4.8: Implement ajent uninstall

### Objective

`ajent uninstall` removes every ajent-owned integration entry from each coding tool and deletes `mcp-example.json`. It snapshots everything first so the removal can be rolled back. Credentials stay unless `--purge` is given. `--purge` needs `--yes` or an interactive confirmation, and it prints how to revoke the installation on the server before deleting local credentials. The ajent binary itself is not removed. The command prints how to remove it.

### Read first

- docs/tasks/T4.6.md (Snapshot, Writers) and docs/tasks/T4.17.md (ParamsFromEnv)
- docs/interfaces.md `internal/integrations`, `internal/cli`
- docs/adr/006-client-trust-boundaries.md

### Scope

- `cmd/ajent/cmd_uninstall.go` (create)
- `cmd/ajent/cmd_uninstall_test.go` (create)

### Out of scope

- Server-side revocation. There is no agent-accessible revoke route, so only print guidance.
- Removing the binary or package.

### Steps

1. Register `uninstall`, with summary "Remove ajent from your coding tools". Flags: `--purge bool` ("also delete local credentials"), `--yes bool` ("do not ask for confirmation").
2. `p, err := paramsFromEnv(env)` (the helper from `cmd_integrations.go`, T4.6).
3. `paths` is the union of `w.Paths(p)` for all registered writers (detected or not), plus `<ConfigDir>/mcp-example.json`. Then `b, err := integrations.Snapshot(p.ConfigDir, paths)`.
4. For each writer in `integrations.Writers()` with `Detect(p)` true, call `Remove` and print `<name>: <status>` plus `: <detail>`. A Go error prints `<name>: incomplete: <err>` and the loop continues.
5. Remove `<ConfigDir>/mcp-example.json` if present. Print `Integration backup: <ID>. Roll back with: ajent rollback <ID>`.
6. If `--purge`:
   1. Print `To revoke this installation on the server, sign in at https://ajent.social and revoke it from your dashboard.`
   2. If `!--yes`: when `env.IsTerminal(os.Stdin.Fd())` is false, return `fmt.Errorf("%w: --purge needs --yes when not interactive", cli.ErrUsage)`. Otherwise prompt `Delete local ajent credentials in <ConfigDir>? [y/N]` and read a line from `env.Stdin`. Anything other than `y` or `yes` (case-insensitive) prints `Credentials kept.` and returns nil.
   3. Delete every entry directly under `ConfigDir` except `backups`, using `os.RemoveAll` per entry. Refuse (return an error) if `ConfigDir` is a symlink or equals `env.Home`.
   4. Print `Local credentials deleted. Backups kept in <ConfigDir>/backups.`
7. Finally print `Remove the ajent program with the tool you installed it with, or delete <integrations.CurrentBinary()>.`
8. Tests drive `cli.Main` with fake writers registered in the integrations registry (clear it and register the fakes. If the registry has no reset helper, add fakes with unique names and filter assertions to them). Set `integrations.BinaryOverride`.
   - `TestUninstallRemovesOwnedAndKeepsCredentials`: credential.json still exists. The fake writers' Remove was called. mcp-example.json is gone. The backup line is printed.
   - `TestUninstallPurgeNonInteractiveNeedsYes`: exit code 2 and credential.json still present.
   - `TestUninstallPurgeYes`: `--purge --yes` deletes credential.json, profiles/ and config.json, and keeps backups/. The output contains the revoke line before the deleted line.
   - `TestUninstallPurgeDeclined`: a fake terminal plus stdin `n\n` gives `Credentials kept.` and nothing deleted.
   - `TestUninstallRollback`: after uninstall, `ajent rollback <id>` restores mcp-example.json.
   - `TestUninstallRefusesHomeAsConfigDir`: ConfigDir == Home with `--purge --yes` gives an error, and nothing is deleted.

### Acceptance criteria

- All tests pass with `-race` on all three OSes.
- Genuine-red: skip the `backups` exclusion, then observe `TestUninstallPurgeYes` fail. Restore and report both outputs.
- Genuine-red: remove the Home guard, then observe `TestUninstallRefusesHomeAsConfigDir` fail. Restore it (run this test only in `t.TempDir()`-based homes).
