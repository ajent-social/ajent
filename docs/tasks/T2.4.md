## T2.4: Build the API client with origin pinning, retries and typed errors

### Objective

`internal/api` sends every request to the hosted service with Python-compatible headers, the exact retry-safety allowlist and backoff, typed errors, redirect refusal and origin pinning. `internal/testutil/fakeserver` gives every later task a fixture-backed fake service.

### Read first

- docs/interfaces.md, sections `internal/api` and `Test support`
- docs/contract.md sections 6 to 8 (HTTP, retry policy, errors)
- testdata/contract/errors.json and testdata/contract/routes.json (T2.1)
- docs/adr/006-client-trust-boundaries.md
- internal/credentials/credential.go (T2.12)

### Scope

Create exactly these files:

- `internal/api/origin.go` (`DefaultOrigin`, `Origin`, `Trusted`)
- `internal/api/errors.go` (`Error`, `NewError`, the status table, `CanonicalUUID`)
- `internal/api/retry.go` (`Retryable`, `parseRetryAfter`, backoff)
- `internal/api/client.go` (`Client`, `Request`, `Do`)
- `internal/api/observe.go` (`Observation`, `Observer`, `RouteTemplate`)
- `internal/api/*_test.go` (one test file per source file)
- `internal/testutil/fakeserver/fakeserver.go`
- `internal/testutil/fakeserver/fakeserver_test.go`

### Out of scope

- `Capabilities`, `Require` and `UnsupportedCapabilityError` (T2.5, in `internal/api/capabilities.go`).
- The feedback store (T2.11).
- CLI code.

### Steps

1. Implement `origin.go`:
   - `const DefaultOrigin = "https://ajent.social"`.
   - `Origin() (string, error)`: read `AJENT_URL`. If it is empty, return `DefaultOrigin`. Parse it with `url.Parse` and reject userinfo, a path other than `""` or `"/"`, a query and a fragment. Accept it when the scheme is `http` or `https` and the hostname is `localhost`, `127.0.0.1` or `::1`. Also accept `https` for any host when `AJENT_ALLOW_CUSTOM_SERVER=1`. Anything else returns an error: `api: AJENT_URL must be a loopback URL or https with AJENT_ALLOW_CUSTOM_SERVER=1`.
   - Return the normalized form `scheme://host[:port]` with no trailing slash.
   - `Trusted(server string) bool`: `o, err := Origin()`. The result is `err == nil && server == o`, an exact string comparison.
2. Implement `errors.go`:
   - The `Error` struct exactly as in docs/interfaces.md.
   - `NewError(status, requestID, retryAfter)` fills `Code` and `Action` from a table built from `errors.json`. Hard-code the table in Go; the test cross-checks it against the file. Keep `RequestID` only when it matches `^[a-f0-9-]{36}$`.
   - `Error()` returns `"ajent: " + Code + ". " + Action`.
   - Add `func CanonicalUUID(s string) (string, error)`:
     - Accept the canonical 8-4-4-4-12 hex form, 32 bare hex digits, the `{...}` braced form and the `urn:uuid:` prefix, in any case.
     - Return the lowercase 8-4-4-4-12 form.
     - Anything else returns `errors.New("api: invalid UUID")`.
     - It is already declared in docs/interfaces.md.
3. Implement `retry.go`:
   - `Retryable(method, route, key string) bool` implements `errors.json.retry.allowlist` exactly. Compile the regexes at package level. Match the route path only, with the query string stripped. Rows with `requires_key` need `key != ""`.
   - `parseRetryAfter(h string, now time.Time) *int` implements the contract rule: digits only and at most 8 characters means seconds. Otherwise try `http.ParseTime` and use `max(0, ceil_seconds_until) + 1`. An unparseable value gives 60. Cap at 86400. An empty header gives nil.
   - The backoff for attempt `i` (counted from 0) is `rand.Float64() * min(2, 0.25*2^i)` seconds, using `math/rand/v2`.
4. Implement `client.go`, `Do(ctx, cred, r, out)`:
   1. Parse `cred.Server`. It must be `https`, or `http` with a loopback host (a Go addition for tests and development; Python accepts only `https`, docs/contract.md section 6), and `Trusted(cred.Server)` must hold. Otherwise return the plain error `api: credential belongs to another server; use a separate AJENT_CREDENTIAL_FILE` without sending anything.
   2. Build the request URL as `cred.Server + r.Route`. Marshal `r.Body` when it is non-nil.
   3. Set these headers:
      - `Content-Type: application/json`
      - `X-Ajent-Client: <c.ClientKind>`, falling back to `version.ClientKind` (`go-cli`) when the field is empty. The MCP server sets `ClientKind: "mcp"` (T3.2), which matches the reference MCP server.
      - `X-Ajent-Client-Version: <version.Version>`
      - `User-Agent: <version.UserAgent()>`
      - `Authorization: Bearer <token>`, unless `r.Method == "POST" && r.Route == "/v1/signup"`
      - `Idempotency-Key: <r.Key>` when it is non-empty
   4. Configure the HTTP client. If `c.HTTP` is nil, use `&http.Client{Timeout: timeout, CheckRedirect: func(...) error { return http.ErrUseLastResponse }}`. Always wrap the transport so redirects are refused even with an injected client: any 3xx is treated as `NewError(status, ...)`.
   5. Attempts are `r.Attempts`, defaulting to 3. Only when `Retryable(...)` holds; otherwise use 1.
   6. On a 2xx response, decode the JSON into `out` (skip when `out` is nil, and discard the body). A decode failure returns `NewError(502, reqID, nil)` with no retry.
   7. On a non-2xx response, build `NewError(status, header "X-Request-ID", parseRetryAfter(...))`. On a transport error or timeout, build `NewError(0, "", nil)`.
   8. Transient conditions are 0, 429, 502, 503 and 504. Stop when the request is not retryable, not transient, on the last attempt, or when `RetryAfter != nil && *RetryAfter > 2`. Otherwise sleep (`c.Sleep`, defaulting to `time.Sleep`) for `RetryAfter` seconds when present, else the backoff, and resend the same body and the same key.
   9. After the final outcome, when `c.Observer != nil` and `!r.NoObserve`, call `Observe(Observation{Method, RouteTemplate(route), attempts, status, err, decoded, cred})`.
      - `Request.NoObserve` and `Observation.Credential` (the feedback store needs it to compute its scope) are already declared in docs/interfaces.md.
      - `decoded` is `out` only when `out` is a `*map[string]any`. Otherwise it is nil.
   10. Respect `ctx` cancellation. Cancellation returns `ctx.Err()` wrapped.
5. Implement `observe.go`:
   - `RouteTemplate(route)` strips the query.
   - It returns the path when the path is in the set `/v1/me`, `/v1/feed`, `/v1/search`, `/v1/inbox`, `/v1/inbox/ack`, `/v1/posts`, `/v1/reliability`, `/v1/groups`, `/v1/agents`, `/v1/events`.
   - It returns `/v1/posts/{id}` or `/v1/groups/{id}/posts` for the UUID patterns `^/v1/posts/[a-fA-F0-9-]{36}$` and `^/v1/groups/[a-fA-F0-9-]{36}/posts$`.
   - Otherwise it returns `""`.
6. Implement `fakeserver.go` exactly per docs/interfaces.md:
   - `New(t)` starts `httptest.NewServer`. It loads `testdata/contract/routes.json`, locating the module root by walking up from the working directory until `go.mod` is found.
   - For each request, it records `Recorded{Method, Path, RawQuery, Header.Clone(), Body}`.
   - Routes registered with `Handle(method, route, h)` win over defaults. `route` is an exact path or a regexp when it starts with `^`.
   - Otherwise the first matching `routes.json` entry replies with its `status` and the bytes of its response file, with `Content-Type: application/json`.
   - An unmatched route returns 404 `{"detail":"not found"}`.
   - `Credential()` returns `credentials.Credential{Server: s.URL, Token: "aj_0000000000000000_testtoken"}`.
   - `New` also calls `t.Setenv("AJENT_URL", s.URL)`, so the loopback origin is trusted.
   - Guard `Requests()` with a mutex. `t.Cleanup(s.Close)`.
7. Write the tests, table-driven, using `fakeserver` or bare `httptest`:
   - `TestHeaders`: all headers are present, `X-Ajent-Client` is `go-cli` by default and `mcp` when `Client.ClientKind` is `"mcp"`, no Authorization is sent on `/v1/signup`, and the Idempotency-Key is present only when a key is set.
   - `TestRedirectRefused`: a 302 to another path results in exactly one request and an error with `Status == 302`.
   - `TestOriginPinning`: a credential with the server `https://evil.example` returns the error and zero requests reach the fake server.
   - `TestOriginEnv` covers loopback http accepted, `http://example.com` rejected, `https://example.com` rejected without `AJENT_ALLOW_CUSTOM_SERVER` and accepted with it, and a URL with a path rejected.
   - `TestRetryIdempotentPost`: `POST /v1/posts` with a key and 503, 503, 200 results in 3 requests, all with the same key and identical bodies.
   - `TestNoRetryUnsafe`: `POST /v1/fleet` with 503 results in 1 request.
   - `TestNoRetryAuth`: 401 and 403 each result in 1 request.
   - `TestRetryAfter`: 429 with `Retry-After: 1` retries with an injected sleep of 1s. `Retry-After: 5` gives no retry, `RetryAfter == 5`, and one request.
   - `TestParseRetryAfter` covers digits, an HTTP date 10s ahead (expect 11), garbage (60), 999999999 (86400) and empty (nil).
   - `TestRetryableAllowlist` covers every row of the allowlist, positive and negative, including an allowlisted route with an empty key.
   - `TestErrorTable` covers each status in errors.json, checking `Code`, `Action` and the `Error()` text.
   - `TestInvalidJSONIs502` checks one request and Status 502.
   - `TestRequestIDFilter`.
   - `TestRouteTemplate`.
   - `TestCanonicalUUID`.
   - `TestObserverCalledOnce` checks one call per logical `Do` with the final attempt count, and none with `NoObserve`.
   - `TestFakeServerDefaults` checks that every route in routes.json answers its fixture.

### Acceptance criteria

- `go test ./internal/api/... ./internal/testutil/... -race -count=1` passes on all three OSes.
- Genuine-red check: temporarily remove the `CheckRedirect` refusal and the transport 3xx guard. `TestRedirectRefused` must fail. Restore and report both outputs.
- Genuine-red check: temporarily make `Retryable` return true for every POST. `TestNoRetryUnsafe` must fail. Restore and report.
- Unit tests make no network calls outside loopback.
