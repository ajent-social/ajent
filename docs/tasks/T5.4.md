## T5.4: Sign and notarize the macOS binaries

### Objective

Release builds sign the darwin binaries with the Developer ID Application certificate and notarize them with Apple, using GoReleaser's cross-platform `notarize.macos` support. On a Mac, `codesign --verify --strict` and `spctl --assess --type execute` accept the released binaries. Builds without the secrets (snapshots, forks) skip this step automatically.

### Read first

- docs/adr/004-release-signing.md
- docs/tasks/T5.14.md (secret names and formats)
- GoReleaser documentation: customization > notarize (macOS, cross-platform mode)
- `.goreleaser.yaml` (the `notarize (T5.4)` marker block)

### Scope

Modify only:

- `.goreleaser.yaml`, between `# ---- BEGIN notarize (T5.4) ----` and `# ---- END notarize (T5.4) ----`.
- `.github/workflows/macos-signing-check.yml` (create)

### Out of scope

- Workflow wiring of the secrets into the release job (T5.11 passes `MACOS_*` as env). Homebrew cask (T5.5). Windows signing.

### Steps

1. Confirm T5.14 is done: `gh secret list --env release --repo ajent-social/ajent-client | grep -c MACOS_` prints 5. If it does not, implement steps 2 to 4 anyway (they are inert without secrets), skip the acceptance items that need a signed release, and report the task as partially blocked on T5.14.
2. Fill the marker block:

   ```yaml
   # ---- BEGIN notarize (T5.4) ----
   notarize:
     macos:
       - enabled: '{{ isEnvSet "MACOS_SIGN_P12" }}'
         ids: [ajent]
         sign:
           certificate: "{{ .Env.MACOS_SIGN_P12 }}"
           password: "{{ .Env.MACOS_SIGN_PASSWORD }}"
         notarize:
           issuer_id: "{{ .Env.MACOS_NOTARY_ISSUER_ID }}"
           key_id: "{{ .Env.MACOS_NOTARY_KEY_ID }}"
           key: "{{ .Env.MACOS_NOTARY_KEY }}"
           wait: true
           timeout: 20m
   # ---- END notarize (T5.4) ----
   ```

   Check each field name against the documentation of the pinned GoReleaser version. If a name differs, use the documented one and report the change. `certificate` and `key` take base64 contents, which match the T5.14 formats.
3. Run `goreleaser check`, then a snapshot with the notarize step enabled but without secrets (`goreleaser release --snapshot --clean --skip=sign,publish`). The notarize step must be skipped (log line "skipped" or "disabled") and the build must succeed.
4. Create `.github/workflows/macos-signing-check.yml`, triggered by `workflow_dispatch` with input `tag` (required), `permissions: contents: read`, and one job on `macos-latest`:
   - Download the darwin arm64 and amd64 archives for the tag with `gh release download "$TAG" --repo ajent-social/ajent-client --pattern 'ajent_*_darwin_*.tar.gz'`, then extract them.
   - For each binary, run `codesign --verify --strict --verbose=2 ajent`, `codesign -dv --verbose=4 ajent 2>&1 | grep -q "Authority=Developer ID Application"` and `spctl --assess --type execute --verbose ajent`. Also run `xattr -w com.apple.quarantine "0081;$(printf %x $(date +%s));Safari;" ajent && ./ajent version`, which must print the version (Gatekeeper accepts a quarantined, notarized binary).
   - SHA-pin every action. Run `actionlint`.
5. After T5.11 has produced a real signed release (or a signed prerelease `v0.7.0-rc.1` authorized by the maintainer), run `gh workflow run macos-signing-check.yml -f tag=<tag>` and wait for green.

### Acceptance criteria

- `goreleaser check` exits 0 and the secretless snapshot succeeds with notarize skipped.
- `actionlint` passes on `macos-signing-check.yml`.
- With T5.14 done and a signed release available, `macos-signing-check.yml` is green. `spctl` prints `accepted` and `source=Notarized Developer ID` for both architectures. Record the run URL.
- Genuine-red: run `macos-signing-check.yml` against an unsigned snapshot archive uploaded to a draft test release (or run its steps locally on a snapshot binary). `spctl --assess` rejects it. Report both outputs, then delete the draft release.

### Verification

- `go run github.com/goreleaser/goreleaser/v2@<GR> check`
- `go run github.com/goreleaser/goreleaser/v2@<GR> release --snapshot --clean --skip=sign,publish`
- `go run github.com/rhysd/actionlint/cmd/actionlint@latest .github/workflows/macos-signing-check.yml`
- `gh run list --workflow macos-signing-check.yml --repo ajent-social/ajent-client --limit 1`
