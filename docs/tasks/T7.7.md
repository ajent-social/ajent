## T7.7: Write the launch-ready release notes template

### Objective

Every GitHub release page opens with the install and verify commands, followed by changes grouped by type. A visitor arriving from a release link can install without leaving the page.

### Read first

- docs/tasks/T5.1.md (release-please configuration)
- docs/adr/003-distribution-channels.md, docs/adr/004-release-signing.md

### Scope

- `.github/release.yml`
- `.github/release-notes-header.md`
- `release-please-config.json` (only add the `changelog-sections` key; T5.1 owns the file)

### Out of scope

- GoReleaser configuration (T5.2). T5.11 wires the header into the release. Note in the PR body that `.goreleaser.yaml` should set `release.header` from this file with `{{ .Tag }}` substitution.
- Marketing announcements (E9).

### Steps

1. `.github/release.yml` (categories for GitHub-generated notes):

   ```yaml
   changelog:
     exclude:
       labels: [skip-changelog]
     categories:
       - title: Features
         labels: [enhancement, feature]
       - title: Fixes
         labels: [bug, fix]
       - title: Coding tool support
         labels: [harness]
       - title: Documentation
         labels: [documentation]
       - title: Other changes
         labels: ["*"]
   ```

2. `.github/release-notes-header.md`: a Go-template-friendly Markdown block (GoReleaser renders `{{ .Tag }}` and `{{ .Version }}`):

   ```markdown
   ## Install

   macOS and Linux:

       curl -fsSL https://ajent.social/install.sh | sh

   Windows (PowerShell):

       irm https://ajent.social/install.ps1 | iex

   Homebrew: `brew install ajent-social/tap/ajent`. Other channels: see docs/install.md.

   Already installed? Script installs update automatically. Package managers: `brew upgrade ajent`, `sudo apt upgrade`, `scoop update ajent`, `winget upgrade AjentSocial.Ajent`.

   ## Verify

   Download `checksums.txt` and `checksums.txt.sig`, then follow docs/verifying-releases.md, or run:

       gh attestation verify ajent_{{ .Version }}_linux_amd64.tar.gz --repo ajent-social/ajent-client
   ```

   Use absolute GitHub URLs for the docs links: `https://github.com/ajent-social/ajent-client/blob/main/docs/install.md`.
3. In `release-please-config.json`, add under the package entry:

   ```json
   "changelog-sections": [
     {"type": "feat", "section": "Features"},
     {"type": "fix", "section": "Fixes"},
     {"type": "perf", "section": "Performance"},
     {"type": "docs", "section": "Documentation"},
     {"type": "chore", "section": "Other changes", "hidden": true},
     {"type": "ci", "section": "Other changes", "hidden": true},
     {"type": "test", "section": "Other changes", "hidden": true}
   ]
   ```

   If `release-please-config.json` does not exist yet, stop and report "blocked on T5.1".
4. Validate with `python3 -m json.tool release-please-config.json` and parse `.github/release.yml` with any YAML parser.

### Acceptance criteria

- Both new files exist and parse. `release-please-config.json` is valid JSON with `changelog-sections`.
- The header contains the install one-liners for both OS families and a verify section.
- ASCII only, and no hosts other than `ajent.social` and `github.com`.

### Verification

```bash
python3 -m json.tool release-please-config.json >/dev/null && echo json-ok
ruby -ryaml -e 'YAML.load_file(".github/release.yml")' && echo yaml-ok
LC_ALL=C grep -n '[^ -~]' .github/release-notes-header.md .github/release.yml || echo ascii-ok
```
