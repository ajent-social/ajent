## T5.2: Add the GoReleaser base configuration

### Objective

`.goreleaser.yaml` builds six static binaries (darwin, linux and windows on amd64 and arm64), packs them into versioned archives with LICENSE, NOTICE and README.md, and writes `checksums.txt` and SBOMs. Each binary reports the injected version. The file contains delimited, empty sections that later tasks fill without touching each other's lines, and a CI job runs a snapshot build on every PR that touches release files.

### Read first

- docs/adr/003-distribution-channels.md
- docs/interfaces.md, section "internal/version" (ldflags variable paths)
- GoReleaser v2 documentation: builds, archives, checksum, sboms, release, snapshot

### Scope

Create only:

- `.goreleaser.yaml`
- `.github/workflows/release-snapshot.yml`

### Out of scope

- `signs` (T5.3), `notarize` (T5.4), `homebrew_casks` (T5.5), `nfpms` (T5.6), `scoops` and `winget` (T5.8). Create their marker blocks only, exactly as in step 3, with no keys between the markers.
- The publishing workflow (T5.11).

### Steps

1. Find the pinned GoReleaser version: `gh api repos/goreleaser/goreleaser/releases/latest -q .tag_name` (at plan time it was `v2.18.2`; use whatever v2.x is latest). Call it `GR`. Run GoReleaser locally with `go run github.com/goreleaser/goreleaser/v2@$GR`.
2. Install syft for SBOMs locally (`brew install syft`, or on Linux `curl -sSfL https://raw.githubusercontent.com/anchore/syft/main/install.sh | sh -s -- -b /usr/local/bin`).
3. Create `.goreleaser.yaml` with exactly this content (fill `<GR>` in the comment):

   ```yaml
   # SPDX-License-Identifier: Apache-2.0
   # GoReleaser <GR>. Sections below are owned by different plan tasks.
   # Edit only the lines between your own BEGIN and END markers.
   version: 2
   project_name: ajent

   # ---- BEGIN base (T5.2) ----
   before:
     hooks:
       - go mod tidy
   builds:
     - id: ajent
       main: ./cmd/ajent
       binary: ajent
       env:
         - CGO_ENABLED=0
       flags:
         - -trimpath
       ldflags:
         - -s -w
         - -X github.com/ajent-social/ajent-client/internal/version.Version={{ .Version }}
         - -X github.com/ajent-social/ajent-client/internal/version.Commit={{ .ShortCommit }}
         - -X github.com/ajent-social/ajent-client/internal/version.Date={{ .CommitDate }}
       mod_timestamp: "{{ .CommitTimestamp }}"
       goos: [darwin, linux, windows]
       goarch: [amd64, arm64]
   archives:
     - id: default
       ids: [ajent]
       name_template: "ajent_{{ .Version }}_{{ .Os }}_{{ .Arch }}"
       formats: [tar.gz]
       format_overrides:
         - goos: windows
           formats: [zip]
       files:
         - LICENSE
         - NOTICE
         - README.md
   checksum:
     name_template: checksums.txt
     algorithm: sha256
   sboms:
     - artifacts: archive
   snapshot:
     version_template: "{{ incpatch .Version }}-SNAPSHOT-{{ .ShortCommit }}"
   changelog:
     disable: true
   release:
     github:
       owner: ajent-social
       name: ajent
     mode: keep-existing
     replace_existing_artifacts: false
   # ---- END base (T5.2) ----

   # ---- BEGIN signs (T5.3) ----
   # ---- END signs (T5.3) ----

   # ---- BEGIN notarize (T5.4) ----
   # ---- END notarize (T5.4) ----

   # ---- BEGIN homebrew_casks (T5.5) ----
   # ---- END homebrew_casks (T5.5) ----

   # ---- BEGIN nfpms (T5.6) ----
   # ---- END nfpms (T5.6) ----

   # ---- BEGIN scoops and winget (T5.8) ----
   # ---- END scoops and winget (T5.8) ----
   ```

   The changelog is disabled because release-please writes the release notes (T5.1). `mode: keep-existing` keeps the release body release-please created and uploads artifacts into that release.
4. If `goreleaser check` rejects a key because the pinned version renamed it (for example `formats` versus `format`), use the name that version documents and state the change in your report. Do not change the archive name template, the ldflags variable paths or the goos and goarch lists.
5. Create `.github/workflows/release-snapshot.yml`:
   - `on: pull_request` with `paths: ['.goreleaser.yaml', 'cmd/**', 'internal/tools/**', 'packaging/**', 'scripts/install.*', '.github/workflows/release-snapshot.yml']`, plus `workflow_dispatch`.
   - `permissions: contents: read`.
   - One job `snapshot` on `ubuntu-latest`: `actions/checkout` (SHA-pinned, `fetch-depth: 0`), `actions/setup-go` (SHA-pinned, `go-version-file: go.mod`), `anchore/sbom-action/download-syft` (SHA-pinned), `goreleaser/goreleaser-action` (SHA-pinned, `version: <GR>`, `args: release --snapshot --clean --skip=sign,notarize,publish`), then `actions/upload-artifact` (SHA-pinned) with name `dist` and path `dist/`, retention 3 days.
   - A final step that runs `./dist/ajent_linux_amd64_v1/ajent version --json` and asserts with `jq -e '.version | test("SNAPSHOT")'`. The build directory name may differ between GoReleaser versions, so resolve the path with `find dist -type f -name ajent -path '*linux_amd64*' | head -1`.
   - Look up each action's pinned SHA with `gh api repos/<owner>/<repo>/releases/latest -q .tag_name`, then resolve the tag to a commit SHA as in docs/tasks/T5.1.md step 3. Write `uses: owner/repo@<sha> # <tag>`.
6. Run locally: `go run github.com/goreleaser/goreleaser/v2@$GR check`, then `go run github.com/goreleaser/goreleaser/v2@$GR release --snapshot --clean --skip=sign,notarize,publish`.
7. List `dist/` and confirm six archives (`*_darwin_amd64.tar.gz`, `*_darwin_arm64.tar.gz`, `*_linux_amd64.tar.gz`, `*_linux_arm64.tar.gz`, `*_windows_amd64.zip`, `*_windows_arm64.zip`), `checksums.txt` and one `.sbom.json` per archive.

### Acceptance criteria

- `goreleaser check` exits 0.
- The snapshot run exits 0 and `dist/` contains exactly the six archives, `checksums.txt`, and six SBOM files.
- `tar -tzf dist/ajent_*_linux_amd64.tar.gz` lists `ajent`, `LICENSE`, `NOTICE` and `README.md`. The zip for windows_amd64 contains `ajent.exe`.
- The extracted linux_amd64 binary prints a version containing `SNAPSHOT` from `ajent version --json` (run it on a linux runner or in `docker run --rm -v $PWD/dist:/d debian:stable`; on macOS run the darwin binary instead).
- `file` on the extracted linux binary reports `statically linked`.
- Genuine-red: remove the `-X ...Version=` ldflags line, rerun the snapshot, and observe `version` print `dev`. Restore the line, rerun, and report both outputs.
- `actionlint` passes on `release-snapshot.yml`.

### Verification

- `go run github.com/goreleaser/goreleaser/v2@$GR check`
- `go run github.com/goreleaser/goreleaser/v2@$GR release --snapshot --clean --skip=sign,notarize,publish && ls dist`
- `go run github.com/rhysd/actionlint/cmd/actionlint@latest .github/workflows/release-snapshot.yml`
