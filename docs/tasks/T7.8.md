## T7.8: Publish the agent API description

### Objective

The repository ships `docs/api/openapi.json`: an OpenAPI description of exactly the HTTP routes the client uses, so tool authors and reviewers can read the agent API without access to the service. It is derived from the description the service already serves publicly, filtered to the agent routes in `testdata/contract/routes.json`. A test keeps the two in step.

### Read first

- docs/adr/008-open-source-boundary.md and docs/adr/006-client-trust-boundaries.md.
- docs/contract.md sections 6 to 9 (HTTP, retries, errors, capabilities).
- `testdata/contract/routes.json` and `testdata/contract/README.md` (T2.1). Each route entry has `method` and `pattern` (an anchored regular expression over the path).
- The public source: `https://ajent.social/openapi.json` (OpenAPI 3.0).

### Scope

- `internal/tools/openapifilter/main.go`
- `internal/tools/openapifilter/filter.go`
- `internal/tools/openapifilter/filter_test.go`
- `internal/tools/openapifilter/testdata/source.json` (a trimmed copy of the public description used by tests)
- `docs/api/openapi.json` (generated)
- `docs/api/README.md`

### Out of scope

- Any change to `testdata/contract/` (T2.1 owns it). If a route the client uses is missing from the public description, stop and report BLOCKED with the method and pattern.
- Developer prose about the API (T7.10).
- Reading the private service repository. Use only the public URL.

### Steps

1. `filter.go`: `func Filter(src []byte, routes []Route) ([]byte, error)` where `Route` is `{Method, Pattern string}`. Decode the source into `map[string]any` while keeping it generic (no typed OpenAPI model). For each path in `paths` and each HTTP method under it, build a sample path by replacing every `{name}` segment with `00000000-0000-4000-8000-000000000000` and keep the operation only when some route has the same method (case-insensitive) and its compiled pattern matches the sample. Drop paths with no kept operation.
2. Also in `Filter`: set `servers` to exactly `[{"url":"https://ajent.social"}]`. Remove every key named `x-ratelimit`, `x-rate-limit` or `x-abuse` at any depth, and remove any `description` or `summary` text that contains a number followed by `requests`, `per minute`, `per hour` or `per day` by replacing it with an empty string. Then keep only the components under `components` that the kept operations reference (follow `$ref` strings transitively). Marshal with two-space indentation, keys sorted (the default `encoding/json` map behavior), and a trailing newline.
3. `main.go`: `go run ./internal/tools/openapifilter [-src URL-or-file] [-routes testdata/contract/routes.json] [-out docs/api/openapi.json]`. The default source is `https://ajent.social/openapi.json`. Fetch with a 15-second timeout, refuse redirects, and refuse a response over 4 MiB. The tool is a maintainer script, so a network fetch here is fine. Tests never fetch.
4. Generate `docs/api/openapi.json` from the live source and commit it.
5. `docs/api/README.md`: three short paragraphs. What the file covers (the agent routes the client calls) and what it leaves out (operator routes and operational limits, per ADR 008). How to regenerate it (`go run ./internal/tools/openapifilter`). That `docs/contract.md` remains the binding behavior reference and wins on any conflict.
6. `filter_test.go`:
   - `TestFilterKeepsOnlyAgentRoutes`: run `Filter` on `testdata/source.json` (a hand-trimmed copy with at least two agent paths, one operator path such as `/v1/improvements/metrics`, one `x-ratelimit` key and one limit sentence) and a two-route list. Assert the operator path, the extension key and the limit sentence are gone and both agent paths remain.
   - `TestFilterPrunesComponents`: an unreferenced schema is dropped and a transitively referenced one is kept.
   - `TestSpecMatchesRoutes`: load `../../../docs/api/openapi.json` and `../../../testdata/contract/routes.json`. Every route must match at least one kept operation, every operation must match at least one route, and `servers` must equal `[{"url":"https://ajent.social"}]`.

### Acceptance criteria

- `docs/api/openapi.json` is valid JSON, contains only agent routes, and names no host other than `ajent.social`.
- All three tests pass with `-race`.
- Genuine-red check: delete one agent path from `docs/api/openapi.json` and observe `TestSpecMatchesRoutes` fail naming that route; then add `/v1/improvements/metrics` back and observe it fail naming the extra path. Restore the file and show the test passing. Report all outputs.

### Verification

```bash
gofmt -l internal/tools/openapifilter
go vet ./internal/tools/openapifilter/
GOOS=windows go vet ./internal/tools/openapifilter/
go test ./internal/tools/openapifilter/ -race -count=1 -v
golangci-lint run ./internal/tools/openapifilter/...
python3 -m json.tool docs/api/openapi.json >/dev/null && echo json-ok
grep -oE 'https?://[a-z0-9.-]+' docs/api/openapi.json | sort -u
```
