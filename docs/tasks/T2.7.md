## T2.7: Port the read commands

### Objective

`ajent me`, `feed`, `groups`, `agents`, `search`, `events`, `inbox` and `doctor` send exactly the requests the Python client sends and print the server's JSON indented by two spaces, preserving key order. `doctor` adds `local_client_version`.

### Read first

- docs/contract.md sections 2, 3 and 10, plus the entries for these eight commands in testdata/contract/commands.json
- docs/interfaces.md `internal/cli`, `internal/api` and `internal/credentials`
- cmd/ajent/testenv_test.go and cmd/ajent/helpers.go (T2.6)

### Scope

Create exactly these files:

- `cmd/ajent/cmd_read.go`
- `cmd/ajent/cmd_read_test.go`

### Out of scope

- Write commands (T2.8), goals (T2.9), scope commands (T2.10) and feedback (T2.11).
- Lazy enrollment. The command calls `env.Credential(ctx, profile)`, and the test injects `Resolve`. This task does not depend on T3.6.
- Any file outside Scope.

### Steps

1. Use the helpers from `cmd/ajent/helpers.go` (T2.6): `profileFlags`, `toolCredential`, `rootCredential` and `getAndPrint`. Do not redefine them.
2. Register these commands in `init()`, each with `Summary`, `Usage` and `Flags`:
   - `me`: GET `/v1/me` with the tool credential.
   - `feed`: GET `/v1/feed` with the tool credential.
   - `groups`: GET `/v1/groups` with the tool credential.
   - `agents`: GET `/v1/agents` with the tool credential.
   - `search`: flags `--group` (UUID, optional), plus the positional words joined with single spaces as `q`.
     - Build the query with `url.Values{"q": {q}}`, and add `group_id` set to `api.CanonicalUUID(group)` when `--group` is given.
     - Route: `/v1/search?` plus `values.Encode()`.
     - An invalid `--group` returns the error `invalid --group: api: invalid UUID` (exit 1).
     - Python sends `q=` even when the query is empty, so keep that.
   - `events`: the optional positional `after`, defaulting to `0`. Route: `/v1/events?after=` plus `url.QueryEscape(after)`.
   - `inbox`: GET `/v1/inbox` with the tool credential.
   - `doctor`: GET `/v1/reliability` with the root credential. Then `out, _ := cli.AddField(raw, "local_client_version", version.Version)` and print it.
3. For each command, parse flags with a `flag.ContinueOnError` FlagSet whose output goes to `env.Stderr`. Unexpected positional args on commands that take none (`me`, `feed`, `groups`, `agents`, `inbox`, `doctor`) are ignored, as in the reference.
4. Write the tests in `cmd_read_test.go`, table-driven:
   - `TestReadCommands`: one case per command with args, expected method, expected path and expected raw query. Run with `newTestEnv`. Assert:
     - exit 0
     - exactly one request (`srv.Requests()`), with the method, path and query
     - stdout equals `json.Indent` of the fixture response file for that route (read from `testdata/contract/responses/`), plus a newline
     - the requested profile name equals `credentials.ProjectProfile("terminal", credentials.ProjectRoot(env.Cwd, env.Home))`, except for doctor
     - search cases: `ajent search flaky test` gives `q=flaky+test`, and `--group` with an uppercase UUID gives a lowercase `group_id`
   - `TestDoctorUsesRootAndAddsVersion`: `writeRoot` with `srv.Credential()`, and `Resolve` set to fail the test if called. The output JSON has `local_client_version` equal to `version.Version` as its last key.
   - `TestSearchInvalidGroup`: exit 1, the stderr text is as in step 5, and zero requests.
   - `TestReadHTTPError`: the fake returns 401 for `/v1/me`. Exit 1, and stderr is `ajent: unauthorized. <action from errors.json>`.
   - `TestProfileFlag`: `--profile codex` requests `ProjectProfile("codex", root)`.

### Acceptance criteria

- `go test ./cmd/ajent/... -race -count=1 -run 'TestReadCommands|TestDoctor|TestSearch|TestReadHTTPError|TestProfileFlag'` passes on all three OSes.
- Genuine-red check: temporarily print with `cli.PrintJSON` on a decoded `map[string]any` instead of `PrintRawJSON`. `TestReadCommands` must fail on key order for at least one fixture with non-alphabetical keys. If no fixture has such keys, add one to the test and state that. Restore and report both outputs.
- Genuine-red check: temporarily drop the project hash (pass `base` directly). `TestReadCommands` must fail on the profile assertion. Restore and report.
