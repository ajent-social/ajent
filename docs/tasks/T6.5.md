## T6.5: Show update notices

### Objective

When a newer stable release exists, an interactive CLI run prints one notice on stderr, at most once every 24 hours. For example: `A new ajent release is available: 0.7.0 -> 0.8.0. Run: ajent update`, or the package manager's command. Non-terminal runs, `mcp`, `hook` and `update` never print it. Release information is refreshed in a detached background `ajent update --check` at most once every 24 hours, so no command waits on the network. `ajent_diagnose` reports `update_available`, `latest_version` and `upgrade_command` from the cached state.

### Steps

1. `internal/update/notice.go`:
   - `func Notice(st State, current string, m Method, now time.Time) (text string, show bool)`. It returns show=false when `!Newer(st.Latest, current)` or `now.Sub(st.LastNotice) < 24*time.Hour`. Otherwise it returns the text `A new ajent release is available: <current> -> <latest>. Run: <cmd>`, where `cmd` is `UpgradeCommand(m)`, or `ajent update` when that is empty.
   - `func NeedsRefresh(st State, now time.Time) bool` returns true when `now.Sub(st.LastCheck) >= 24*time.Hour`.
   - `func DiagnoseFields(configDir, executable, current string) map[string]any` loads the state, ignoring errors. It returns `{"update_available": Newer(st.Latest, current), "latest_version": st.Latest, "upgrade_command": <UpgradeCommand(Detect(...)) or "ajent update">}`. It does no network I/O.
   - `notice_test.go`: `TestNoticeShown`, `TestNoticeRateLimited`, `TestNoticeNotNewer`, `TestNoticeManagedCommand`, `TestNeedsRefresh`, `TestDiagnoseFieldsNoNetwork` (use an `http.DefaultTransport` replacement that fails the test if it is used).
2. `cmd/ajent/wire_notice.go`. `init()` appends to `wire` a func `(env *cli.Env)` that:
   1. Returns unless `len(os.Args) > 1`, and returns when `os.Args[1]` is one of `mcp`, `hook`, `update`, `post-upgrade`, `version` or `help`.
   2. Returns when `!update.CheckAllowed(env.Getenv)` or `env.Getenv("AJENT_DETACHED") == "1"`.
   3. Resolves `dir := env.Dir()` and `st := update.LoadState(dir)`.
   4. If `update.NeedsRefresh(st, env.Now())`, sets `st.LastCheck = env.Now()` and saves it first (so parallel runs do not all spawn), then calls `startDetached(exe, []string{"update", "--check"}, filepath.Join(dir, "update.log"))`.
   5. If `env.IsTerminal(os.Stderr.Fd())` and `Notice(...)` returns show, prints the text plus a newline to `env.Stderr`, sets `st.LastNotice = env.Now()` and saves it.
   Use the package-level seam `startDetached` declared by T6.3 in `cmd_update.go`; never redeclare it. Also add the seam `var osArgs = func() []string { return os.Args }` for tests. Errors are silently ignored. A notice must never break a command.
3. `wire_notice_test.go`: `TestNoticePrintedOnTTY`, `TestNoticeSkippedNonTTY`, `TestNoticeSkippedForMCP`, `TestRefreshSpawnedOncePerDay` (two calls within the same fake `Now` produce one spawn), `TestNoticeSkippedInCI` (`CI=true`).
4. In `internal/mcp/tools_read.go`, in the `ajent_diagnose` handler, after building the response map, merge the keys of `update.DiagnoseFields(s.Dir, exe, version.Version)`, with `exe` from `os.Executable()`. Keep the existing keys and never overwrite them. Add `TestDiagnoseIncludesUpdateFields` in the new file `internal/mcp/tools_diagnose_update_test.go`: write a `state.json` with `latest: "99.0.0"` and assert `update_available` is true.
