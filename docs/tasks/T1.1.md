## T1.1: Initialize the Go module and layout

### Objective

The repository builds with `go build ./...`. Running `./ajent version` prints the version, commit and build date, and `./ajent version --json` prints the `version.Info` JSON. The Makefile targets `fmt`, `lint`, `test`, `build` and `docs` exist.

### Read first

- docs/interfaces.md, section "internal/version"
- docs/design.md, section "Package layout"
- docs/adr/002-go-stdlib-single-binary.md

### Scope

Create or modify only these files:

- `go.mod`
- `cmd/ajent/main.go`
- `internal/version/version.go`
- `internal/version/version_test.go`
- `cmd/ajent/main_test.go`
- `Makefile`
- `.gitignore` (extend the existing file, keep its current lines)
- `.editorconfig`
- `internal/doc.go` is NOT created. Do not create empty package directories; Go does not track empty directories. Later tasks create their own packages.

### Out of scope

- `internal/cli` and any subcommand other than `version`. T2.6 owns `internal/cli` and replaces the body of `cmd/ajent/main.go` so that it calls `cli.Main`. Leave a comment at the top of `main.go`: `// T2.6 replaces this dispatcher with cli.Main.`
- CI workflows (T1.4), license headers check script (T1.2). Still add the SPDX header line to every file you create (see Steps).
- Any third-party dependency. `go.mod` has no `require` block after this task.

### Steps

1. Run `go mod init github.com/ajent-social/ajent`, then edit `go.mod` so the `go` directive reads `go 1.26`. Do not add a `toolchain` line.
2. Create `internal/version/version.go` with first line `// SPDX-License-Identifier: Apache-2.0`, then `package version`, and exactly the identifiers from docs/interfaces.md:
   - `var Version = "dev"`, `var Commit = "none"`, `var Date = "unknown"` in one `var (...)` block.
   - `const ClientKind = "go-cli"`.
   - `type Info struct` with fields `Version`, `Commit`, `Date`, `ClientKind`, `GoVersion`, `OS`, `Arch` and JSON tags `version`, `commit`, `date`, `client_kind`, `go_version`, `os`, `arch`.
   - `func Get() Info` fills `GoVersion` from `runtime.Version()`, `OS` from `runtime.GOOS` and `Arch` from `runtime.GOARCH`.
   - `func UserAgent() string` returns `"ajent/" + Version + " (" + runtime.GOOS + "/" + runtime.GOARCH + ")"`.
   - Add a doc comment on every exported identifier.
3. Create `internal/version/version_test.go` (package `version`) with these tests:
   - `TestGetDefaults`: `Get()` returns `Version == "dev"`, `Commit == "none"`, `Date == "unknown"`, `ClientKind == "go-cli"`, non-empty `GoVersion`, `OS == runtime.GOOS`, `Arch == runtime.GOARCH`.
   - `TestInfoJSONFieldNames`: marshal `Get()` and unmarshal into `map[string]any`. Assert the key set is exactly `version, commit, date, client_kind, go_version, os, arch`.
   - `TestUserAgent`: set `Version = "1.2.3"` (restore with `t.Cleanup`) and assert `UserAgent() == "ajent/1.2.3 (" + runtime.GOOS + "/" + runtime.GOARCH + ")"`.
4. Create `cmd/ajent/main.go` (package `main`, SPDX header, then the T2.6 comment). Behavior:
   - No arguments: print `usage: ajent <command>` and `commands: version` on two lines to stderr, then exit 2.
   - `version`: print `ajent <Version> (commit <Commit>, built <Date>)` followed by a newline to stdout, then exit 0.
   - `version --json`: print `json.MarshalIndent(version.Get(), "", "  ")` plus a newline to stdout, then exit 0. Parse with a `flag.NewFlagSet("version", flag.ContinueOnError)` and a `-json` bool flag. Go's `flag` accepts both `-json` and `--json`.
   - Any other command: print `ajent: unknown command "<name>"` to stderr, then exit 2.
   - Put the logic in `func run(args []string, stdout, stderr io.Writer) int`. `main` calls `os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))`.
5. Create `cmd/ajent/main_test.go` with a table test `TestRun` whose cases are: `no args` (exit 2, stderr contains `usage:`), `version` (exit 0, stdout has prefix `ajent dev (commit none, built unknown)`), `version --json` (exit 0, stdout unmarshals into `version.Info` with `ClientKind == "go-cli"`), `unknown` (exit 2, stderr contains `unknown command`).
6. Create `Makefile` with these exact targets (use tabs for recipes):

   ```makefile
   VERSION ?= dev
   COMMIT  ?= $(shell git rev-parse --short HEAD 2>/dev/null || echo none)
   DATE    ?= $(shell date -u +%Y-%m-%dT%H:%M:%SZ)
   PKG     := github.com/ajent-social/ajent/internal/version
   LDFLAGS := -s -w -X $(PKG).Version=$(VERSION) -X $(PKG).Commit=$(COMMIT) -X $(PKG).Date=$(DATE)

   .PHONY: fmt lint test build docs
   fmt:
    gofmt -w .
   lint:
    test -z "$$(gofmt -l .)"
    go vet ./...
    golangci-lint run
   test:
    go test -race -count=1 ./...
   build:
    CGO_ENABLED=0 go build -trimpath -ldflags "$(LDFLAGS)" -o ajent ./cmd/ajent
   docs:
    @if [ -d internal/tools/gendocs ]; then go run ./internal/tools/gendocs; else echo "gendocs not yet implemented (T7.3)"; fi
   ```

7. Extend `.gitignore`. Keep the existing lines (`.claude/scratch/`, `ajent.social`, `dist/`) and append:

   ```gitignore
   /ajent
   /ajent.exe
   *.test
   coverage.out
   *.out
   .DS_Store
   ```

8. Create `.editorconfig`:

   ```ini
   root = true

   [*]
   charset = utf-8
   end_of_line = lf
   insert_final_newline = true
   trim_trailing_whitespace = true

   [*.go]
   indent_style = tab

   [Makefile]
   indent_style = tab

   [*.{md,yml,yaml,json,sh,ps1}]
   indent_style = space
   indent_size = 2
   ```

9. Run `gofmt -w .` and `go vet ./...`.

### Acceptance criteria

- `go build ./...` succeeds with no `require` lines in `go.mod`.
- `make build && ./ajent version` prints `ajent dev (commit <sha>, built <date>)`.
- `go build -ldflags "-X github.com/ajent-social/ajent/internal/version.Version=9.9.9" -o /tmp/aj ./cmd/ajent && /tmp/aj version` prints a line that starts with `ajent 9.9.9`.
- `go test -race -count=1 ./...` passes and runs `TestGetDefaults`, `TestInfoJSONFieldNames`, `TestUserAgent` and `TestRun`.
- Genuine-red check: temporarily change the `client_kind` JSON tag to `kind`, run `go test ./internal/version/ -run TestInfoJSONFieldNames` and observe it fail, then restore the tag and observe it pass. Report both outputs.

### Verification

```bash
gofmt -l .
go vet ./...
go test -race -count=1 -v ./internal/version/ ./cmd/ajent/
make build && ./ajent version && ./ajent version --json
```
