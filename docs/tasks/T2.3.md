## T2.3: Build the credentials and profiles file store

### Objective

`internal/credentials` loads and saves the root credential and per-tool profiles in exactly the Python client's on-disk layout, and computes project roots and hashes identical to the Python client. Existing installations therefore keep their identities.

### Read first

- docs/interfaces.md, section `internal/credentials`
- docs/contract.md sections 3 to 5 (profile resolution, files, project root and hashes)
- testdata/contract/golden.json and testdata/contract/files/ (produced by T2.1)
- internal/credentials/credential.go (produced by T2.12)
- internal/config (produced by T2.2)

### Scope

Create exactly these files:

- `internal/credentials/store.go` (`RootPath`, `LoadRoot`, `SaveRoot`, `CreateRoot`, `ProfileDir`, `ProfilePath`, `ProfileLockPath`, `LoadProfile`, `SaveProfile`)
- `internal/credentials/project.go` (`ProjectRoot`, `ProjectScope`, `ProjectProfile`)
- `internal/credentials/store_test.go`
- `internal/credentials/project_test.go`

### Out of scope

- `credential.go` (T2.12). Do not edit it.
- Enrollment and network calls (T3.6).
- Scope settings merging (T3.6).

### Steps

1. `RootPath(dir string) string`: if `os.Getenv("AJENT_CREDENTIAL_FILE")` is non-empty, return it with a leading `~` expanded to the home directory. Otherwise return `filepath.Join(dir, "credential.json")`.
2. `LoadRoot(dir string) (Credential, error)`:
   - Go addition (docs/contract.md section 4): Python has no `AJENT_TOKEN`; this override exists only in Go. If `AJENT_TOKEN` is non-empty, return `Credential{Server: <origin>, Token: <value>}`. Get the origin from `os.Getenv("AJENT_URL")` when it is set, otherwise `"https://ajent.social"`. This package must not import `internal/api`, so to avoid a cycle, declare the unexported constant `defaultOrigin = "https://ajent.social"` with a comment pointing to `api.DefaultOrigin`.
   - Otherwise call `config.ReadJSON(RootPath(dir), &c)`. When the error satisfies `errors.Is(err, fs.ErrNotExist)`, return `ErrNoCredential`. Pass other errors through, wrapped.
3. `SaveRoot(dir, c)` calls `config.WriteJSON(RootPath(dir), c)`. `CreateRoot(dir, c)` marshals `c` and calls `config.CreateExclusive(RootPath(dir), data)`, so an `fs.ErrExist` error passes through.
   - Before writing, both call `config.EnsurePrivateDir(filepath.Dir(RootPath(dir)))`.
   - Note that `WriteJSON` output is indented. The Python client writes compact JSON. Readers accept both, so this is compatible.
4. `ProfileDir(dir, root)` returns `filepath.Join(dir, "profiles", root.Identity())`. `ProfilePath` returns `ProfileDir/<profile>.json`, and `ProfileLockPath` returns `ProfileDir/<profile>.lock`.
5. `LoadProfile(dir, root, profile) (Credential, bool, error)`:
   - If `!ValidProfile(profile)`, return `ErrInvalidProfile`.
   - A missing file returns `(Credential{}, false, nil)`.
   - A symlink returns an error wrapping `config.ErrSymlink`.
   - Otherwise decode the file and return `ok = true`, including when the profile is pending (callers decide what to do).
6. `SaveProfile` validates the profile name, calls `config.EnsurePrivateDir(ProfileDir(...))`, then `config.WriteJSON`.
7. `ProjectRoot(cwd, home string) string`:
   1. Resolve `cwd` and `home` with `filepath.Abs` then `filepath.EvalSymlinks`. If `EvalSymlinks` fails, keep the Abs value.
   2. Walk `d` from cwd upward. At each `d`, if `<d>/.git` exists (any type) or `<d>/.aj/config.json` is a regular file, return `d`.
   3. If `d == home`, stop and return cwd.
   4. When `filepath.Dir(d) == d` (the filesystem root), stop and return cwd.
8. `ProjectScope(root)` returns `"project:" + hex(sha256([]byte(root)))`.
9. `ProjectProfile(base, root)`: take the first 30 bytes of `base`, cutting at a byte boundary. This is safe because valid profile names are ASCII. Return that plus `"-"` plus `hex(sha256([]byte(root)))[:8]`.
10. Tests in `project_test.go`:
    - `TestGoldenHashes`: load `../../testdata/contract/golden.json`. For every case, assert `ProjectScope(root)` and, for every entry in `profiles`, `ProjectProfile(name, root)`. Also assert `Credential{Token: golden.token}.Identity() == golden.identity`.
    - `TestProjectRoot`, table-driven over a temp tree:
      - `home/repo/.git` with cwd `home/repo/a/b` gives `home/repo`.
      - `home/proj/.aj/config.json` with cwd `home/proj/sub` gives `home/proj`.
      - Markers only above home (`tmp/.git`, home = `tmp/home`, cwd = `tmp/home/x`) gives cwd.
      - A marker at home itself (`home/.git`, cwd `home/x`) gives home, matching the reference, which checks home before stopping.
      - `.aj/config.json` as a directory is not a marker.
    - `TestProjectProfileTruncates`: a 45-character base yields 30 characters plus `-` plus 8 hex characters.
11. Tests in `store_test.go`:
    - `TestLoadPythonFixtures`: copy `testdata/contract/files/home/.aj` into `t.TempDir()`. `LoadRoot(dir)` succeeds with the fixture token. `LoadProfile` for the completed profile name (read the file name from the fixture directory) returns `ok` and not pending. The pending fixture returns `Pending == true`.
    - `TestRoundTripKeepsUnknownFields`: `LoadRoot`, then `SaveRoot`, then re-read as `map[string]any`. `future_field` survives.
    - `TestTokenEnvOverride`: `t.Setenv("AJENT_TOKEN", "x")` returns `Token == "x"` without reading any file.
    - `TestCredentialFileEnv`: `AJENT_CREDENTIAL_FILE` points elsewhere.
    - `TestLoadRootMissing` returns `ErrNoCredential`.
    - `TestCreateRootExclusive`: the second call satisfies `errors.Is(err, fs.ErrExist)`.
    - `TestLoadProfileInvalidName` returns `ErrInvalidProfile`.
    - `TestLoadProfileSymlink` is skipped on Windows.

### Acceptance criteria

- `go test ./internal/credentials/... -race -count=1` passes on ubuntu, macos and windows. `TestGoldenHashes` compares POSIX literal strings, so it is OS-independent.
- Genuine-red check: temporarily change `ProjectProfile` to use the first 31 characters of the base. `TestGoldenHashes` must fail. Restore and report both outputs.
- Genuine-red check: temporarily remove the `d == home` stop. The above-home `TestProjectRoot` case must fail. Restore and report.
