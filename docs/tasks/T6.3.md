## T6.3: Implement ajent update

### Objective

`ajent update` checks for a newer release. For script installs it downloads the archive for the current platform, verifies the Ed25519-signed checksums, smoke-tests the new binary and replaces the running executable atomically, including on Windows through a rename-aside. For package-managed installs it prints the exact upgrade command and changes nothing. `--check` reports without changing anything, `--version` pins a release, `--pre` allows prereleases, and `--auto on|off|status` sets the automatic-update preference. A tampered checksum or signature leaves the old binary untouched and exits 1.

### Steps

1. `apply.go`:
   - `func ArchiveName(version, goos, goarch string) string` returns `"ajent_" + version + "_" + goos + "_" + goarch + ext`, where `ext` is `.zip` for windows and `.tar.gz` otherwise.
   - `var ErrNoAsset = errors.New("update: release has no asset for this platform")`
   - `func Apply(ctx context.Context, s *Source, r Release, executable string) error`:
     1. Resolve `name := ArchiveName(r.Version, runtime.GOOS, runtime.GOARCH)`. Require `r.Assets[name]`, `r.Assets["checksums.txt"]` and `r.Assets["checksums.txt.sig"]`, and return `ErrNoAsset` otherwise.
     2. Download each with `s.HTTP`, using a separate context timeout of 5 minutes for the archive and a 100 MiB `io.LimitReader` cap. A non-200 status is an error naming the asset.
     3. Run `VerifyChecksums(checksums, sig, PublicKeys)`, then `VerifyFile(checksums, name, archive)`. Return the error unchanged on failure, before touching the filesystem.
     4. Extract the single entry `ajent` (tar.gz) or `ajent.exe` (zip) into a temp file created by `os.CreateTemp(filepath.Dir(exe), ".ajent-update-*")`, where `exe` is `executable` resolved with `filepath.EvalSymlinks`. Reject entries with `..` or absolute names, and cap the size at 200 MiB. Set mode 0755 on unix.
     5. Smoke-test: run `<tmp> version --json` with a 10s timeout. The decoded `version` must equal `r.Version`. Otherwise delete the temp file and return an error `update: new binary failed its self-check`.
     6. Call `replaceExecutable(tmp, exe)`. On error, delete the temp file and return an error that includes `cannot write <dir>` when the cause is a permission error (`errors.Is(err, fs.ErrPermission)`).
   - `replace_unix.go`: `func replaceExecutable(newPath, exe string) error { return os.Rename(newPath, exe) }`. The rename is atomic within one directory.
   - `replace_windows.go`: `old := exe + ".old"`. Remove any existing `old`, ignoring not-exist. Run `os.Rename(exe, old)` (a running exe can be renamed), then `os.Rename(newPath, exe)`. If the second rename fails, run `os.Rename(old, exe)` to roll back and return the original error.
   - `func CleanupOld(executable string)` removes `executable + ".old"` when it exists, ignoring all errors. It is a no-op on unix except for removing a leftover `.old` if present.
1a. Detached background processes. T6.4, T6.5 and T6.6 use these, so they live here:
   - `detach.go`: `func StartDetached(executable string, args []string, logPath string) error`. It opens `logPath` for append (`os.O_APPEND|os.O_CREATE|os.O_WRONLY`, mode 0600). Before opening, it truncates the file to empty if it is larger than 1 MiB. It builds `cmd := exec.Command(executable, args...)` with `cmd.Stdin = nil` and `cmd.Stdout`/`cmd.Stderr` set to the log file, sets `cmd.Env = append(os.Environ(), "AJENT_DETACHED=1")`, calls `setDetached(cmd)`, then `cmd.Start()`, then `cmd.Process.Release()`, and closes the parent's copy of the log file. It never waits.
   - `detach_unix.go`: `func setDetached(cmd *exec.Cmd) { cmd.SysProcAttr = &syscall.SysProcAttr{Setsid: true} }`
   - `detach_windows.go`: `func setDetached(cmd *exec.Cmd) { cmd.SysProcAttr = &syscall.SysProcAttr{CreationFlags: 0x00000200 | 0x00000008, HideWindow: true} }`. The flags are `CREATE_NEW_PROCESS_GROUP | DETACHED_PROCESS`.
   - `detach_test.go`: `TestStartDetachedWritesLog` re-executes the test binary itself (`os.Args[0]`) with `-test.run=TestHelperProcess` and env `GO_HELPER=1`. The helper writes `hello` and exits. The test polls the log for up to 5s until it contains `hello`, and asserts that `StartDetached` returned in under 1s. Also add `TestStartDetachedTruncatesLargeLog`.
2. `apply_test.go`. Use `fakerelease.BuildAssets` with a test key appended to `PublicKeys` (restore it in `t.Cleanup`). The "binary" is a real helper executable: build it at test start with `go build -ldflags "-X github.com/ajent-social/ajent/internal/version.Version=<v>" -o <tmp> github.com/ajent-social/ajent/cmd/ajent` (use `testing.Short()` to skip in `-short` mode), so the self-check can run `version --json`. Tests:
   - `TestArchiveNameMatchesFakeRelease`: the keys produced by `BuildAssets` include `ArchiveName(...)`.
   - `TestApplyReplaces`: copy an old binary (0.7.0) to a temp path, apply 0.7.1, and assert the file now reports 0.7.1.
   - `TestApplyTamperedChecksums`: flip a byte in `checksums.txt`. The error is `ErrBadSignature` and the file is byte-identical to before.
   - `TestApplyTamperedSignature`: the same, with a signature from a different key.
   - `TestApplyTamperedArchive`: flip a byte in the archive. The error is `ErrChecksumMismatch` and the file is unchanged.
   - `TestApplyWrongVersionBinary`: the archive holds a 0.7.0 binary but the release says 0.7.1. The self-check error occurs and the file is unchanged.
   - `TestApplyMissingAsset`: `ErrNoAsset`.
   - `TestApplyReadOnlyDir` (unix only; skip as root): the error mentions `cannot write`.
   - `TestApplyZipSlip`: an archive entry `../ajent` is rejected.
   - `TestReplaceWindowsRollback` (windows only): make the target of the second rename unwritable by holding an open handle on a pre-created file with exclusive sharing. The original exe is restored.
3. `cmd/ajent/cmd_update.go`. In `init()`:
   - Call `update.CleanupOld(exe)`, where `exe` comes from `os.Executable()` (ignore errors).
   - Register `cli.Command{Name: "update", Summary: "Update ajent to the latest release", Run: runUpdate}`.
   - Declare package-level seams: `var executablePath = os.Executable` and `var newSource = update.DefaultSource`.
   - Declare the shared seams that T6.4, T6.5 and T6.6 use. Those rows never redeclare them:
     - `var startDetached = update.StartDetached`
     - `var autoRun func(ctx context.Context, env *cli.Env) error` (nil here; T6.6 assigns it from `hook_autoupdate.go`)
   - Define the hidden bool flag `--auto-run`. Leave it out of the `Flags` func so help does not list it. When it is set, `runUpdate` does nothing else: if `autoRun == nil` it returns `errors.New("automatic updates are not available in this build")`, otherwise it returns `autoRun(ctx, env)`.
   `runUpdate` flags: `--check` (bool), `--version` (string), `--pre` (bool), `--auto` (string: `on`, `off` or `status`). Behavior:
   1. `--auto`: load the state. `on` or `off` sets `State.Auto` to true or false and saves it. For all three values, print `automatic updates: on|off (<reason>)`, where the reason is `script install` or `managed by <Label>; use <UpgradeCommand>`. Also print `env AJENT_AUTO_UPDATE=0 overrides this` when that env var is `0`. Return nil. Any other value returns `cli.ErrUsage`.
   2. Detect the method with `update.Detect(exe, env.ConfigDir)`.
   3. Resolve the target: `--version` uses `Get` (error when it is not `update.Valid`), otherwise `Latest(ctx, --pre)`. An `ErrUnavailable` error returns an error `update check unavailable: <cause>` (exit 1).
   4. `current := version.Version`. `available := update.Newer(target.Version, current) || (--version set && target.Version != current)`.
   5. `--check`: save `State.LastCheck = env.Now()` and `State.Latest = target.Version` (T6.5 runs `ajent update --check` in the background to refresh these). Then print JSON via `cli.PrintJSON` with keys `current`, `latest`, `update_available`, `method`, `command` (UpgradeCommand, possibly empty). Return nil.
   6. If not available: print `ajent <current> is up to date` and return nil.
   7. If `method.Managed()`: print `ajent was installed with <Label>. Upgrade with: <UpgradeCommand>` to stdout and return nil. Never modify files.
   8. If the method is unknown: print `ajent cannot tell how it was installed. Reinstall with: curl -fsSL https://ajent.social/install.sh | sh` (on windows: `irm https://ajent.social/install.ps1 | iex`) and return nil.
   9. Script: run `update.Apply`. On success, update `State.Latest` and `State.LastCheck`, save the state, and print `updated ajent <current> -> <new>`. On error, return it (exit 1).
4. `cmd/ajent/cmd_update_test.go`. Drive `cli.Main` with buffers, override `executablePath` to point at a temp copy of a built binary, and override `newSource` to point at fakerelease. Write `install.json` in a temp config dir to make the install a script install. Tests:
   - `TestAutoRunFlagWithoutHook`: with `autoRun` nil, `ajent update --auto-run` exits 1 with `not available in this build`.
   - `TestUpdateCheckJSON`
   - `TestUpdateUpToDate`
   - `TestUpdateScriptApplies`
   - `TestUpdateManagedPrintsCommand`: evalSymlinks cannot be faked from here, so place the temp exe under a directory path containing `/Cellar/ajent/0.7.0/bin/`. The output contains `brew upgrade ajent` and the file is unchanged.
   - `TestUpdateTamperedExit1`
   - `TestUpdateAutoOnOffStatus`
   - `TestUpdateBadAutoValueUsage` (exit 2)
   - `TestUpdatePinnedVersion`
