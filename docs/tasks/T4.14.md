## T4.14: Write the Copilot CLI integration

### Objective

When GitHub Copilot CLI is installed (its config directory exists), `ajent integrations sync` adds an `ajent` server entry under `mcpServers` in `<Home>/.copilot/mcp-config.json` on every OS. Every other key stays as it was. A second run leaves the file byte-identical. Python-era or outdated ajent entries are replaced. A foreign `ajent` entry is preserved.

Decision (orchestrator, from the T2.1 contract freeze): Go writes the harness `env` block only when the config directory or credential file is non-default, while the Python client always wrote both variables (docs/contract.md section 9). Any existing `ajent` entry whose command runs `ajent mcp` or `client.py mcp` counts as ajent-owned (`Owned` in T4.17) and is replaced, so migration, post-upgrade sync and uninstall work on Python-era entries. This intentionally differs from the reference, which left any differing existing entry unchanged and, for Claude Code and Codex, kept any registration that `mcp get ajent` found. Entries that are not owned are still never modified.

### Out of scope

- The JSON merge algorithm itself (T4.17). Call it; do not reimplement it.
- Backups (T4.6 snapshots `Paths` before calling Apply).

### Steps

1. `type copilotWriter struct{}` registered in `init()` with `Register(copilotWriter{})`. `Target()` returns `Target{Name: "copilot", Profile: "copilot"}`.
2. `configPath(p Params) string` returns `filepath.Join(p.Home, ".copilot", "mcp-config.json")`.
3. `Detect(p)` returns true when `filepath.Join(p.Home, ".copilot")` exists and is a directory (`os.Stat`). Never create that directory.
4. `Paths(p)` returns `[]string{configPath(p)}`.
5. `Apply(ctx, p)`:
   - If `!Detect(p)`, return `Result{Name: "copilot", Status: "skipped"}, nil`.
   - `e := Entry(p, "copilot")`. This entry adds `"type": "local"` and `"tools": ["*"]`. Then set `e["type"] = "local"; e["tools"] = []any{"*"}`.
   - `changed, err := MergeJSONServer(configPath(p), "mcpServers", e)`.
   - `errors.Is(err, ErrUnparseable)` gives status `incomplete`, detail `config has comments or is not plain JSON; left unchanged`.
   - `errors.Is(err, ErrForeignEntry)` gives status `incomplete`, detail `an existing ajent entry with other settings was preserved`.
   - `errors.Is(err, config.ErrSymlink)` gives status `incomplete`, detail `config is a symlink; left unchanged`.
   - Any other error is returned as is.
   - `changed` gives status `configured`. Otherwise the status is `unchanged`.
   - These error results return `nil` as the Go error.
6. Golden cases. Each has `before/<relative path>` and `after/<relative path>`, mirroring a fake home. Use `p.Binary = "/opt/ajent/bin/ajent"` and the default config dir `<home>/.aj`:
   - `fresh-dir`: the config directory exists and the file is absent. after = `{"mcpServers": {"ajent": <entry>}}`.
   - `foreign-servers`: before has `mcpServers.github` and `mcpServers.postgres`. after appends `ajent` last, and the others are byte-identical.
   - `python-entry`: before has `mcpServers.ajent` with `command: "/usr/bin/python3"` and `args` starting with `/HOME/.aj/client.py`. after has the new entry in the same position.
   - `current`: before == after (already configured).
   The expected entry for the default config is `{"command":"/opt/ajent/bin/ajent","args":["mcp","--profile","copilot","--project-profile"],"type":"local","tools":["*"]}` (shown compact; the file is indented). The new entry is encoded with `json.Marshal` on a map, which sorts keys alphabetically (`args`, `command`, `env`, `tools`, `type`), then indented with 2 spaces at the entry's depth. Write each `after/` file by hand from these rules. Do not generate it from the code under test.
7. Tests in `copilot_test.go`:
   - `TestCopilotGolden`: table over the cases. Copy `before/` into `t.TempDir()`, run Apply, and compare every file under the home against `after/` byte-for-byte.
   - `TestCopilotSecondRunUnchanged`: Apply twice. The second result is `unchanged` and the file bytes are identical.
   - `TestCopilotNotDetected`: no config dir gives `skipped`, and the directory is not created.
   - `TestCopilotJSONCPreserved`: a file with a `// comment` gives `incomplete`, and the bytes are unchanged.
   - `TestCopilotForeignEntryPreserved`: `ajent` with `command: "npx"` gives `incomplete`, and the bytes are unchanged.
   - `TestCopilotRemove`: after Apply, Remove deletes only `mcpServers.ajent`, and other servers remain.
   - `TestCopilotCustomConfigDirEnv`: `ConfigDir` not equal to `<home>/.aj` gives an entry with `env.AJENT_CONFIG_DIR`.
   - `TestCopilotEntryShape`: the merged entry has `type == "local"` and `tools == ["*"]`.

### Acceptance criteria

- All tests pass with `-race` on ubuntu, macos and windows.
- Genuine-red: change the profile string in Apply to `"wrong"`, then observe `TestCopilotGolden` fail. Restore and report both outputs.
- Genuine-red: make Detect return true unconditionally, then observe `TestCopilotNotDetected` fail. Restore.
