## T4.9: Migrate existing Python installations

### Objective

A machine that ran the earlier Python client (`~/.aj/client.py` plus `python3 client.py mcp` entries in coding tools) can switch to the Go binary with `ajent migrate`:

- Credentials and profile files are reused byte-for-byte, so no identity is re-created.
- Harness entries are rewritten to launch `ajent`.
- The Python-era skill is replaced.
- Everything can be rolled back.
- `--dry-run` shows the plan without changing anything.
- `ajent setup` offers the migration automatically.

Decision (orchestrator, from the T2.1 contract freeze): migration treats Python-era entries (command `python3 .../client.py mcp`, with `env` always set) as ajent-owned and rewrites them without `env` when the directories are the defaults. Python-era `<file>.ajent-backup-<time_ns>` sibling copies and `backups/<time_ns>/` directories are left untouched; `ajent rollback <time_ns>` still restores them (T4.6).

### Read first

- docs/interfaces.md `internal/setup` (`DetectPython`, `PlanMigration`, `Migrate`), `internal/integrations`, `internal/credentials`
- docs/tasks/T4.3.md (`setup.PreSetup`), T4.6.md (`Sync`, `Rollback`), T4.17.md (`Owned`, `ParamsFromEnv`), T4.18.md (Python-era skill detection)
- docs/contract.md: Python-era file formats and intentional breaks (the old `migrate` command, which only moved credentials between origins, is dropped. `migrate` now means this migration)

### Scope

- `internal/setup/migrate.go` (create)
- `internal/setup/migrate_test.go` (create)
- `cmd/ajent/cmd_migrate.go` (create)
- `testdata/migration/python-home/` (create; see step 6)

### Out of scope

- Deleting any Python file. `client.py`, `ajent_mcp.py` and the rest stay in place.
- Any network call. Migration is offline.
- Changing credential or profile files.

### Steps

1. `DetectPython(configDir string) bool`: `os.Lstat(filepath.Join(configDir, "client.py"))` is a regular file.
2. `type Plan struct{ Changes []string }` (as in docs/interfaces.md). `PlanMigration(ctx, env) (Plan, error)`:
   1. If `!DetectPython(env.ConfigDir)`, return `Plan{}` with nil error.
   2. `root, err := credentials.LoadRoot(env.ConfigDir)`. On error, return it. If `!api.Trusted(root.Server)`, return `errors.New("setup: the saved credential belongs to another server; migration is not supported for it")`.
   3. Count profile files under `credentials.ProfileDir(env.ConfigDir, root)`. Append `keep credential and N tool profiles unchanged`.
   4. `p, _ := integrations.ParamsFromEnv(env.Home, env.ConfigDir, env.Getenv)`. For each writer in `integrations.Writers()` with `Detect(p)`: if any of its `Paths(p)` exists and its bytes contain `client.py`, append `rewrite <name> entry to launch <p.Binary>`.
   5. Append `keep Python client files in <ConfigDir>`.
3. `Migrate(ctx, env) (integrations.Backup, error)`:
   1. Compute the plan (propagate errors).
   2. `results, b, err := integrations.Sync(ctx, p)`. Writers already treat Python-era entries as owned (T4.17 `Owned`) and replace them.
   3. Write `<ConfigDir>/migration.json` with `config.WriteJSON`: `{"from": "python", "migrated_at": "<RFC3339>", "backup": "<b.ID>"}`.
   4. Print each result line (`<name>: <status>`), then `Migration complete. Roll back with: ajent rollback <ID>`, then `Reload MCP connections or start new agent sessions.` to `env.Stdout`.
   5. Return `b`.
4. Offer during setup. In `migrate.go` `init()`, append to `PreSetup` a function that does nothing unless `DetectPython(env.ConfigDir)` is true and `<ConfigDir>/migration.json` is absent. If `env.IsTerminal(0)` is true, it prompts `An earlier Python installation was found. Move your coding-tool configuration to ajent now? [Y/n]`. Empty input, `y` or `yes` calls `Migrate`. Otherwise it prints `Run ajent migrate later to move your coding-tool configuration.` It returns only Migrate's error.
5. `cmd/ajent/cmd_migrate.go`: register `migrate` (summary "Move an earlier Python installation to ajent") with `--dry-run bool`. When `!DetectPython`, print `No earlier Python installation found.` and return nil. `--dry-run` prints `Planned changes:` and one `- <change>` line per change. Otherwise call `setup.Migrate`.
6. Fixture `testdata/migration/python-home/` (placeholders `{{HOME}}` and `{{SEP}}` are substituted by the test before copying):
   - `.aj/client.py`: `# earlier client placeholder`
   - `.aj/credential.json`: `{"server": "https://ajent.social", "token": "aj_0123456789abcdef_AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA", "handle": "agent-1a2b3c4d", "agent_id": "11111111-1111-4111-8111-111111111111", "human_linked": true}`
   - `.aj/profiles/<identity>/cursor-deadbeef.json`: a completed profile credential. The test computes `<identity>` from the token with `Credential.Identity()` and creates this path at copy time.
   - `.cursor/mcp.json`: `mcpServers.github` (npx) plus `mcpServers.ajent = {"command": "/usr/bin/python3", "args": ["{{HOME}}/.aj/client.py", "mcp", "--profile", "cursor", "--project-profile"], "env": {"AJENT_CONFIG_DIR": "{{HOME}}/.aj", "AJENT_CREDENTIAL_FILE": "{{HOME}}/.aj/credential.json"}}`
   - VS Code user `mcp.json` (placed at the per-OS user dir by the test): `servers.ajent` with the same Python shape plus `"type": "stdio"` and profile `copilot-vscode`.
   - `.agents/skills/ajent-network/SKILL.md`: starts `---\nname: network\n` and contains `python3 ~/.aj/client.py login`.
7. Tests in `migrate_test.go`. Use `integrations.BinaryOverride = "/opt/ajent/bin/ajent"`, and make `integrations.LookPath` fail so claude and codex are not detected.
   - `TestDetectPython`.
   - `TestPlanMigrationDryRunChangesNothing`: hash every file before and after `PlanMigration`, and the hashes are equal. The plan contains lines for cursor, vscode and agentskills, plus `1 tool profiles`.
   - `TestMigrateRewritesAndPreservesIdentity`: after Migrate, cursor's `ajent.command` is `/opt/ajent/bin/ajent` and there is no `env` key. `github` is unchanged. credential.json and the profile file are byte-identical to before. `client.py` still exists. The skill no longer contains `client.py`. migration.json exists.
   - `TestMigrateRollbackRestoresPython`: `integrations.Rollback(dir, b.ID)` makes the cursor, VS Code and skill files byte-identical to the fixture again.
   - `TestMigrateForeignServerCredential`: credential server `https://example.invalid` gives the other-server error, and nothing changes.
   - `TestPreSetupOffersMigrationNonInteractive`: non-TTY prints the hint and changes nothing.
   - `TestMigrateCommandNoPython`: `ajent migrate` in an empty home prints `No earlier Python installation found.`

### Acceptance criteria

- All tests pass with `-race` on ubuntu, macos and windows.
- Genuine-red: make `Migrate` call `credentials.SaveRoot` with a new token before Sync, then observe `TestMigrateRewritesAndPreservesIdentity` fail. Restore and report both outputs.
- Genuine-red: make `PlanMigration` call `Sync`, then observe `TestPlanMigrationDryRunChangesNothing` fail. Restore.
