## T4.11: Run the phase-1 lint and race qualification

### Objective

The complete phase-1 client (E2, E3 and E4) is clean under every static and dynamic check on all three operating systems, and the result is reported with executed test counts rather than just "green". Any finding is fixed in the smallest possible change.

### Read first

- AGENTS.md (repository conventions)
- `.golangci.yml` and `.github/workflows/ci.yml` (T1.4)
- docs/interfaces.md (fixes must not change listed signatures)

### Scope

- Any `.go` file under `internal/`, `cmd/` or the module root, only to fix a reported finding.
- `.golangci.yml`, only to add a narrowly scoped `//nolint`-equivalent exclusion that has a written reason, when a finding is a false positive.
- No other files.

### Out of scope

- Refactors, renames, new features and test rewrites beyond what a finding requires.
- Changing exported signatures listed in docs/interfaces.md.

### Steps

1. Run each command below from the repository root and save the full output:
   1. `gofmt -l .`
   2. `go vet ./...`
   3. `GOOS=windows go vet ./...` and `GOOS=darwin go vet ./...`
   4. `go run github.com/golangci/golangci-lint/v2/cmd/golangci-lint@<version pinned in ci.yml> run ./...`
   5. `go run golang.org/x/vuln/cmd/govulncheck@latest ./...`
   6. `go test -race -count=1 -json ./... > test.json`
2. Fix each finding in its own commit, touching only the file that finding names. `gofmt` findings are fixed with `gofmt -w`.
3. Count the executed tests: `grep -c '"Action":"pass","Package":"[^"]*","Test"' test.json` gives passed tests. Also count `"Action":"fail"` and `"Action":"skip"` with a `"Test"` field. Every skip must have a reason printed in its output. List every skip.
4. Push and let CI run on ubuntu, macos and windows. From each OS's test job log, record the same three counts.
5. Write the PR description with a table: OS, passed, failed, skipped, and the command list with pass or fail for each.

### Acceptance criteria

- `gofmt -l .` prints nothing. `go vet` (native, windows and darwin), golangci-lint and govulncheck exit 0. govulncheck may report vulnerabilities only in unreachable code, and those must be listed.
- `go test -race ./...` passes on all three OSes with 0 failures. The executed pass count is reported per OS and is greater than zero for each of the packages `internal/config`, `internal/credentials`, `internal/api`, `internal/mcp`, `internal/integrations`, `internal/setup` and `cmd/ajent`.
- Genuine-red: before fixing, run step 1.6 once with a deliberately failing assertion added to one test in `internal/integrations`, and confirm the JSON shows `"Action":"fail"` for it and the count changes. Remove the assertion and report both counts.

### Verification

- `gofmt -l .`
- `go vet ./... && GOOS=windows go vet ./... && GOOS=darwin go vet ./...`
- `go test -race -count=1 ./...`
- CI run URL for the PR, with all jobs green
