## T6.6: Apply automatic updates for script installs

### Objective

For script installs, automatic updates are on by default (ADR 005). At most once every 24 hours, the session-start hook starts a detached `ajent update --auto-run`, which applies the newest verified stable release. Nothing is applied when any of these hold: `AJENT_AUTO_UPDATE=0`, `CI` is set, `ajent update --auto off` was run, or the install is package-managed. Prereleases are never applied automatically.

- docs/adr/005-upgrade-strategy.md
- docs/tasks/T4.2.md (`sessionStartExtras`), T6.3.md (`cmd_update.go`, `Apply`, `StartDetached`, `--auto` preference), T6.2.md (`State.AutoEnabled`, `LoadState`, `SaveState`, `CheckAllowed`, `DefaultSource`), T6.1.md (`Detect`)

### Scope

Create exactly these files:

- `cmd/ajent/hook_autoupdate.go`, `cmd/ajent/hook_autoupdate_test.go`
- `cmd/ajent/cmd_update_autorun_test.go`

Do not edit `cmd/ajent/cmd_update.go` or `cmd/ajent/cmd_update_test.go` (owned by T6.3). T6.3 already declares the hidden `--auto-run` flag, the nil `autoRun` seam and the `startDetached` seam.

### Out of scope

- The `--auto on|off|status` preference (T6.3 owns it). Post-upgrade sync (T6.4). Notices (T6.5).

### Steps

1. `hook_autoupdate.go`, with `func autoUpdateDue(env *cli.Env, dir, exe string) bool`. It returns true only when all of these hold:
   - `env.Getenv("AJENT_AUTO_UPDATE") != "0"`
   - `update.CheckAllowed(env.Getenv)`, which covers `CI` and `AJENT_NO_UPDATE_CHECK`
   - `env.Getenv("AJENT_DETACHED") != "1"`
   - `version.Version` is `update.Valid` and does not contain `SNAPSHOT`
   - `m := update.Detect(exe, dir)` gives `m == update.MethodScript`
   - `st.AutoEnabled(m)` is true
   - `env.Now().Sub(st.LastAutoUpdate) >= 24*time.Hour`
2. `init()` appends to `sessionStartExtras` a func that resolves `dir` and `exe`. When `autoUpdateDue` is true, it sets `st.LastAutoUpdate = env.Now()` and saves it (the rate limit is recorded before spawning, so a crash cannot cause a spawn storm), then calls `startDetached(exe, []string{"update", "--auto-run"}, filepath.Join(dir, "update.log"))`. Use the package seam `startDetached` declared by T6.3 in `cmd_update.go`; never redeclare it. It never writes to stdout and ignores errors.
3. In `hook_autoupdate.go`, implement `func runAutoUpdate(ctx context.Context, env *cli.Env) error` and assign it in `init()` with `autoRun = runAutoUpdate`. `ajent update --auto-run` (the flag T6.3 declares) then calls it. It does the following:
   1. Resolve `dir, err := env.Dir()` and `exe, err := executablePath()` (the T6.3 seam), and build `src := newSource(dir)`. Load the state and detect the method. If `!st.AutoEnabled(m)` or `env.Getenv("AJENT_AUTO_UPDATE") == "0"`, print `auto-run: disabled` to stderr and return nil.
   2. `r, err := src.Latest(ctx, false)`. Never use prereleases.
   3. If `!update.Newer(r.Version, version.Version)`, print `auto-run: up to date <v>` and return nil.
   4. Otherwise call `update.Apply(ctx, src, r, exe)`. On success, print `auto-run: updated <old> -> <new>` to stderr and save `State.Latest`. On failure, print `auto-run: failed: <err>` and return the error. The detached process's exit code goes nowhere, but the log records it.
   All output goes to stderr, which the detached launcher redirects to `update.log`.
4. `hook_autoupdate_test.go`. Tests override `startDetached` and use a temp config dir with `install.json` making the temp exe a script install:
   - `TestAutoUpdateDueDefaultOn`
   - `TestAutoUpdateOffByEnv`
   - `TestAutoUpdateOffInCI`
   - `TestAutoUpdateOffByPreference` (`State.Auto=false`)
   - `TestAutoUpdateOffForHomebrew` (exe path under `/Cellar/ajent/`)
   - `TestAutoUpdateRateLimited` (a second call within 24h does not spawn)
   - `TestAutoUpdateSkipsDevVersion`
   - `TestHookSpawnsAutoRun` (runs the hook via `cli.Main`; the seam receives `["update","--auto-run"]`; stdout holds only the hook text)
5. Tests in `cmd_update_autorun_test.go` (drive `cli.Main` with `update --auto-run`, overriding the T6.3 seams `executablePath` and `newSource`): `TestAutoRunAppliesStable` (fakerelease has 0.7.1 stable and 0.8.0-rc.1; the result is 0.7.1), `TestAutoRunUpToDate`, `TestAutoRunDisabledByPreference`, `TestAutoRunIgnoresManaged`.

### Acceptance criteria

- `go test ./cmd/ajent -run 'AutoUpdate|AutoRun|HookSpawns' -race -count=1` passes on ubuntu, macos and windows CI.
- `golangci-lint` and `gofmt -l` are clean.
- Genuine-red: change `Latest(ctx, false)` to `Latest(ctx, true)` and run `TestAutoRunAppliesStable`. It fails with version 0.8.0-rc.1. Restore it and report both outputs.
