## T5.8: Publish the Scoop bucket and winget manifests

### Objective

Each stable release commits `bucket/ajent.json` to `ajent-social/scoop-bucket` (`scoop bucket add ajent https://github.com/ajent-social/scoop-bucket; scoop install ajent`). It also opens a pull request to `microsoft/winget-pkgs` with manifests for package ID `AjentSocial.Ajent` (`winget install AjentSocial.Ajent`). Snapshot runs render both, and the rendered manifests pass `winget validate` on Windows.

### Read first

- docs/adr/003-distribution-channels.md
- GoReleaser documentation: customization > scoop, customization > winget
- `.goreleaser.yaml` (the `scoops and winget (T5.8)` marker block)

### Scope

Modify only `.goreleaser.yaml`, between `# ---- BEGIN scoops and winget (T5.8) ----` and `# ---- END scoops and winget (T5.8) ----`.
Create:

- `.github/workflows/windows-manifests.yml`
- `scripts/test-scoop.ps1`

### Out of scope

- Creating the bucket repository, the winget fork or the tokens (T5.0). The release workflow env wiring (T5.11). Microsoft's review of the first winget PR, which the maintainer follows up during E8.

### Steps

1. Fill the marker block:

   ```yaml
   # ---- BEGIN scoops and winget (T5.8) ----
   scoops:
     - name: ajent
       ids: [default]
       repository:
         owner: ajent-social
         name: scoop-bucket
         branch: main
         token: "{{ .Env.SCOOP_BUCKET_TOKEN }}"
       directory: bucket
       homepage: https://ajent.social
       description: "Connect your coding agents to a shared, private workspace of checked findings through MCP."
       license: Apache-2.0
       commit_author:
         name: ajent-release-bot
         email: ajent-release-bot@users.noreply.github.com
       commit_msg_template: "ajent {{ .Tag }}"
       skip_upload: auto
   winget:
     - name: ajent
       ids: [default]
       package_identifier: AjentSocial.Ajent
       publisher: Ajent
       publisher_url: https://ajent.social
       publisher_support_url: https://github.com/ajent-social/ajent-client/issues
       author: The Ajent Authors
       homepage: https://github.com/ajent-social/ajent-client
       short_description: "Connect your coding agents to a shared, private workspace of checked findings through MCP."
       license: Apache-2.0
       license_url: https://github.com/ajent-social/ajent-client/blob/main/LICENSE
       copyright: "Copyright 2026 The Ajent Authors"
       release_notes_url: "https://github.com/ajent-social/ajent-client/releases/tag/{{ .Tag }}"
       tags: [mcp, cli, ai-agents, developer-tools]
       commit_author:
         name: ajent-release-bot
         email: ajent-release-bot@users.noreply.github.com
       repository:
         owner: ajent-social
         name: winget-pkgs
         branch: "ajent-{{ .Version }}"
         token: "{{ .Env.WINGET_TOKEN }}"
         pull_request:
           enabled: true
           draft: false
           base:
             owner: microsoft
             name: winget-pkgs
             branch: master
       skip_upload: auto
   # ---- END scoops and winget (T5.8) ----
   ```

   Check field names against the pinned GoReleaser version (`goreleaser check` fails on unknown keys) and report any renames. GoReleaser writes a fresh manifest (url and hash per architecture) on every release, so `checkver` and `autoupdate` are not needed.
2. Run the snapshot with publishing skipped (`goreleaser release --snapshot --clean --skip=sign,notarize,publish`). Rendered files appear under `dist/` (find them with `find dist -name 'ajent.json'` and `find dist -path '*winget*' -name '*.yaml'`).
3. Create `scripts/test-scoop.ps1` (PowerShell 7, SPDX header as `#` comment). Parameters: `-Manifest <path>` and `-DistDir <path>`. It:
   1. Starts `python -m http.server 8765 --directory $DistDir` as a background job.
   2. Copies the manifest to a temp file, rewriting every `https://github.com/ajent-social/ajent-client/releases/download/<tag>/` prefix to `http://127.0.0.1:8765/`.
   3. Installs Scoop non-interactively when missing (`irm get.scoop.sh -outfile install.ps1; .\install.ps1 -RunAsAdmin`).
   4. Runs `scoop install <temp manifest>` and asserts `ajent version --json | ConvertFrom-Json` has the expected `version`.
   5. Runs `scoop uninstall ajent`.
4. Create `.github/workflows/windows-manifests.yml`: on `pull_request` with paths `.goreleaser.yaml` and `scripts/test-scoop.ps1`, plus `workflow_dispatch`. `permissions: contents: read`. One job on `windows-latest`:
   1. Checkout, setup-go, download syft, and the GoReleaser snapshot, all SHA-pinned.
   2. `pwsh scripts/test-scoop.ps1 -Manifest <rendered bucket json> -DistDir dist`.
   3. Install winget if absent (winget is not on all hosted images; use `Repair-WinGetPackageManager` from the `Microsoft.WinGet.Client` module, or the `Cyberboss/install-winget` action SHA-pinned), then run `winget validate --manifest <rendered winget manifest dir>`.
   If winget cannot be installed on the runner, the step prints a warning and the job still fails. Do not mark it passing silently.
5. Run `actionlint` on the workflow and `Invoke-ScriptAnalyzer -Path scripts/test-scoop.ps1 -Severity Warning,Error` (install PSScriptAnalyzer in the job).

### Acceptance criteria

- `goreleaser check` exits 0.
- `windows-manifests.yml` is green on the PR. The Scoop install prints the snapshot version and `winget validate` reports `Manifest validation succeeded`. Record the run URL.
- PSScriptAnalyzer reports no warnings or errors, and `actionlint` passes.
- Genuine-red: in the workflow's temp copy, change the hash of the amd64 architecture in the rendered Scoop manifest. `scoop install` fails with a hash check error. Revert and report both outputs (use a temporary workflow_dispatch input `corrupt_hash: true` that the script honors; remove the input before merge, or keep it default false).

### Verification

- `go run github.com/goreleaser/goreleaser/v2@<GR> check`
- `go run github.com/goreleaser/goreleaser/v2@<GR> release --snapshot --clean --skip=sign,notarize,publish`
- `go run github.com/rhysd/actionlint/cmd/actionlint@latest .github/workflows/windows-manifests.yml`
- `gh run list --workflow windows-manifests.yml --limit 1`
