## T1.5: Add public-safety gates

### Objective

No secret and no privately denylisted term can land on `main`. gitleaks scans every push and PR. A private denylist scan, whose patterns live only in the `LEAK_DENYLIST` Actions secret, scans the tree and PR diff. A DCO check rejects commits without `Signed-off-by`.

### Read first

- docs/adr/001-open-source-client-apache-2.md

### Scope

- `.github/workflows/safety.yml`
- `scripts/leak-scan.sh`
- `scripts/leak-scan_test.sh`
- `.gitleaks.toml`

### Out of scope

- The denylist content. Never write real denylist patterns anywhere in the repository, in test fixtures, in commit messages or in PR bodies. Tests use the synthetic pattern `zz-synthetic-leak-[0-9]+`.
- Setting the `LEAK_DENYLIST` secret. That is a maintainer action. Note it in the PR body.

### Steps

1. `scripts/leak-scan.sh` (POSIX `sh`, `set -eu`, SPDX header on line 2):
   - Inputs: patterns from env `LEAK_DENYLIST` (newline-separated extended regexes, blank lines and lines starting with `#` ignored). Optional first argument: a directory to scan (default `.`). Optional env `LEAK_SCAN_DIFF_BASE`: when set, also scan the added lines of `git diff "$LEAK_SCAN_DIFF_BASE"...HEAD`.
   - If `LEAK_DENYLIST` is empty or unset: when env `LEAK_SCAN_REQUIRED=1`, print `leak-scan: LEAK_DENYLIST is not configured` and exit 2. Otherwise print `leak-scan: skipped (no denylist available)` and exit 0.
   - Write the patterns to a temp file created with `mktemp` and removed in a `trap`. Run `grep -rnIE -i -f "$patterns" --exclude-dir=.git --exclude-dir=dist "$dir"`, but print only `file:line` for each hit by piping through `cut -d: -f1,2`. Never print the matched text or the pattern.
   - Exit 1 when there is any hit, and print `leak-scan: <n> potential leak(s)` to stderr.
   - Add `set +x` at the top so that tracing can never echo the patterns.
2. `scripts/leak-scan_test.sh`:
   - Create a temp dir containing `clean.txt` (`hello world`) and run with `LEAK_DENYLIST='zz-synthetic-leak-[0-9]+'`. Expect exit 0.
   - Add `dirty.txt` containing `zz-synthetic-leak-42` and expect exit 1, with output containing `dirty.txt:1` and NOT containing `zz-synthetic-leak`.
   - Run with an empty `LEAK_DENYLIST` and `LEAK_SCAN_REQUIRED=1`. Expect exit 2.
   - Run with an empty `LEAK_DENYLIST` and no `LEAK_SCAN_REQUIRED`. Expect exit 0.
   - Print `PASS` or `FAIL: <case>`.
3. `.gitleaks.toml`:

   ```toml
   [extend]
   useDefault = true

   [[rules]]
   id = "ajent-api-token"
   description = "Ajent API token"
   regex = '''aj_[0-9a-f]{16}_[A-Za-z0-9_-]{43}'''
   keywords = ["aj_"]

   [allowlist]
   paths = ['''testdata/''']
   ```

4. `.github/workflows/safety.yml`:
   - `name: safety`, triggers `push: branches: [main]` and `pull_request:`, and `permissions: contents: read`.
   - Job `gitleaks` (ubuntu-latest): checkout with `fetch-depth: 0`. Install gitleaks from its GitHub release: resolve the latest tag with `gh release view -R gitleaks/gitleaks --json tagName`, and download the `linux_x64` tarball plus its checksums file with `curl`, verifying sha256. Then run `gitleaks git --config .gitleaks.toml --redact --verbose`. Use the binary rather than `gitleaks-action`, because the action requires a license for organizations.
   - Job `leak-scan` (ubuntu-latest): checkout with `fetch-depth: 0`, run `sh scripts/leak-scan_test.sh`, then run `scripts/leak-scan.sh .` with env `LEAK_DENYLIST: ${{ secrets.LEAK_DENYLIST }}`, `LEAK_SCAN_REQUIRED: ${{ github.event_name == 'push' && '1' || '0' }}` and `LEAK_SCAN_DIFF_BASE: ${{ github.event.pull_request.base.sha }}`. Fork PRs get no secrets, so the script skips. Pushes to main fail closed.
   - Job `dco` (ubuntu-latest, only `if: github.event_name == 'pull_request'`): checkout with `fetch-depth: 0` and run:

     ```bash
     base=${{ github.event.pull_request.base.sha }}
     head=${{ github.event.pull_request.head.sha }}
     missing=0
     for c in $(git rev-list --no-merges "$base..$head"); do
       git log -1 --format=%B "$c" | grep -qE '^Signed-off-by: .+ <.+>$' || { echo "missing sign-off: $c"; missing=1; }
     done
     exit $missing
     ```

   - Pin all actions by SHA as described in docs/tasks/T1.4.md step 1.
5. Make both scripts executable. Run `shellcheck` if it is available.

### Acceptance criteria

- `sh scripts/leak-scan_test.sh` prints `PASS`.
- On a PR, jobs `gitleaks`, `leak-scan` and `dco` pass.
- Genuine-red check, part 1: on a throwaway draft PR, add a file containing `zz-synthetic-leak-7` and run the job with the repository secret set to include `zz-synthetic-leak-[0-9]+`. If the maintainer has not set the secret, instead run `LEAK_DENYLIST='zz-synthetic-leak-[0-9]+' scripts/leak-scan.sh .` locally with the file present. Observe exit 1 with `file:line` only. Remove the file and observe exit 0. Report both outputs.
- Genuine-red check, part 2: on the throwaway PR, push one commit without `-s` and observe the `dco` job fail. Close the throwaway PR afterwards.
- No real denylist term appears anywhere in the diff.

### Verification

```bash
sh scripts/leak-scan_test.sh
LEAK_DENYLIST='zz-synthetic-leak-[0-9]+' scripts/leak-scan.sh .
shellcheck scripts/leak-scan.sh scripts/leak-scan_test.sh || true
gh pr checks <pr-number>
```
