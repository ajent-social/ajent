## T3.6: Build internal/profiles and wire lazy enrollment

### Objective

`internal/profiles` resolves the credential for a tool profile. It reuses an enrolled profile, lazily enrolls a new one with the installation's root credential exactly once even under heavy concurrency, re-syncs scope settings when they change, and falls back to private-only collaboration when domain grants are refused. `cmd/ajent` wires this into `cli.Env.Resolve`, so both CLI commands and the MCP server use it.

### Read first

- docs/interfaces.md, sections "internal/profiles", "internal/credentials", "internal/config", "internal/api" and "internal/cli" (Env.Resolve).
- docs/contract.md section 4 "Files" (profile layout), "Scope settings" (settings merge) and "Enrollment" (POST /v1/fleet) (T2.1).
- docs/adr/006-client-trust-boundaries.md ("Repository content grants nothing").
- `cmd/ajent/main.go` (T2.6), to find where `cli.Env` is built.

### Scope

Create:

- `internal/profiles/settings.go`, `internal/profiles/settings_test.go`
- `internal/profiles/enroll.go`, `internal/profiles/enroll_test.go`
- `internal/profiles/helper_test.go` (the subprocess helper for the concurrency test)

Do not edit `cmd/ajent/main.go` (owned by T2.6). Wiring attaches through the `wire` slice that T2.6 declares there.

### Out of scope

- Any file in `internal/mcp`. The MCP command already passes `env.Resolve` into the Session (T3.2).
- Changing credential file formats (T2.3).

### Steps

1. `settings.go`: `ScopeSettings(dir, projectRoot string, root credentials.Credential) (Settings, bool, error)`.
   1. Read `<dir>/config.json` (user) and `<projectRoot>/.aj/config.json` (project) with `config.ReadJSON`. Refuse symlinks, including a symlinked `.aj` directory. A missing file means `{}`. A file that is not a JSON object is an error.
   2. If both are empty, return `(Settings{}, false, nil)`. Legacy manual installs send no settings.
   3. `settings` = project if non-empty, else user. `private_only` must be a bool if present, else return an error.
   4. `scope` = `credentials.ProjectScope(projectRoot)`.
   5. Grants come only from `<dir>/scope-grants.json[root.Identity()]`, where the keys "user" and `scope` each hold a list of `{"domain","id"}`. Build `allowed` (domain to id) only when not private.
   6. `domain` = `settings.domain`. If it is non-empty, not in `allowed`, and not private, return the error "This project selects an unapproved domain. Run ajent configure --scope project, or select private mode."
   7. Return `Settings{Scope: scope, Grants: sorted unique ids, Domain: "" if private else domain, PrivateOnly: private}`, with `true`. `Grants` must marshal as `[]`, never `null`.
2. `enroll.go`: `Existing(dir, root, profile)` returns the enrolled non-pending profile credential, else `root`. It never writes. It rejects an invalid profile name with `credentials.ErrInvalidProfile`.
3. `Enroller.Resolve(ctx, root, profile, projectRoot)`:
   1. Validate the profile name and ensure `credentials.ProfileDir` exists (0700).
   2. `lock, err := config.Acquire(credentials.ProfileLockPath(dir, root, profile), 30*time.Second)`, and defer `Release`.
   3. Load the profile. If it is absent, create `{server: root.Server, token: credentials.NewToken(), pending: true}` with an exclusive create (`SaveProfile` must not overwrite an existing file; use `config.CreateExclusive` on `ProfilePath`).
   4. Compute `settings, configured := ScopeSettings(...)` and its fingerprint = compact JSON of the Settings.
   5. Sync when the profile is pending, when the fingerprint differs from the in-process memo for this profile, or when more than 300 seconds have passed since the last sync (use `e.Now`). The memo is an unexported `map[string]syncMemo` on the Enroller, guarded by a mutex.
   6. The sync body is `{"profile":profile,"token":c.Token}`, merged with the Settings fields when `configured`. POST `/v1/fleet` with the root credential. On `*api.Error` with Status 403, when `settings.Grants` is non-empty, retry once with `{"profile","token","scope":settings.Scope,"grants":[],"domain":"","private_only":true}` and set `DomainNotice` = "Domain access is unavailable; private collaboration remains connected. Run ajent configure to review scope access." On a successful normal sync, clear `DomainNotice`. Any other error is returned unchanged.
   7. Merge the response fields into the credential (agent_id, group_id, handle and any others, via `Extra`), clear `Pending`, and save with `SaveProfile` (an atomic replace). Record the memo and return.
4. `cmd/ajent/wire_profiles.go`: `func init() { wire = append(wire, wireProfiles) }`. `func wireProfiles(env *cli.Env)` sets `env.Resolve` to a closure that calls `dir, err := env.Dir()` (never read `env.ConfigDir` directly: `DefaultEnv` leaves it empty until `Dir()` resolves it), loads the root via `credentials.LoadRoot(dir)`, computes `projectRoot := credentials.ProjectRoot(env.Cwd, env.Home)`, and calls `enroller.Resolve`. `enroller` is `&profiles.Enroller{Dir: dir, API: env.API, Now: time.Now}`, created once per process on the first call (guard with `sync.Once`).
5. Tests:
   - `TestScopeSettingsTable`: no files, a user-only file, project overriding user, private_only true, an unapproved domain, a hostile project file listing a grant absent from scope-grants.json (ignored, error on domain), a non-bool private_only, and a symlinked project config (skip on windows).
   - `TestExistingNeverWrites`.
   - `TestResolveEnrollsOnce`: enroll once, then a second Resolve within 300s makes no second request.
   - `TestResolveResyncsOnSettingsChange` and `TestResolveResyncsAfter300s` (inject `Now`).
   - `TestResolve403FallsBackToPrivate`: the fake server returns 403 on the first `/v1/fleet` with grants, then 200. Assert two requests, a second body with `private_only: true` and empty grants, and a DomainNotice that is set.
   - `TestResolveConcurrentProcesses`: use the `TestHelperProcess` pattern (`os.Args[0]` with `-test.run=TestHelperProcess` and env `GO_WANT_HELPER=1`). Launch 12 subprocesses against one fake server URL and one temp config dir. Each resolves the same new profile and prints its token. Assert exactly one POST `/v1/fleet` was recorded, and all 12 printed tokens are identical.
   - `TestWireProfilesSetsResolve` (cmd/ajent): the `wire` slice contains `wireProfiles`, and after `wireProfiles(env)` with `env.ConfigDir` empty and `AJENT_CONFIG_DIR` set through `t.Setenv`, `env.Resolve` is non-nil and resolves against the fake server.
6. Run gofmt, go vet (including GOOS=windows) and golangci-lint.

### Acceptance criteria

- All step 5 tests pass with `-race` on ubuntu, macos and windows. `TestResolveConcurrentProcesses` must run on windows too, which exercises `LockFileEx`.
- A project `.aj/config.json` can never add a grant.
- Genuine-red check: temporarily remove the `config.Acquire` call. Observe `TestResolveConcurrentProcesses` fail (more than one enrollment or differing tokens), then restore it. Temporarily ignore `scope-grants.json` and trust `settings.grants` from project config. Observe `TestScopeSettingsTable` fail on the hostile-file case, then restore it. Report both outputs.
