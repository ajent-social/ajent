## T4.7: Write the cross-OS harness integration tests

### Objective

One end-to-end suite exercises every real registered writer together against a realistic fake home directory on ubuntu, macos and windows. The suite runs `Sync` twice, then rolls back the first snapshot. It proves three things: foreign configuration survives intact, the second run changes nothing, and rollback returns every file to its original bytes.

### Read first

- docs/tasks/T4.6.md, T4.17.md, T4.4.md, T4.16.md, T4.5.md, T4.13.md, T4.14.md, T4.15.md and T4.18.md (each writer's paths and CLI calls)
- docs/interfaces.md `internal/integrations`

### Scope

- `internal/integrations/harness_e2e_test.go` (create)
- `testdata/integrations/e2e/home/` (create: the fixture home described in step 1)

### Out of scope

- Changing writer code. If a writer bug appears, report it in the PR description with the failing test output, and fix it only if the fix is a single obvious line inside that writer's own file. Otherwise mark the test `t.Skip("writer bug: <name>, see PR")` and report it.
- CI workflow changes. The existing CI already runs `go test ./...` on all three OSes.

### Steps

1. Build the fixture home `testdata/integrations/e2e/home/` with these files. Paths use forward slashes, and the test remaps VS Code's directory per OS with the same `userDir` logic as T4.15, copying `vscode-user/mcp.json` there:
   - `.cursor/mcp.json`: `{"mcpServers": {"github": {"command": "npx", "args": ["-y", "@modelcontextprotocol/server-github"]}}}`
   - `.gemini/settings.json`: `{"theme": "Default", "selectedAuthType": "oauth-personal", "mcpServers": {"fs": {"command": "node", "args": ["fs.js"]}}}`
   - `.copilot/mcp-config.json`: `{"mcpServers": {"playwright": {"type": "local", "command": "npx", "args": ["@playwright/mcp@latest"], "tools": ["*"]}}}`
   - `vscode-user/mcp.json`: `{"inputs": [], "servers": {"github": {"type": "http", "url": "https://api.githubcopilot.com/mcp/"}}}`
   - `.claude.json`: `{"numStartups": 3, "mcpServers": {"context7": {"type": "stdio", "command": "npx", "args": ["-y", "@upstash/context7-mcp"]}}}`
   - `.agents/skills/other-skill/SKILL.md`: a foreign skill that must stay untouched.
   All files use 2-space indentation and a trailing newline.
2. `copyHome(t)` copies the fixture into `t.TempDir()`. On darwin it moves `vscode-user/` to `Library/Application Support/Code/User/`. On linux it moves it to `.config/Code/User/`. On windows it moves it to `AppData/Roaming/Code/User/` and sets `Getenv("APPDATA")` accordingly.
3. Install fakes (restore them with `t.Cleanup`):
   - `integrations.LookPath` returns success for `claude` and `codex`.
   - `integrations.Run` emulates both CLIs:
     - `claude mcp add-json`, `claude mcp remove` and the marketplace calls edit `<home>/.claude.json` `mcpServers.ajent` and an in-memory marketplace set.
     - `codex mcp add`, `codex mcp remove` and `codex mcp get ajent --json` keep an in-memory entry. They also write a line `[mcp_servers.ajent]` plus `command = "..."` to `<home>/.codex/config.toml` on add and remove it on remove, so file backups have something to restore.
     - Any other argv fails.
4. `p := integrations.Params{Home: home, Binary: <abs path "/opt/ajent/bin/ajent" converted with filepath.FromSlash>, ConfigDir: filepath.Join(home, ".aj"), GOOS: runtime.GOOS, Getenv: fakeGetenv}`.
5. `TestHarnessSyncTwiceThenRollback`:
   1. Hash every file under home (path to sha256) into `before`.
   2. `res1, b1, err := integrations.Sync(ctx, p)`. There is no error. Every one of claude, codex, cursor, gemini, copilot, vscode and agentskills reports `configured`.
   3. For each JSON config, assert the foreign entries (`github`, `fs`, `theme`, `selectedAuthType`, `playwright`, `inputs`, `servers.github`, `numStartups`, `context7`) decode deep-equal to the fixture values, and `ajent.command == p.Binary`.
   4. Hash everything into `after1`.
   5. `res2, _, err := integrations.Sync(ctx, p)`. Every result is `unchanged`. Hash into `after2`. Apart from `.aj/integration-status.json` and the new backup directory under `.aj/backups/`, `after2 == after1`.
   6. `integrations.Rollback(p.ConfigDir, b1.ID)`. Hash again. Excluding `.aj/`, the hashes equal `before`, including the deletion of files that did not exist (`.agents/skills/ajent-network/SKILL.md` and `.codex/config.toml`).
   7. `other-skill/SKILL.md` has been unchanged at every step.
6. `TestHarnessForeignAjentEntryBlocksOnlyThatTool`: pre-seed `.cursor/mcp.json` with `mcpServers.ajent = {"command": "npx", "args": ["foreign"]}`. Sync gives cursor `incomplete` and every other tool `configured`. The cursor file bytes are unchanged.
7. `TestHarnessNoToolsInstalled`: an empty home with LookPath failing everywhere. Only `agentskills` is configured, and there are no errors.

### Acceptance criteria

- `go test ./internal/integrations -run TestHarness -race -count=1 -v` passes on ubuntu, macos and windows. Report the executed test count per OS from CI.
- Genuine-red: temporarily comment out `Register(cursorWriter{})` in `cursor.go` (do not commit this), then observe `TestHarnessSyncTwiceThenRollback` fail on the cursor assertion. Restore and report both outputs.

### Verification

- `go test ./internal/integrations -run TestHarness -race -count=1 -v`
- `GOOS=windows go vet ./internal/integrations`
