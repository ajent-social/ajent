## T4.17: Build the integrations core: registry, entries, JSON merge and stable path

### Objective

`internal/integrations` provides the shared machinery every harness writer uses:

- the `Writer` registry
- an exec seam for tests
- the canonical MCP entry builder
- an ownership test for existing entries
- an order-preserving JSON merge
- stable binary path resolution

When this task lands, the seven writer rows (T4.4, T4.5, T4.13, T4.14, T4.15, T4.16, T4.18) can each be built in parallel in their own file.

Decision (orchestrator, from the T2.1 contract freeze): Go writes the harness `env` block only when the config directory or credential file is non-default, while the Python client always wrote both variables (docs/contract.md section 9). Any existing `ajent` entry whose command runs `ajent mcp` or `client.py mcp` counts as ajent-owned (`Owned` in T4.17) and is replaced, so migration, post-upgrade sync and uninstall work on Python-era entries. This intentionally differs from the reference, which left any differing existing entry unchanged and, for Claude Code and Codex, kept any registration that `mcp get ajent` found. Entries that are not owned are still never modified.

### Steps

1. Implement the `Writer` interface exactly as already declared in docs/interfaces.md. Writers need the config directory to decide the `env` block, so the interface takes a parameter struct:

   ```go
   type Params struct {
       Home           string // user home directory
       Binary         string // stable absolute path to launch (StableBinary result)
       ConfigDir      string // ajent config dir actually in use
       CredentialFile string // "" when AJENT_CREDENTIAL_FILE is unset
       GOOS           string // runtime.GOOS in production, overridden in tests
       Getenv         func(string) string // for APPDATA, XDG_CONFIG_HOME, LOCALAPPDATA
   }
   type Writer interface {
       Target() Target
       Detect(p Params) bool
       Paths(p Params) []string // absolute files this writer may modify (for backups)
       Apply(ctx context.Context, p Params) (Result, error)
       Remove(ctx context.Context, p Params) (Result, error)
   }
   ```

   `Target` and `Result` are as in docs/interfaces.md. `Sync(ctx context.Context, p Params) ([]Result, Backup, error)` is implemented by T4.6.
2. `registry.go`: `Register(w Writer)` appends to an unexported slice and panics on a duplicate `Target().Name`. `Writers()` returns a copy sorted by this fixed order: `claude, codex, cursor, gemini, copilot, vscode, agentskills`, with unknown names last, alphabetically. Add the exported `func ResetForTest() (restore func())` in `registry.go`: it swaps the registry for an empty one and returns a function that restores the previous registry. Tests in other packages (`cmd/ajent` for T4.6, T4.8 and T6.4, and `internal/setup` for T4.9) use it as `defer integrations.ResetForTest()()`.
3. `run.go`:

   ```go
   type Runner func(ctx context.Context, name string, args ...string) ([]byte, error)
   var Run Runner = defaultRunner
   ```

   `defaultRunner` uses `exec.CommandContext(ctx, name, args...)` with a 30s timeout and `CombinedOutput`. It returns output and error. Callers never print the output, because vendor output can contain other MCP secrets. Add `var LookPath = exec.LookPath`.
4. `entry.go`:
   - `func MCPArgs(profile string) []string` returns `[]string{"mcp", "--profile", profile, "--project-profile"}`.
   - `func EntryEnv(p Params) map[string]string` returns nil when `p.ConfigDir` equals `filepath.Join(p.Home, ".aj")` and `p.CredentialFile == ""`. Otherwise it returns a map with `AJENT_CONFIG_DIR` (only when the dir is non-default) and `AJENT_CREDENTIAL_FILE` (only when set).
   - `func Entry(p Params, profile string) map[string]any` returns `{"command": p.Binary, "args": MCPArgs(profile)}` plus `"env": EntryEnv(p)` when that is non-nil. Use `[]any` for args and `map[string]any` for env, so the result compares equal to decoded JSON with `reflect.DeepEqual`.
   - `func Owned(entry map[string]any) bool` returns true when any of these holds:
     1. `filepath.Base(command)` (after trimming `.exe`, case-insensitive) equals `ajent`.
     2. Any string element of `args` has base name `client.py`. That identifies a Python-era install.
     3. `command` has base name `python3` or `python`, or starts with `python3.`, and `args[0]` ends with `client.py`.
     Everything else is foreign.
   - `func SameEntry(a, b map[string]any) bool` normalizes through a JSON marshal and unmarshal, then compares with `reflect.DeepEqual`.
5. `jsonmerge.go` implements `MergeJSONServer(path, section string, entry map[string]any) (changed bool, err error)` and `RemoveJSONServer(path, section string) (changed bool, err error)` with these rules:
   - If `path` is a symlink, return `config.ErrSymlink`.
   - A missing file counts as `{}`. Create parent directories with 0700.
   - Parse with `json.Decoder` tokens into an ordered object: a slice of `{key string; raw json.RawMessage}` for the top level, and the same for the `section` object. Values other than `section` stay as raw bytes and are never re-encoded.
   - If the file is not valid JSON (including JSONC with comments or trailing commas), return `ErrUnparseable` (`errors.New("integrations: config is not plain JSON; left unchanged")`) and do not write.
   - If `section` exists but is not an object, return `ErrUnparseable`.
   - Existing `ajent` key: if `SameEntry(existing, entry)`, return `false, nil`. If `!Owned(existing)`, return `ErrForeignEntry` (`errors.New("integrations: an ajent entry with foreign settings exists; left unchanged")`). Otherwise replace it in place, keeping its position.
   - With no `ajent` key, append it as the last key of `section`. With no `section` key, append the section as the last top-level key.
   - A new or replaced `ajent` entry is encoded with `json.Marshal(entry)`, which sorts map keys alphabetically, and then indented to its depth. Writer golden files depend on this.
   - Emit with 2-space indentation. Re-indent each preserved raw value with `json.Indent` at the right depth, so an unchanged file round-trips byte-identically when it was already 2-space indented. End with a single `\n`.
   - Write with `config.WritePrivate`. Keep the file mode if the file existed: stat it before writing, and chmod after writing if it differs from 0600.
   - `RemoveJSONServer` deletes `section.ajent` only when `Owned`. It returns `false, nil` when the key is absent and `ErrForeignEntry` when it is foreign. It leaves an empty section in place.
6. Golden fixtures under `testdata/integrations/jsonmerge/<case>/{before.json,after.json}` for these cases:
   - `empty-file` (before absent)
   - `foreign-servers-kept`
   - `other-top-level-keys-kept`
   - `replace-python-entry`
   - `unchanged-second-run` (before == after)
   - `section-missing`
   Also add `jsonc/before.json` containing a `//` comment, which must be left byte-identical with `ErrUnparseable`, and `foreign-ajent/before.json`, which must be left identical with `ErrForeignEntry`.
7. `stablepath.go` implements `func StableBinary(executable string, goos string, getenv func(string) string, exists func(string) bool) string`. This is the signature declared in docs/interfaces.md. Callers pass `runtime.GOOS`, `os.Getenv` and a stat-based `exists`. Rules are evaluated in order on `filepath.ToSlash(executable)`:
   1. Homebrew formula: contains `/Cellar/ajent/`. Take the prefix before `/Cellar/`. If `exists(prefix + "/bin/ajent")`, return it (native separators).
   2. Homebrew cask: contains `/Caskroom/ajent/`. Take the prefix before `/Caskroom/`, and return `prefix/bin/ajent` if it exists.
   3. WinGet: contains `/Microsoft/WinGet/Packages/` (case-insensitive). Return `%LOCALAPPDATA%\Microsoft\WinGet\Links\ajent.exe` if it exists.
   4. Scoop: matches `/scoop/apps/ajent/<version>/` where `<version>` is not `current`. Replace `<version>` with `current` if that path exists.
   5. Otherwise return `executable` unchanged.
   Add `func CurrentBinary() (string, error)`, which calls `os.Executable()` and then `StableBinary(exe, runtime.GOOS, os.Getenv, fileExists)`.
   Add `var BinaryOverride string`. When non-empty, `CurrentBinary` returns it. Tests use this to pin the path.
   Add `func ParamsFromEnv(home, configDir string, getenv func(string) string) (Params, error)`. It returns `Params{Home: home, ConfigDir: configDir, CredentialFile: getenv("AJENT_CREDENTIAL_FILE"), Binary: <CurrentBinary()>, GOOS: runtime.GOOS, Getenv: getenv}`. T4.6, T4.8, T4.9 and T6.4 build Params only through this function. `BinaryOverride` and `ParamsFromEnv` are declared in docs/interfaces.md.
8. Tests:
   - `TestMergeGolden` is table-driven over the fixture directories. It copies `before.json` into `t.TempDir()`, merges `Entry(p, "cursor")` with `p.Binary = "/usr/local/bin/ajent"` and default config, then compares bytes with `after.json`.
   - `TestMergeSecondRunIdentical`, `TestMergeRefusesSymlink` (skip on windows when symlink creation fails), `TestMergeJSONCUnchanged`, `TestMergeForeignEntry`, `TestRemoveOwnedOnly`.
   - `TestOwned` (table: ajent, ajent.exe, python3 plus client.py, `/opt/homebrew/bin/python3.12` plus client.py, node, and npx with foreign args).
   - `TestEntryEnv` (default dir gives nil, custom dir, credential file).
   - `TestStableBinary` (table with fake `exists` covering all five rules on darwin, linux and windows paths).
   - `TestRegistryOrderAndDuplicatePanics`.

### Acceptance criteria

- All tests pass on ubuntu, macos and windows CI with `-race`.
- Genuine-red: change the merge to re-encode preserved values with `json.Marshal` instead of keeping raw bytes, then observe `TestMergeGolden/other-top-level-keys-kept` fail on key order or spacing. Restore and report both outputs.
- Genuine-red: make `Owned` return true for every entry and observe `TestMergeForeignEntry` fail. Restore.
