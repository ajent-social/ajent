## T2.10: Port the scope and domain commands

### Objective

A human can choose whether Ajent represents all projects or one project, and whether it uses a verified domain or private mode. Choices are saved only by an explicit command. `scope-grants.json` gains a grant only from a successful `POST /v1/domain-grants`, never from project files. `ajent configure`, `ajent domains` and `ajent revoke-grant` match the Python client. The logic lives in a reusable package so `ajent setup` (T4.3) can call it.

### Steps

1. Define the package API in `internal/scope/scope.go`, exactly as already declared in docs/interfaces.md section `internal/scope`:

   ```go
   type Options struct {
       Scope       string // "", "user", "project"
       Domain      string
       DomainSet   bool   // true when --domain was given (even empty)
       Private     bool
       DuringSetup bool   // non-interactive setup returns ErrDeferred instead of failing
   }
   var ErrDeferred = errors.New("scope: connected privately; configure a domain later with ajent configure --scope user|project --domain DOMAIN")
   func Configure(ctx context.Context, env *cli.Env, root credentials.Credential, opts Options) (message string, err error)
   func ValidDomain(d string) bool
   ```

2. `ValidDomain` normalizes the domain first (`strings.ToLower(strings.TrimSpace(d))`, then trim a trailing `.`), then matches Go's equivalent of the reference regex. Go `regexp` has no lookahead, so check the total length (1 to 253) separately, then match `^(?:[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?\.)+[a-z](?:[a-z0-9-]{0,61}[a-z0-9])?$`.
3. `Configure` follows these steps in order:
   1. Interactivity: `tty, ttyErr := env.OpenTTY()`, which is interactive when `ttyErr == nil`. Close it when done.
   2. If `opts.Scope == ""`:
      - When not interactive: during setup, return `ErrDeferred`. Otherwise return `errors.New("choose --scope user or --scope project")`.
      - When interactive, prompt `Use Ajent for (1) all your projects or (2) this project? [1]:`. An empty answer means `1`. Anything other than 1 or 2 returns `errors.New("choose 1 or 2")`.
   3. Key: `"user"`, or `credentials.ProjectScope(credentials.ProjectRoot(env.Cwd, env.Home))` for the project scope.
   4. If `!opts.DomainSet && !opts.Private`:
      - GET `/v1/domains` with `root`, decoding `{"domains":[{"domain":string,"verified":bool}]}`.
      - When not interactive: during setup (`opts.DuringSetup`), return `ErrDeferred`. Otherwise return `errors.New("choose --domain DOMAIN or --private")`.
      - Print `Verified domains: a, b` to the tty when there are any.
      - Prompt `Domain to represent (or private) [<default>]:`, where the default is the single verified domain when there is exactly one, else `private`.
      - The answer `private` sets `Private = true`.
   5. If not private:
      - Normalize and validate the domain, else return `errors.New("enter a DNS domain without a URL or port")`.
      - GET `/v1/domains`. If the domain is not listed as verified:
        - POST `/v1/domains/proof` with `{"domain":d,"action":"challenge"}` and print `Add DNS TXT <name> = <value>` to `env.Stdout`.
        - When interactive, prompt `Press Enter when the DNS record is ready:`.
        - POST `/v1/domains/proof` with `{"domain":d,"action":"check"}`.
      - Then POST `/v1/domain-grants` with `{"domain":d,"scope":key}` and decode the grant as `map[string]any` (it has at least `id` and `domain`).
      - An `*api.Error` with Status 403 returns `errors.New("this scope needs human approval; run ajent link, sign in and approve the domain scope")`.
   6. Target file: `<env.Dir()>/config.json` for the user scope, or `<projectRoot>/.aj/config.json` for the project scope (create `.aj` with 0700).
      - Read the existing object with `config.ReadJSON` into `map[string]any`. A missing file means `{}`, and a non-object is an error.
      - Set `version` to 1, `domain` to `""` if private else the domain, and `private_only` to the private flag.
   7. When there is a grant:
      - Take `config.Acquire(<dir>/scope-grants.lock, 5*time.Second)`.
      - Read `<dir>/scope-grants.json` as `map[string]map[string][]map[string]any`, missing meaning empty.
      - Under `account := bindings[root.Identity()]`, replace the entries in `account[key]` whose `domain` equals the domain with the new grant (appended last).
      - `config.WriteJSON`, then release the lock.
   8. `config.WriteJSON(target, settings)`.
   9. Return the message `<"Private mode" or domain> saved for <"all your projects" or "this project">. New and existing agents inherit these settings on their next operation.`
4. Wrap every prompt in `prompt(tty, msg, def string) (string, error)`: write `msg`, plus `[def]` when `def != ""`, plus `:`. Read one line with `bufio.Reader.ReadString('\n')`. At EOF with no text, return `errors.New("no answer received; use --scope and --domain or --private")`. Trim the answer and return the default when it is empty.
5. In `cmd/ajent/cmd_scope.go`, register three commands:
   - `configure`, with flags `--scope` (`user` or `project`; any other value is a usage error), `--domain` (use `fs.Visit` to set `DomainSet`) and `--private`. It loads the root credential with `rootCredential(env)`, calls `scope.Configure`, and prints the message to stdout.
   - `domains`: `getAndPrint` on `/v1/domains` with the root credential.
   - `revoke-grant`: exactly one positional arg, which must pass `api.CanonicalUUID`, else `errors.New("supply the grant ID shown by ajent domains")`. Send DELETE `/v1/domain-grants/<id>` with the root credential and print the raw response.
6. Tests in `internal/scope/scope_test.go`, using the fakeserver and `cli.Env` values built directly (`OpenTTY` returns a pipe-backed fake with scripted input, or an error for non-interactive):
   - `TestConfigureUserVerifiedDomain`: non-interactive with `Scope=user`, `Domain=example.com` and `DomainSet`. The fake `/v1/domains` lists `example.com` as verified and `/v1/domain-grants` returns `{"id":"<uuid>","domain":"example.com"}`. Assert:
     - `config.json` is `{"version":1,"domain":"example.com","private_only":false}`, preserving any pre-existing extra key
     - `scope-grants.json[identity]["user"]` holds exactly that grant
     - the proof endpoints were not called
   - `TestConfigureProjectPrivate`: `Scope=project`, `Private`. `<root>/.aj/config.json` has `private_only: true` and `domain: ""`. There are no network calls and no `scope-grants.json` change.
   - `TestConfigureUnverifiedRunsProof`: the challenge and check are posted in order, and the TXT line is printed.
   - `TestConfigure403Message`.
   - `TestConfigureNonInteractiveNeedsScope` covers both the plain error and `ErrDeferred` with `DuringSetup`, for a missing scope and for a missing domain choice.
   - `TestConfigureInteractivePrompts`: scripted answers `2\n` then `\n` with one verified domain choose the project scope and that domain.
   - `TestHostileProjectConfigGrantsNothing`:
     - Write a project `.aj/config.json` of `{"version":1,"domain":"evil.example","grants":["<uuid>"],"private_only":false}` plus a malicious `scope-grants.json` placed at `<projectRoot>/.aj/scope-grants.json`.
     - Run `Configure` with `Scope=project`, `Private`.
     - The user-level `<dir>/scope-grants.json` does not exist afterwards, and no request to `/v1/domain-grants` was made.
   - `TestValidDomain` covers `example.com`, `a.b.co`, `EXAMPLE.com.` (valid after normalization), `http://x.com`, `x.com:80`, `localhost` (invalid: no dot) and `-a.com`.
7. Tests in `cmd/ajent/cmd_scope_test.go`: `TestDomainsUsesRoot`, `TestRevokeGrantValidation` (a bad id gives exit 1 with zero requests, and a good id sends a DELETE with a canonical lowercase UUID), and `TestConfigureBadScopeFlag` (exit 2).

### Acceptance criteria

- `go test ./internal/scope/... ./cmd/ajent/... -race -count=1` passes on all three OSes.
- Genuine-red check: temporarily make `Configure` also copy the project config's `grants` into `scope-grants.json`. `TestHostileProjectConfigGrantsNothing` must fail. Restore and report both outputs.
- Genuine-red check: temporarily skip the verified check so proof always runs. `TestConfigureUserVerifiedDomain` must fail. Restore and report.
