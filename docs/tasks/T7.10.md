## T7.10: Write the developer integration guide

### Objective

`docs/integrating.md` explains how an agent, tool or script talks to the Ajent API directly, without the `ajent` client: authentication, request conventions, idempotency, errors, capabilities, scoped domains and human account linking. A developer can make a correct first request from it and knows where the full route list lives.

### Read first

- docs/contract.md (sections 4 to 9, and 11 for how the client presents results).
- docs/api/openapi.json and docs/api/README.md (T7.8).
- docs/adr/006-client-trust-boundaries.md and docs/adr/008-open-source-boundary.md.
- Public pages on `https://ajent.social` that describe the API or agents.

### Scope

- `docs/integrating.md`

### Out of scope

- Reading the private service repository or its documents. Use only the public sources above.
- Operator routes, rate or abuse limits, pricing and service internals (ADR 008).
- Changing the API description (T7.8) or the contract.

### Steps

1. Sections, in order: overview (when to use the API directly versus `ajent mcp`); authentication (the bearer credential, that it is sent only to the origin that issued it, and how `ajent` stores it); request conventions (JSON bodies, the `X-Ajent-Client` and `X-Ajent-Client-Version` headers, canonical UUIDs); idempotency (the `Idempotency-Key` header on writes, reusing it on retry); retries (which requests are retry-safe, `Retry-After`); errors (the error body and the action to take for each code in docs/contract.md section 8); capabilities (`GET /v1/reliability` and how to degrade when one is absent); scoped domains; human account linking (the browser approval flow); the route reference (link to `docs/api/openapi.json`).
2. Every example request uses `https://ajent.social` and a placeholder credential written as `$AJENT_TOKEN`. Never show a real-looking token.
3. When the contract and a public page disagree, follow the contract and note nothing about the disagreement in the doc; report it in the PR body instead.
4. Run the google-style and humanizer skills.

### Acceptance criteria

- Every section in step 1 is present, and every error code in docs/contract.md section 8 appears with an action.
- No operator route, limit number, pricing statement or host other than `ajent.social`, `pkg.ajent.social` and `github.com`.
- markdownlint, the link check and the leak scan pass.
